Choose the next capability to understand

Start with the knowledge-base walkthrough to learn how to upload documents, verify indexing, and query a reference collection. The other guides cover the neighboring capabilities that turn model access into a reviewable application.

For a new implementation, use this order: access → structured extraction → reference ingestion → retrieval → exact tools → evaluation → interface. Evaluate the examples against the quality criteria for your own application.

Use a small complete example. Carry one synthetic case through the stages, retain its evidence, and show the result to a reviewer. Add more tools only when the next experiment needs them.

How to use the examples

Configure credentials privately and choose currently available models through the access guide. Code blocks are starter scripts or explicitly labelled continuations. The HTML pages do not execute Python or call GenAI Studio. The knowledge-base guide documents a readiness-check mismatch found in the reviewed SDK; it does not silently patch the repository.

Shared records, exact mappings, and reviewer edits belong in deliberate database storage. The reference collection supplies context. Preserve that distinction throughout the application.
