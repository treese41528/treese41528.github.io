====================================
Appendix A: Calculus Review
====================================

From Formulas to Statistical Reasoning
-----------------------------------------

Calculus in this course is not an end in itself but the engine behind three core statistical workflows. **Optimization** uses derivatives to find maximum likelihood estimates — setting the score function to zero is just setting a derivative to zero. **Uncertainty quantification** uses the curvature of the log-likelihood (second derivatives) to measure how precisely the data pinpoint a parameter. **Transformation** uses change-of-variables formulas (Jacobians) to derive the distributions of functions of random variables. Every major result in Chapters 2–5 rests on one of these three applications.

This appendix develops the calculus tools that the rest of the course assumes. We state results precisely, provide intuition for why each one matters statistically, and verify key results computationally. The proofs that *use* these tools — the central limit theorem, delta method, Cramér-Rao bound — live in :ref:`Appendix E <appendix-statistical-inference>`. The matrix-specific gradient and Hessian identities used in multivariate estimation live in :ref:`Appendix B <appendix-linear-algebra>`. The iterative optimization and quadrature algorithms live in :ref:`Appendix C <appendix-numerical-analysis>`.

.. admonition:: Road Map 🧭
   :class: important

   - **Sections 1–2 (Univariate):** Differentiation rules — especially logarithmic differentiation and the chain rule — that produce score functions; integration techniques (by parts, change of variables) that compute moments and derive densities
   - **Section 3 (Approximation):** Taylor series as the bridge from exact to tractable — first-order gives the delta method, second-order gives the quadratic likelihood approximation and the Wald statistic
   - **Section 4 (Leibniz Rule):** Differentiation under the integral sign — the single calculus fact that makes E[score] = 0 and the Fisher information equality work
   - **Sections 5–8 (Multivariate):** Gradients, Hessians, the multivariate chain rule, convexity, multivariate Taylor expansions, and Jacobian determinants — the geometry of multi-parameter inference

   - **Python/NumPy**: Basic array operations (:ref:`appendix-python-random-generation`)

Univariate Differentiation
----------------------------

Basic Rules
~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   The **derivative** of :math:`f` at :math:`x` is :math:`f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}`, provided the limit exists. The derivative gives the instantaneous rate of change and the slope of the tangent line at :math:`x`.

.. admonition:: Theorem: Differentiation Rules
   :class: note

   For differentiable functions :math:`f` and :math:`g`:

   - **Sum rule:** :math:`(f + g)' = f' + g'`
   - **Product rule:** :math:`(fg)' = f'g + fg'`
   - **Quotient rule:** :math:`(f/g)' = (f'g - fg')/g^2`
   - **Chain rule:** :math:`\frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)`

**Why the chain rule dominates this course.** Nearly every likelihood in parametric statistics involves compositions: the data enter through a sufficient statistic, which enters the log-likelihood through a nonlinear function of the parameter. In generalized linear models (Chapter 3.5), the composition is explicit: the linear predictor :math:`\boldsymbol{x}^\top \boldsymbol{\beta}` passes through a link function :math:`g(\cdot)` to produce the mean :math:`\mu`, which enters the log-likelihood. The chain rule is what produces the score vector, the information matrix, and the IRLS weight structure from these compositions.


Logarithmic Differentiation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   For a positive differentiable function :math:`f(x) > 0`:

   .. math::

      \frac{d}{dx} \log f(x) = \frac{f'(x)}{f(x)}

   Equivalently, :math:`f'(x) = f(x) \cdot \frac{d}{dx} \log f(x)`.

**Why we always work with log-likelihoods.** Three reasons make logarithmic differentiation the central tool of likelihood-based inference:

1. **Products become sums.** For independent data, :math:`L(\theta) = \prod_{i=1}^n f(x_i; \theta)`, so :math:`\ell(\theta) = \log L(\theta) = \sum_{i=1}^n \log f(x_i; \theta)`. Sums are easier to differentiate, and the CLT applies to sums.

2. **Exponential families simplify.** If :math:`f(x; \theta) = h(x) \exp(\eta(\theta) T(x) - A(\eta))`, then :math:`\log f = \eta T(x) - A(\eta) + \log h(x)`. Differentiating with respect to :math:`\eta` is straightforward.

3. **The score has mean zero.** The derivative :math:`U(\theta) = \ell'(\theta)` satisfies :math:`\mathbb{E}[U(\theta)] = 0` at the true parameter — a property that is natural in log space but has no analogue for the raw likelihood. This is proved in the Leibniz Rule section below.

**Worked Example: Poisson Score Function.**
Let :math:`X_1, \ldots, X_n \overset{\text{iid}}{\sim} \text{Poisson}(\lambda)`. The likelihood is:

.. math::

   L(\lambda) = \prod_{i=1}^n \frac{e^{-\lambda} \lambda^{x_i}}{x_i!}

Taking the log:

.. math::

   \ell(\lambda) = \sum_{i=1}^n (x_i \log \lambda - \lambda - \log x_i!) = \left(\sum x_i\right) \log \lambda - n\lambda - \sum \log x_i!

The **score function** is:

.. math::

   U(\lambda) = \ell'(\lambda) = \frac{\sum x_i}{\lambda} - n

Setting :math:`U(\hat{\lambda}) = 0` gives the MLE :math:`\hat{\lambda} = \bar{X}`.

.. code-block:: python

   import numpy as np
   from scipy.optimize import approx_fprime

   rng = np.random.default_rng(42)

   n = 50
   lam_true = 3.5
   data = rng.poisson(lam_true, n)
   sum_x = int(np.sum(data))
   xbar = np.mean(data)

   def poisson_loglik(lam_arr):
       lam = lam_arr[0]
       if lam <= 0:
           return -1e20
       return float(np.sum(data * np.log(lam) - lam))

   def score_analytical(lam):
       return sum_x / lam - n

   print(f"Poisson score verification (n={n}, x̄={xbar:.2f})")
   print(f"{'λ':>8}  {'Analytical':>12}  {'Numerical':>12}  "
         f"{'Difference':>12}")
   print("-" * 50)
   for lam in [2.0, 3.0, xbar, 4.0, 5.0]:
       s_anal = score_analytical(lam)
       s_num = approx_fprime(np.array([lam]),
                             poisson_loglik, 1e-8)[0]
       print(f"{lam:>8.2f}  {s_anal:>12.6f}  {s_num:>12.6f}  "
             f"{abs(s_anal - s_num):>12.2e}")

   print(f"\nMLE: λ̂ = x̄ = {xbar:.2f}")
   print(f"Score at MLE: U({xbar:.2f}) = "
         f"{score_analytical(xbar):.6f}")

   --------------------------------------------------
      2.00     35.500000     35.500000      3.11e-07
      3.00      7.000000      6.999998      2.22e-06

The analytical and numerical derivatives agree to within :math:`\sim 10^{-6}` at every evaluation point, and the score is exactly zero at the MLE :math:`\hat{\lambda} = \bar{X}`.

**Normal Score for** :math:`\mu` **(brief).** For :math:`X_1, \ldots, X_n \sim N(\mu, \sigma^2)` with :math:`\sigma^2` known, the log-likelihood is :math:`\ell(\mu) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum(x_i - \mu)^2`. The score is :math:`U(\mu) = \frac{1}{\sigma^2}\sum(x_i - \mu) = \frac{n}{\sigma^2}(\bar{X} - \mu)`. Setting to zero gives :math:`\hat{\mu} = \bar{X}`.


Higher Derivatives and the Second Derivative Test
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Second Derivative Test
   :class: note

   At a critical point :math:`x^*` where :math:`f'(x^*) = 0`:

   - :math:`f''(x^*) > 0` implies :math:`x^*` is a local minimum
   - :math:`f''(x^*) < 0` implies :math:`x^*` is a local maximum
   - :math:`f''(x^*) = 0` is inconclusive

**The second derivative as information.** At a candidate MLE :math:`\hat{\theta}`, the quantity :math:`J(\hat{\theta}) = -\ell''(\hat{\theta})` is the **observed Fisher information**. It measures the curvature of the log-likelihood at its peak: a sharply curved peak (large :math:`J`) means the data strongly favor :math:`\hat{\theta}` over nearby values, implying high precision. A broad, flat peak (small :math:`J`) means the data are compatible with a range of parameter values, implying low precision. The standard error of the MLE is approximately :math:`1/\sqrt{J(\hat{\theta})}`.

**Worked Example: Poisson MLE is a Maximum.** For the Poisson, :math:`\ell''(\lambda) = -\sum x_i / \lambda^2`. Since :math:`\sum x_i > 0` and :math:`\lambda > 0`, we have :math:`\ell''(\lambda) < 0` for all :math:`\lambda` — the log-likelihood is strictly concave, and the MLE is the unique global maximum.

.. code-block:: python

   import numpy as np

   rng = np.random.default_rng(42)

   n = 50
   lam_true = 3.5
   data = rng.poisson(lam_true, n)
   sum_x = int(np.sum(data))
   xbar = np.mean(data)

   print(f"Poisson log-likelihood analysis "
         f"(n={n}, Σxᵢ={sum_x}, x̄={xbar:.2f})")
   print(f"{'λ':>6}  {'ℓ(λ)':>12}  {'ℓ′(λ)':>12}  "
         f"{'ℓ″(λ)':>12}")
   print("-" * 48)
   for lam in [2.0, 2.5, 3.0, xbar, 3.5, 4.0, 4.5]:
       ll = sum_x * np.log(lam) - n * lam
       score = sum_x / lam - n
       d2 = -sum_x / lam**2
       print(f"{lam:>6.2f}  {ll:>12.4f}  {score:>12.4f}  "
             f"{d2:>12.4f}")

   print(f"\nAt MLE λ̂ = {xbar:.2f}:")
   print(f"  Score ℓ′({xbar:.2f}) = "
         f"{sum_x/xbar - n:.6f} (zero ✓)")
   print(f"  ℓ″({xbar:.2f}) = "
         f"{-sum_x/xbar**2:.4f} < 0 (maximum ✓)")
   print(f"  Observed information J({xbar:.2f}) = "
         f"{sum_x/xbar**2:.4f}")

Integration
-------------

Definite Integrals as Expectations
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   The **expected value** of :math:`g(X)` where :math:`X` has density :math:`f` is:

   .. math::

      \mathbb{E}[g(X)] = \int_{-\infty}^{\infty} g(x)\,f(x)\,dx

   Special cases: :math:`g(x) = x` gives the mean; :math:`g(x) = (x - \mu)^2` gives the variance; :math:`g(x) = e^{tx}` gives the MGF; :math:`g(x) = \mathbf{1}_{[a,b]}(x)` gives :math:`P(a \le X \le b)`.

**Intuition.** Every integral in this course is either a probability, an expectation, or a normalizing constant. Thinking of integrals as expectations unlocks a powerful verification strategy: if you can sample from :math:`f`, you can approximate any integral by averaging :math:`g(X_i)` over simulated draws. This is the **Monte Carlo method** developed in Chapter 2.

.. code-block:: python

   import numpy as np
   from scipy import stats
   from scipy.integrate import quad

   rng = np.random.default_rng(42)

   # Verify E[X²] for Gamma(α=3, β=2) three ways
   alpha, beta = 3.0, 2.0

   # Analytical: E[X²] = Var(X) + (E[X])² = α/β² + (α/β)²
   analytical = alpha / beta**2 + (alpha / beta)**2

   # scipy.integrate.quad
   integrand = lambda x: x**2 * stats.gamma.pdf(
       x, a=alpha, scale=1/beta)
   quad_result, _ = quad(integrand, 0, np.inf)

   # Monte Carlo
   samples = rng.gamma(alpha, 1/beta, 100000)
   mc_result = np.mean(samples**2)

   print("Verification: E[X²] for Gamma(α=3, β=2)")
   print(f"{'Method':>20}  {'E[X²]':>10}  "
         f"{'Error':>12}")
   print("-" * 48)
   print(f"{'Analytical':>20}  {analytical:>10.6f}  "
         f"{'—':>12}")
   print(f"{'scipy.integrate':>20}  {quad_result:>10.6f}  "
         f"{abs(quad_result - analytical):>12.2e}")
   print(f"{'Monte Carlo (n=10⁵)':>20}  {mc_result:>10.6f}  "
         f"{abs(mc_result - analytical):>12.2e}")

.. code-block:: text

   Verification: E[X²] for Gamma(α=3, β=2)
                 Method       E[X²]         Error
   ------------------------------------------------
             Analytical    3.000000             —
        scipy.integrate    3.000000      0.00e+00
    Monte Carlo (n=10⁵)    3.010147      1.01e-02

All three methods agree. The Monte Carlo estimate is within 0.3% of the exact value — typical for :math:`10^5` samples.


Integration by Parts
~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Integration by Parts
   :class: note

   .. math::

      \int u\,dv = uv - \int v\,du

   Equivalently, :math:`\int_a^b u(x) v'(x)\,dx = [u(x)v(x)]_a^b - \int_a^b u'(x) v(x)\,dx`.

**Intuition.** Integration by parts trades one integral for another. The art is choosing :math:`u` and :math:`dv` so that the new integral :math:`\int v\,du` is simpler than the original. In statistics, the typical pattern is: :math:`u = x^k` (a power that decreases when differentiated) and :math:`dv = e^{-\beta x} dx` (an exponential that stays exponential when integrated).

**Worked Example:** :math:`\mathbb{E}[X]` **for Gamma** :math:`(\alpha, \beta)` **via IBP.**

.. math::

   \mathbb{E}[X] = \int_0^\infty x \cdot \frac{\beta^\alpha}{\Gamma(\alpha)} x^{\alpha-1} e^{-\beta x}\,dx = \frac{\beta^\alpha}{\Gamma(\alpha)} \int_0^\infty x^\alpha e^{-\beta x}\,dx

Set :math:`u = x^\alpha` and :math:`dv = e^{-\beta x}\,dx`, giving :math:`du = \alpha x^{\alpha-1}\,dx` and :math:`v = -e^{-\beta x}/\beta`. The boundary term :math:`[uv]_0^\infty = 0`, since :math:`x^\alpha(-e^{-\beta x}/\beta) \to 0` at both limits: the exponential dominates as :math:`x \to \infty`, and :math:`x^\alpha \to 0` at :math:`x = 0` because :math:`\alpha > 0`. Then:

.. math::

   \int_0^\infty x^\alpha e^{-\beta x}\,dx = \frac{\alpha}{\beta} \int_0^\infty x^{\alpha-1} e^{-\beta x}\,dx = \frac{\alpha}{\beta} \cdot \frac{\Gamma(\alpha)}{\beta^\alpha}

Substituting back: :math:`\mathbb{E}[X] = \frac{\beta^\alpha}{\Gamma(\alpha)} \cdot \frac{\alpha}{\beta} \cdot \frac{\Gamma(\alpha)}{\beta^\alpha} = \frac{\alpha}{\beta}`.

.. code-block:: python

   import numpy as np

   rng = np.random.default_rng(42)

   alpha, beta = 3.0, 2.0
   n_samples = 100000
   samples = rng.gamma(alpha, 1/beta, n_samples)

   print(f"Verification: E[X] for Gamma(α={alpha}, β={beta})")
   print(f"Theoretical E[X] = α/β = {alpha/beta:.6f}")
   print(f"Simulated mean    = {np.mean(samples):.6f}")
   print(f"Difference        = "
         f"{abs(np.mean(samples) - alpha/beta):.6f}")

.. code-block:: text

   Verification: E[X] for Gamma(α=3.0, β=2.0)
   Theoretical E[X] = α/β = 1.500000
   Simulated mean    = 1.500859
   Difference        = 0.000859

**Brief second example:** For :math:`X \sim \text{Exp}(\lambda)`, :math:`\mathbb{E}[X] = \int_0^\infty x \lambda e^{-\lambda x}\,dx`. Setting :math:`u = x`, :math:`dv = \lambda e^{-\lambda x}\,dx` gives :math:`[uv]_0^\infty = 0` and :math:`\int_0^\infty e^{-\lambda x}\,dx = 1/\lambda`, so :math:`\mathbb{E}[X] = 1/\lambda`. This is the :math:`\alpha = 1` special case of the Gamma result above.


Change of Variables — Univariate
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Univariate Change of Variables
   :class: note

   If :math:`Y = g(X)` where :math:`g` is monotone and differentiable with inverse :math:`g^{-1}`, then:

   .. math::

      f_Y(y) = f_X(g^{-1}(y)) \cdot \left|\frac{d}{dy} g^{-1}(y)\right|

**Intuition.** Densities are not probabilities — they measure probability *per unit length*. When a transformation stretches the :math:`x`-axis, the same total probability is spread over a wider interval, so the density must decrease. The factor :math:`|dx/dy|` is the "stretching factor" that adjusts the density to preserve total probability. This is the univariate Jacobian.

**Worked Example: Inverse CDF Method for the Exponential.** Let :math:`U \sim \text{Uniform}(0, 1)` and define :math:`X = -\log(U)/\lambda`. Then :math:`g^{-1}(x) = e^{-\lambda x}` and :math:`|dg^{-1}/dx| = \lambda e^{-\lambda x}`, so:

.. math::

   f_X(x) = f_U(e^{-\lambda x}) \cdot \lambda e^{-\lambda x} = 1 \cdot \lambda e^{-\lambda x} = \lambda e^{-\lambda x}

for :math:`x > 0`, which is the :math:`\text{Exp}(\lambda)` density. This is the **inverse CDF method** — the foundation of simulation-based inference in :ref:`Chapter 2 <ch2.4-transformation-methods>`.

The multivariate analogue of this result uses the Jacobian determinant; see the Multiple Integrals section below.


Improper Integrals and Convergence
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

An **improper integral** :math:`\int_0^\infty f(x)\,dx` converges if :math:`\lim_{M \to \infty} \int_0^M f(x)\,dx` exists and is finite.

**Comparison test:** If :math:`0 \le f(x) \le g(x)` for all :math:`x \ge a` and :math:`\int_a^\infty g(x)\,dx` converges, then :math:`\int_a^\infty f(x)\,dx` converges.

**Statistical relevance.** Normalizing constants require convergent integrals: :math:`\int f(x; \theta)\,dx = 1`. Not all moments exist — the Cauchy distribution has no mean because :math:`\int |x|/(1+x^2)\,dx` diverges. Monte Carlo estimation of :math:`\mathbb{E}[g(X)]` requires finite :math:`\text{Var}(g(X))`; when this fails, variance reduction techniques (Chapter 2.5) are needed.


Taylor Series and Approximation
----------------------------------

Taylor's Theorem
~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Taylor's Theorem with Lagrange Remainder
   :class: note

   If :math:`f` has :math:`(n+1)` continuous derivatives on an interval containing :math:`a` and :math:`x`, then:

   .. math::

      f(x) = \sum_{k=0}^{n} \frac{f^{(k)}(a)}{k!}(x-a)^k + R_n(x)

   where the remainder satisfies :math:`R_n(x) = \frac{f^{(n+1)}(c)}{(n+1)!}(x-a)^{n+1}` for some :math:`c` between :math:`a` and :math:`x`.

**Intuition.** Taylor's theorem says any sufficiently smooth function is locally polynomial. The first-order Taylor polynomial is the tangent line; the second-order is the best-fit parabola; each additional term captures higher-order curvature. The remainder :math:`R_n` quantifies the approximation error, and its :math:`(x-a)^{n+1}` factor shows that accuracy improves rapidly close to the expansion point. For log-likelihoods near the MLE, the second-order Taylor approximation is a quadratic — and a quadratic in the exponent of :math:`L(\theta) = e^{\ell(\theta)}` produces a normal distribution.

.. admonition:: Definition
   :class: definition

   **Big-O and little-o notation.** We write :math:`f(x) = O(g(x))` as :math:`x \to a` if :math:`|f(x)| \le C|g(x)|` for some constant :math:`C` and all :math:`x` near :math:`a`. We write :math:`f(x) = o(g(x))` if :math:`f(x)/g(x) \to 0` as :math:`x \to a`. In Taylor expansions, :math:`R_n(x) = O((x-a)^{n+1})` means the error shrinks at least as fast as the :math:`(n+1)`-th power of the distance from :math:`a`.

.. code-block:: python

   import numpy as np

   def taylor_log1px(x, order):
       """Taylor polynomial of log(1+x) about x=0."""
       result = 0.0
       for k in range(1, order + 1):
           result += ((-1) ** (k + 1)) * x ** k / k
       return result

   print("Taylor approximations of log(1+x) at selected points")
   print(f"{'x':>6}  {'Exact':>10}  {'T₁':>10}  {'T₂':>10}  "
         f"{'T₃':>10}  {'T₄':>10}")
   print("-" * 62)
   for x in [0.1, 0.3, 0.5, 0.8, 1.0, 1.5]:
       exact = np.log(1 + x)
       vals = [taylor_log1px(x, k) for k in [1, 2, 3, 4]]
       print(f"{x:>6.1f}  {exact:>10.6f}  {vals[0]:>10.6f}  "
             f"{vals[1]:>10.6f}  {vals[2]:>10.6f}  "
             f"{vals[3]:>10.6f}")

   print("\nAbsolute errors |log(1+x) - Tₙ(x)|:")
   print(f"{'x':>6}  {'|E₁|':>10}  {'|E₂|':>10}  "
         f"{'|E₃|':>10}  {'|E₄|':>10}")
   print("-" * 46)
   for x in [0.1, 0.3, 0.5, 0.8, 1.0, 1.5]:
       exact = np.log(1 + x)
       errs = [abs(exact - taylor_log1px(x, k))
               for k in [1, 2, 3, 4]]
       print(f"{x:>6.1f}  {errs[0]:>10.2e}  {errs[1]:>10.2e}  "
             f"{errs[2]:>10.2e}  {errs[3]:>10.2e}")

First-Order Taylor: The Delta Method Connection
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: First-Order Taylor Approximation
   :class: note

   For a twice continuously differentiable function :math:`g` and a point :math:`a`:

   .. math::

      g(x) \approx g(a) + g'(a)(x - a)

   The error is :math:`O((x-a)^2)`.

**Statistical application: the delta method.** If :math:`\hat{\theta}` is close to :math:`\theta`, then:

.. math::

   g(\hat{\theta}) \approx g(\theta) + g'(\theta)(\hat{\theta} - \theta)

Taking variance of both sides (noting :math:`g(\theta)` is a constant):

.. math::

   \text{Var}(g(\hat{\theta})) \approx [g'(\theta)]^2 \,\text{Var}(\hat{\theta})

This is the **delta method** — proved rigorously as an asymptotic result in :ref:`Appendix E <appendix-statistical-inference>`, but the calculus it rests on is just first-order Taylor. The approximation improves as :math:`\hat{\theta} \to \theta` (i.e., as :math:`n \to \infty`).

**Worked Example: Variance-Stabilizing Transformation for Poisson.** If :math:`\bar{X} \sim \text{approx.\ } N(\lambda, \lambda/n)` (by CLT), what is the approximate distribution of :math:`\sqrt{\bar{X}}`? By the delta method with :math:`g(x) = \sqrt{x}` and :math:`g'(x) = 1/(2\sqrt{x})`:

.. math::

   \text{Var}(\sqrt{\bar{X}}) \approx \frac{1}{4\lambda} \cdot \frac{\lambda}{n} = \frac{1}{4n}

The variance no longer depends on :math:`\lambda` — this is a **variance-stabilizing transformation**. It is practically useful because standard errors for :math:`\sqrt{\hat{\lambda}}` do not require estimating :math:`\lambda`.

.. code-block:: python

   import numpy as np

   rng = np.random.default_rng(42)

   lam = 3.0
   n_reps = 50000

   print("Delta method: Var(√X̄) for Poisson(λ=3)")
   print(f"Theoretical: Var(√X̄) ≈ 1/(4n)")
   print(f"{'n':>6}  {'Var(√X̄) sim':>14}  {'1/(4n)':>10}  "
         f"{'Ratio':>8}")
   print("-" * 44)
   for n in [25, 100, 500]:
       sqrt_xbar = np.zeros(n_reps)
       for i in range(n_reps):
           sqrt_xbar[i] = np.sqrt(
               np.mean(rng.poisson(lam, n)))
       var_sim = np.var(sqrt_xbar)
       var_theory = 1.0 / (4 * n)
       print(f"{n:>6}  {var_sim:>14.6f}  {var_theory:>10.6f}  "
             f"{var_sim/var_theory:>8.4f}")

.. code-block:: text

Second-Order Taylor: Quadratic Likelihood Approximation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Second-Order Taylor Approximation
   :class: note

   For a three times continuously differentiable function :math:`f` and a point :math:`a`:

   .. math::

      f(x) \approx f(a) + f'(a)(x-a) + \frac{f''(a)}{2}(x-a)^2

   The error is :math:`O((x-a)^3)`.

**Statistical application: the quadratic log-likelihood.** At the MLE, :math:`\ell'(\hat{\theta}) = 0` by definition. The second-order Taylor expansion simplifies to:

.. math::

   \ell(\theta) \approx \ell(\hat{\theta}) + \frac{\ell''(\hat{\theta})}{2}(\theta - \hat{\theta})^2 = \ell(\hat{\theta}) - \frac{J(\hat{\theta})}{2}(\theta - \hat{\theta})^2

where :math:`J(\hat{\theta}) = -\ell''(\hat{\theta})` is the observed Fisher information. Exponentiating:

.. math::

   L(\theta) \approx L(\hat{\theta}) \exp\left\{-\frac{J(\hat{\theta})}{2}(\theta - \hat{\theta})^2\right\}

This is proportional to a normal density with mean :math:`\hat{\theta}` and variance :math:`1/J(\hat{\theta})`. This quadratic approximation is the origin of:

- **Asymptotic normality of MLEs:** :math:`\hat{\theta} \sim \text{approx.\ } N(\theta, 1/J(\hat{\theta}))` (proved in Appendix E)
- **Wald confidence intervals:** :math:`\hat{\theta} \pm z_{\alpha/2}/\sqrt{J(\hat{\theta})}`
- **Newton-Raphson optimization:** each step minimizes the local quadratic (Appendix C)

**The Wald statistic.** The Wald test statistic :math:`W = J(\hat{\theta})(\hat{\theta} - \theta_0)^2` measures how far :math:`\theta_0` is from :math:`\hat{\theta}` in units of curvature. Under the quadratic approximation, :math:`W \approx 2[\ell(\hat{\theta}) - \ell(\theta_0)]` — the Wald and likelihood ratio statistics agree to second order.

.. code-block:: python

   import numpy as np
   from scipy.special import gammaln
   from scipy.optimize import minimize_scalar

   rng = np.random.default_rng(42)

   n = 50
   alpha_true, beta_true = 4.0, 2.0
   data = rng.gamma(alpha_true, 1/beta_true, n)
   xbar = np.mean(data)

   def profile_loglik(alpha):
       if alpha <= 0:
           return -1e20
       beta = alpha / xbar
       return (n * (alpha * np.log(beta) - gammaln(alpha))
               + (alpha - 1) * np.sum(np.log(data))
               - beta * np.sum(data))

   result = minimize_scalar(lambda a: -profile_loglik(a),
                            bounds=(0.5, 20), method='bounded')
   alpha_hat = result.x
   ll_max = profile_loglik(alpha_hat)

   # Observed information (numerical second derivative)
   eps = 1e-5
   J_obs = -(profile_loglik(alpha_hat + eps)
             - 2 * profile_loglik(alpha_hat)
             + profile_loglik(alpha_hat - eps)) / eps**2

   print(f"Profile log-likelihood: Gamma data (n={n})")
   print(f"MLE: α̂ = {alpha_hat:.4f}, J(α̂) = {J_obs:.4f}")
   print()
   print(f"{'α':>8}  {'ℓ(α) exact':>12}  {'ℓ(α) quad':>12}  "
         f"{'Difference':>12}")
   print("-" * 50)
   for da in [-1.5, -1.0, -0.5, 0, 0.5, 1.0, 1.5]:
       alpha = alpha_hat + da
       if alpha <= 0:
           continue
       ll_exact = profile_loglik(alpha)
       ll_quad = ll_max - 0.5 * J_obs * da**2
       print(f"{alpha:>8.2f}  {ll_exact:>12.4f}  "
             f"{ll_quad:>12.4f}  "
             f"{abs(ll_exact - ll_quad):>12.4f}")

Convergence of Taylor Series
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   The **radius of convergence** :math:`R` of the Taylor series :math:`\sum_{k=0}^\infty a_k (x-a)^k` is the largest :math:`R` such that the series converges for :math:`|x - a| < R` and diverges for :math:`|x - a| > R`.

Not all Taylor series converge everywhere. The series for :math:`\log(1+x)` converges exactly for :math:`-1 < x \le 1` (with conditional convergence at :math:`x = 1` and divergence at :math:`x = -1`). The series for :math:`e^x` converges for all :math:`x`. The Cauchy distribution's density :math:`1/(\pi(1+x^2))` has a Taylor series with radius of convergence 1, despite the function being defined everywhere.

**Statistical relevance.** The quadratic log-likelihood approximation can fail when:

- The log-likelihood has a **flat region** (e.g., near-collinear predictors in regression produce a nearly flat ridge)
- The parameter is near a **boundary** (e.g., :math:`p` near 0 or 1 in a Bernoulli model — the Wald CI can extend outside [0, 1])
- The log-likelihood has **multiple modes** (mixture models — see the Convexity section below)

These failures motivate profile likelihood (exact) and bootstrap (nonparametric) as alternatives to Wald-based inference.


Leibniz Rule and Differentiation Under the Integral
------------------------------------------------------

Statement and Regularity Conditions
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Leibniz Integral Rule
   :class: note

   **General form.** If :math:`a(\theta)`, :math:`b(\theta)` are differentiable and :math:`\frac{\partial f}{\partial \theta}` is continuous, then:

   .. math::

      \frac{d}{d\theta} \int_{a(\theta)}^{b(\theta)} f(x, \theta)\,dx = f(b(\theta), \theta)\,b'(\theta) - f(a(\theta), \theta)\,a'(\theta) + \int_{a(\theta)}^{b(\theta)} \frac{\partial f}{\partial \theta}(x, \theta)\,dx

   **Special case (fixed limits).** When the limits do not depend on :math:`\theta`:

   .. math::

      \frac{d}{d\theta} \int_a^b f(x, \theta)\,dx = \int_a^b \frac{\partial}{\partial \theta} f(x, \theta)\,dx

   This interchange of differentiation and integration is valid when :math:`\frac{\partial f}{\partial \theta}` is continuous and dominated by an integrable function (the **dominated convergence theorem**).

**Regularity conditions.** We cannot always interchange :math:`d/d\theta` and :math:`\int`. The standard conditions that ensure validity are:

1. The **support** of :math:`f(x; \theta)` does not depend on :math:`\theta`. This excludes families like :math:`\text{Uniform}(0, \theta)` where the upper bound is the parameter.
2. :math:`f(x; \theta)` is **differentiable** in :math:`\theta` for almost all :math:`x`.
3. There exists a **dominating function** :math:`g(x)` with :math:`\int g(x)\,dx < \infty` such that :math:`|\frac{\partial}{\partial \theta} f(x; \theta)| \le g(x)` for all :math:`\theta`.

These conditions are satisfied by all standard exponential family distributions. They are formalized as regularity conditions R4–R6 in :ref:`Appendix E <appendix-e-regularity-conditions>`.


Application: The Score Has Mean Zero
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: :math:`\mathbb{E}[U(\theta)] = 0`
   :class: note

   Under the regularity conditions above, the score function :math:`U(\theta) = \frac{d}{d\theta} \log f(X; \theta)` satisfies :math:`\mathbb{E}_\theta[U(\theta)] = 0`.

.. admonition:: Derivation
   :class: note

   Start from the normalization identity: :math:`\int f(x; \theta)\,dx = 1` for all :math:`\theta`.

   **Step 1.** Differentiate both sides with respect to :math:`\theta`. The right side gives :math:`0`. On the left, Leibniz (with fixed limits :math:`-\infty` to :math:`\infty`) lets us move :math:`d/d\theta` inside the integral:

   .. math::

      0 = \frac{d}{d\theta} \int f(x; \theta)\,dx = \int \frac{\partial}{\partial \theta} f(x; \theta)\,dx

   **Step 2.** Use the logarithmic derivative identity :math:`\frac{\partial f}{\partial \theta} = f \cdot \frac{\partial \log f}{\partial \theta}`:

   .. math::

      0 = \int \frac{\partial \log f(x; \theta)}{\partial \theta} \cdot f(x; \theta)\,dx = \mathbb{E}\left[\frac{\partial}{\partial \theta} \log f(X; \theta)\right] = \mathbb{E}[U(\theta)]

**Intuition.** The score has mean zero because the total probability must always integrate to 1, regardless of :math:`\theta`. When we differentiate this constraint, we get a restriction on the score's expectation. This is not a property of any particular estimator — it is a property of the *model* itself. It means the score function is "centered," which is what makes the CLT apply to :math:`\sum U_i(\theta)/\sqrt{n}` and ultimately yields the asymptotic normality of the MLE.

.. code-block:: python

   import numpy as np

   rng = np.random.default_rng(42)

   n = 100000
   mu_true = 5.0
   sigma2 = 4.0
   data = rng.normal(mu_true, np.sqrt(sigma2), n)

   print("Score function: Normal(μ, σ²=4)")
   print(f"n = {n:,}")
   print()
   print(f"{'μ':>8}  {'E[U(μ)] theory':>16}  "
         f"{'Mean U(μ) sim':>16}")
   print("-" * 46)
   for mu in [3.0, 4.0, 5.0, 6.0, 7.0]:
       scores = (data - mu) / sigma2
       mean_score = np.mean(scores)
       theory = (mu_true - mu) / sigma2
       print(f"{mu:>8.1f}  {theory:>16.6f}  "
             f"{mean_score:>16.6f}")

   print(f"\nAt true μ = {mu_true}: E[U(μ)] = 0 ✓")
   print(f"At μ ≠ {mu_true}: E[U(μ)] ≠ 0 — score has "
         f"nonzero expectation")

Application: Fisher Information Equivalence
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The same Leibniz trick, applied a second time, yields the equivalence of the two forms of Fisher information. The calculus is as follows — the full statistical interpretation is in :ref:`Appendix E <appendix-statistical-inference>`.

.. admonition:: Derivation: Information Equality
   :class: note

   Start from :math:`\mathbb{E}[U(\theta)] = 0`, i.e., :math:`\int U(\theta)\,f(x; \theta)\,dx = 0`.

   Differentiate with respect to :math:`\theta` using the product rule inside the integral (justified by Leibniz/dominated convergence):

   .. math::

      0 = \int \left[\frac{\partial U}{\partial \theta} \cdot f + U \cdot \frac{\partial f}{\partial \theta}\right] dx = \int \left[\ell''(\theta) + U(\theta)^2\right] f\,dx

   where we used :math:`\frac{\partial f}{\partial \theta} = f \cdot U(\theta)` (the logarithmic derivative identity again). Therefore:

   .. math::

      \mathbb{E}[\ell''(\theta)] + \mathbb{E}[U(\theta)^2] = 0

   Since :math:`\mathbb{E}[U] = 0`, we have :math:`\mathbb{E}[U^2] = \text{Var}(U)`. Thus :math:`\text{Var}(U(\theta)) = -\mathbb{E}[\ell''(\theta)]`: the variance of the score equals the negative expected second derivative of the log-likelihood. Both quantities equal the **per-observation Fisher information** :math:`I_1(\theta)`, where the subscript 1 indicates information from a single observation (an iid sample of size :math:`n` has total information :math:`n I_1(\theta)`).

.. code-block:: python

   import numpy as np

   rng = np.random.default_rng(42)

   lam_true = 2.0
   n_samples = 100000

   # Exp(lambda): score U = 1/lambda - X
   # l''(lambda) = -1/lambda^2
   # I_1 = 1/lambda^2
   samples = rng.exponential(1/lam_true, n_samples)
   scores = 1/lam_true - samples

   var_score = np.var(scores)
   neg_E_lpp = 1 / lam_true**2

   print(f"Fisher information equivalence: Exp(λ={lam_true})")
   print(f"Analytical I₁(λ) = 1/λ² = {neg_E_lpp:.6f}")
   print()
   print(f"Form 1: Var(U) from {n_samples:,} samples")
   print(f"  Var(U) = {var_score:.6f}")
   print()
   print(f"Form 2: -E[ℓ″(λ)] = 1/λ²")
   print(f"  -E[ℓ″] = {neg_E_lpp:.6f}")
   print()
   print(f"Ratio Var(U) / (-E[ℓ″]) = "
         f"{var_score/neg_E_lpp:.6f}")

.. code-block:: text

   Fisher information equivalence: Exp(λ=2.0)
   Analytical I₁(λ) = 1/λ² = 0.250000

   Form 1: Var(U) from 100,000 samples
     Var(U) = 0.252651

   Form 2: -E[ℓ″(λ)] = 1/λ²
     -E[ℓ″] = 0.250000

   Ratio Var(U) / (-E[ℓ″]) = 1.010606

The ratio is within 1% of 1.0 — the small deviation is simulation noise. Both forms of Fisher information give the same answer, confirming the calculus-based derivation above.


Multivariate Differential Calculus
-------------------------------------

Partial Derivatives and the Gradient
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   For :math:`f: \mathbb{R}^p \to \mathbb{R}`, the **partial derivative** :math:`\frac{\partial f}{\partial \theta_j}` is the derivative of :math:`f` with respect to :math:`\theta_j`, holding all other variables fixed.

.. admonition:: Definition
   :class: definition

   The **gradient** of :math:`f` at :math:`\boldsymbol{\theta}` is the column vector of partial derivatives:

   .. math::

      \nabla f(\boldsymbol{\theta}) = \left(\frac{\partial f}{\partial \theta_1}, \ldots, \frac{\partial f}{\partial \theta_p}\right)^\top

**Intuition.** The gradient generalizes the derivative to higher dimensions. It points in the direction of steepest ascent of :math:`f`, and its magnitude gives the rate of increase in that direction. Setting :math:`\nabla f = \mathbf{0}` is the multivariate analogue of setting :math:`f' = 0` — it finds critical points. In MLE, the **score vector** :math:`\mathbf{U}(\boldsymbol{\theta}) = \nabla \ell(\boldsymbol{\theta})` is the gradient of the log-likelihood, and solving :math:`\mathbf{U}(\hat{\boldsymbol{\theta}}) = \mathbf{0}` gives the MLE.

**Worked Example: Score Vector for Normal** :math:`(\mu, \sigma^2)`. The log-likelihood is:

.. math::

   \ell(\mu, \sigma^2) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^n (x_i - \mu)^2

The score vector has two components:

.. math::

   \frac{\partial \ell}{\partial \mu} = \frac{1}{\sigma^2}\sum(x_i - \mu) = \frac{n(\bar{X} - \mu)}{\sigma^2}, \qquad \frac{\partial \ell}{\partial \sigma^2} = -\frac{n}{2\sigma^2} + \frac{\sum(x_i - \mu)^2}{2(\sigma^2)^2}

Setting both to zero gives :math:`\hat{\mu} = \bar{X}` and :math:`\hat{\sigma}^2 = \frac{1}{n}\sum(x_i - \bar{X})^2`.

For matrix-specific gradient identities (:math:`\nabla_{\boldsymbol{\beta}}(\mathbf{y} - \mathbf{X}\boldsymbol{\beta})^\top(\mathbf{y} - \mathbf{X}\boldsymbol{\beta})`, :math:`\nabla_{\mathbf{x}} \mathbf{x}^\top \mathbf{A} \mathbf{x}`, etc.), see :ref:`Appendix B <appendix-linear-algebra>`.


The Hessian Matrix
~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   The **Hessian matrix** of :math:`f: \mathbb{R}^p \to \mathbb{R}` is the :math:`p \times p` matrix of second partial derivatives:

   .. math::

      \mathbf{H}(\boldsymbol{\theta}) = \begin{pmatrix} \frac{\partial^2 f}{\partial \theta_1^2} & \cdots & \frac{\partial^2 f}{\partial \theta_1 \partial \theta_p} \\ \vdots & \ddots & \vdots \\ \frac{\partial^2 f}{\partial \theta_p \partial \theta_1} & \cdots & \frac{\partial^2 f}{\partial \theta_p^2} \end{pmatrix}

   By **Clairaut's theorem**, if the second partial derivatives are continuous, then :math:`\frac{\partial^2 f}{\partial \theta_i \partial \theta_j} = \frac{\partial^2 f}{\partial \theta_j \partial \theta_i}`, so :math:`\mathbf{H}` is symmetric.

**Connection to observed information.** In MLE, the observed Fisher information matrix is :math:`\mathbf{J}(\hat{\boldsymbol{\theta}}) = -\mathbf{H}_\ell(\hat{\boldsymbol{\theta}})` — the negated Hessian of the log-likelihood at the MLE. Its inverse :math:`\mathbf{J}^{-1}` estimates the covariance matrix of :math:`\hat{\boldsymbol{\theta}}`.

.. code-block:: python

   import numpy as np

   rng = np.random.default_rng(42)

   n = 100
   mu_true, sigma2_true = 5.0, 4.0
   data = rng.normal(mu_true, np.sqrt(sigma2_true), n)

   mu_hat = np.mean(data)
   sigma2_hat = np.var(data)

   def normal_loglik(params):
       mu, s2 = params
       if s2 <= 0:
           return -1e20
       return (-n/2 * np.log(2*np.pi*s2)
               - np.sum((data - mu)**2) / (2*s2))

   # Analytical Hessian at MLE
   H11 = -n / sigma2_hat
   H12 = 0.0
   H22 = -n / (2 * sigma2_hat**2)

   # Numerical Hessian
   eps = 1e-5
   theta_hat = np.array([mu_hat, sigma2_hat])
   H_num = np.zeros((2, 2))
   for i in range(2):
       for j in range(2):
           e_i = np.zeros(2); e_i[i] = eps
           e_j = np.zeros(2); e_j[j] = eps
           H_num[i,j] = (
               normal_loglik(theta_hat + e_i + e_j)
               - normal_loglik(theta_hat + e_i - e_j)
               - normal_loglik(theta_hat - e_i + e_j)
               + normal_loglik(theta_hat - e_i - e_j)
           ) / (4 * eps**2)

   J = -np.array([[H11, H12], [H12, H22]])
   cov_hat = np.linalg.inv(J)

   print(f"Hessian of Normal log-likelihood (n={n})")
   print(f"MLE: μ̂={mu_hat:.4f}, σ̂²={sigma2_hat:.4f}")
   print()
   print("Analytical Hessian:")
   print(f"  H₁₁ = -n/σ̂²    = {H11:.4f}")
   print(f"  H₁₂ = 0         = {H12:.4f}")
   print(f"  H₂₂ = -n/(2σ̂⁴) = {H22:.4f}")
   print()
   print("Numerical Hessian:")
   print(f"  H₁₁ = {H_num[0,0]:.4f}")
   print(f"  H₁₂ = {H_num[0,1]:.4f}")
   print(f"  H₂₂ = {H_num[1,1]:.4f}")
   print()
   print("Estimated covariance (-H)⁻¹:")
   print(f"  Var(μ̂)  = {cov_hat[0,0]:.6f}  "
         f"(theory: {sigma2_hat/n:.6f})")
   print(f"  Var(σ̂²) = {cov_hat[1,1]:.6f}  "
         f"(theory: {2*sigma2_hat**2/n:.6f})")
   print(f"  Cov      = {cov_hat[0,1]:.6f}  (theory: 0)")

.. code-block:: text

   MLE: μ̂=4.8995, σ̂²=2.3888

   Analytical Hessian:
     H₁₁ = -n/σ̂²    = -41.8624
     H₁₂ = 0         = 0.0000
     H₂₂ = -n/(2σ̂⁴) = -8.7623

The Multivariate Chain Rule
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Multivariate Chain Rule
   :class: note

   If :math:`f: \mathbb{R}^p \to \mathbb{R}` and :math:`\mathbf{g}: \mathbb{R}^q \to \mathbb{R}^p` are differentiable, then:

   .. math::

      \nabla_{\mathbf{x}} f(\mathbf{g}(\mathbf{x})) = \mathbf{J}_g(\mathbf{x})^\top \nabla_{\mathbf{z}} f(\mathbf{z})\big|_{\mathbf{z} = \mathbf{g}(\mathbf{x})}

   where :math:`\mathbf{J}_g` is the :math:`p \times q` Jacobian matrix of :math:`\mathbf{g}` (the Jacobian matrix is defined formally in the Multiple Integrals section below).

**Statistical application: GLM score vectors.** In a generalized linear model, the log-likelihood depends on :math:`\boldsymbol{\beta}` through the composition :math:`\boldsymbol{\eta} = \mathbf{X}\boldsymbol{\beta} \to \boldsymbol{\mu} = g^{-1}(\boldsymbol{\eta}) \to \ell(\boldsymbol{\mu})`. The chain rule produces:

.. math::

   \frac{\partial \ell}{\partial \boldsymbol{\beta}} = \mathbf{X}^\top \text{diag}\left(\frac{d\mu_i}{d\eta_i}\right) \text{diag}\left(\frac{1}{V(\mu_i)}\right) (\mathbf{y} - \boldsymbol{\mu})

This is the score vector for the GLM. The chain rule is what generates the weight matrix :math:`\mathbf{W}` in the IRLS algorithm (:ref:`Ch3.5 <ch3_5-generalized-linear-models>`).

For the derivation of specific matrix-vector gradient identities used in linear models, see :ref:`Appendix B <appendix-linear-algebra>`.


Second-Order Conditions
~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Multivariate Second Derivative Test
   :class: note

   At a critical point :math:`\boldsymbol{\theta}^*` where :math:`\nabla f = \mathbf{0}`:

   - :math:`\mathbf{H}` positive definite :math:`\Rightarrow` local minimum
   - :math:`\mathbf{H}` negative definite :math:`\Rightarrow` local maximum
   - :math:`\mathbf{H}` indefinite (has both positive and negative eigenvalues) :math:`\Rightarrow` saddle point

**Intuition.** The eigenvalues of :math:`\mathbf{H}` are the curvatures along the principal directions of :math:`f`. Positive definite means all curvatures are positive (bowl shape); negative definite means all curvatures are negative (dome shape). For log-likelihoods, a negative definite Hessian at :math:`\hat{\boldsymbol{\theta}}` confirms a local maximum. If the log-likelihood is *globally* concave (negative semi-definite Hessian everywhere), the local maximum is the global maximum.

**The implicit function theorem** (brief statement). If :math:`\mathbf{F}(\mathbf{x}, \mathbf{y}) = \mathbf{0}` defines :math:`\mathbf{y}` implicitly as a function of :math:`\mathbf{x}`, and :math:`\frac{\partial \mathbf{F}}{\partial \mathbf{y}}` is invertible, then locally :math:`\frac{d\mathbf{y}}{d\mathbf{x}} = -\left(\frac{\partial \mathbf{F}}{\partial \mathbf{y}}\right)^{-1} \frac{\partial \mathbf{F}}{\partial \mathbf{x}}`. This is used in profile likelihood: fixing one parameter and maximizing over others implicitly defines the nuisance MLEs as functions of the parameter of interest.


Convexity and Optimization
-----------------------------

Convex Sets and Functions
~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   A set :math:`C \subseteq \mathbb{R}^p` is **convex** if for all :math:`\mathbf{x}, \mathbf{y} \in C` and :math:`t \in [0, 1]`:

   .. math::

      t\mathbf{x} + (1-t)\mathbf{y} \in C

.. admonition:: Definition
   :class: definition

   A function :math:`f: C \to \mathbb{R}` defined on a convex set :math:`C` is:

   - **Convex** if :math:`f(t\mathbf{x} + (1-t)\mathbf{y}) \le t\,f(\mathbf{x}) + (1-t)\,f(\mathbf{y})` for all :math:`\mathbf{x}, \mathbf{y} \in C` and :math:`t \in [0, 1]`
   - **Strictly convex** if the inequality is strict for :math:`t \in (0, 1)` and :math:`\mathbf{x} \ne \mathbf{y}`
   - **Concave** if :math:`-f` is convex; **strictly concave** if :math:`-f` is strictly convex

**Intuition.** A convex function lies below every chord connecting two points on its graph — equivalently, the region above the graph is a convex set. A concave function lies above every chord. For log-likelihoods, **concavity** is the desirable property: a concave log-likelihood has a unique global maximum (no local traps), and gradient-based optimizers are guaranteed to find it.


Hessian Characterization of Convexity
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Second-Order Characterization
   :class: note

   For a twice continuously differentiable function :math:`f: \mathbb{R}^p \to \mathbb{R}`:

   - :math:`f` is convex :math:`\Leftrightarrow` :math:`\mathbf{H}(\mathbf{x})` is positive semi-definite for all :math:`\mathbf{x}`
   - :math:`\mathbf{H}(\mathbf{x})` positive definite for all :math:`\mathbf{x}` :math:`\Rightarrow` :math:`f` is strictly convex (sufficient but not necessary)
   - :math:`f` is concave :math:`\Leftrightarrow` :math:`\mathbf{H}(\mathbf{x})` is negative semi-definite for all :math:`\mathbf{x}`

.. admonition:: Derivation (sketch)
   :class: note

   The second-order Taylor expansion gives :math:`f(\mathbf{y}) = f(\mathbf{x}) + \nabla f(\mathbf{x})^\top(\mathbf{y}-\mathbf{x}) + \frac{1}{2}(\mathbf{y}-\mathbf{x})^\top \mathbf{H}(\mathbf{c})(\mathbf{y}-\mathbf{x})` for some :math:`\mathbf{c}`. If :math:`\mathbf{H}` is PSD everywhere, the quadratic term is :math:`\ge 0`, so :math:`f(\mathbf{y}) \ge f(\mathbf{x}) + \nabla f(\mathbf{x})^\top(\mathbf{y}-\mathbf{x})`, which is the first-order characterization of convexity.

**Key consequence.** If :math:`\ell(\boldsymbol{\theta})` is concave (Hessian NSD everywhere), then any critical point is a global maximum. There are no local maxima to be trapped in, and the MLE (if it exists) is unique.


Convexity and Exponential Families
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Concavity of Exponential Family Log-Likelihoods
   :class: note

   For a regular exponential family in natural form, the log-likelihood :math:`\ell(\boldsymbol{\eta}) = \boldsymbol{\eta}^\top \mathbf{T}(\mathbf{x}) - nA(\boldsymbol{\eta})` is concave in the natural parameter :math:`\boldsymbol{\eta}`, because :math:`\nabla^2 A(\boldsymbol{\eta}) = \text{Cov}(\mathbf{T}(X))` is positive semi-definite (as a covariance matrix), so :math:`-\nabla^2 \ell = n\nabla^2 A` is PSD.

**Consequence.** MLEs for exponential families are unique (when they exist in the interior of the parameter space). This is why Newton-Raphson converges reliably for exponential family models — the log-likelihood surface has no local traps.

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # Normal model: concave (unique max)
   n = 50
   data_normal = rng.normal(3.0, 1.0, n)
   mu_hat = np.mean(data_normal)

   print("Log-likelihood shape comparison")
   print()
   print(f"Normal model: n={n}, μ̂={mu_hat:.4f}")
   print(f"  ℓ″(μ) = -n/σ² = {-n/1.0:.1f} < 0 for all μ "
         f"(concave ✓)")
   print(f"  Unique global maximum at μ̂ = x̄")
   print()

   # Symmetric mixture: NOT concave (two maxima)
   n_mix = 50
   mix_data = np.concatenate([
       rng.normal(-3, 0.5, n_mix // 2),
       rng.normal(3, 0.5, n_mix // 2)])

   def mixture_ll(mu):
       ld1 = stats.norm.logpdf(mix_data, -mu, 0.5)
       ld2 = stats.norm.logpdf(mix_data, mu, 0.5)
       mx = np.maximum(ld1, ld2)
       return np.sum(mx + np.log(
           0.5*np.exp(ld1 - mx) + 0.5*np.exp(ld2 - mx)))

   mu_grid = np.linspace(-5, 5, 1000)
   ll_vals = np.array([mixture_ll(mu) for mu in mu_grid])
   local_max = [(mu_grid[i], ll_vals[i])
                for i in range(1, len(ll_vals)-1)
                if ll_vals[i] > ll_vals[i-1]
                and ll_vals[i] > ll_vals[i+1]]

   print(f"Mixture: f(x|μ) = 0.5 N(-μ, 0.25) "
         f"+ 0.5 N(μ, 0.25)")
   print(f"  {len(local_max)} local maxima found:")
   for mu, ll in local_max:
       print(f"    μ = {mu:+.2f}, ℓ(μ) = {ll:.2f}")
   print(f"  NOT concave — Newton-Raphson may converge")
   print(f"  to different modes depending on initialization.")

Strict Convexity and Unique Optimization
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem
   :class: note

   If :math:`f` is strictly convex on a convex set :math:`C`, then :math:`f` has at most one minimizer. If :math:`C` is also closed and :math:`f(\mathbf{x}) \to \infty` as :math:`\|\mathbf{x}\| \to \infty`, then :math:`f` has exactly one minimizer.

**Statistical corollary.** For exponential families with full-rank sufficient statistics, the negative log-likelihood is strictly convex, so the MLE is unique. When the sufficient statistic lies on the boundary of the convex support (e.g., all observations identical in a Bernoulli model with all successes), the MLE may be on the boundary of the parameter space.


Multivariate Taylor Expansion
-------------------------------

The Multivariate Taylor Formula
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Second-Order Multivariate Taylor Expansion
   :class: note

   For :math:`f: \mathbb{R}^p \to \mathbb{R}` three times continuously differentiable:

   .. math::

      f(\boldsymbol{\theta} + \boldsymbol{\delta}) = f(\boldsymbol{\theta}) + \nabla f(\boldsymbol{\theta})^\top \boldsymbol{\delta} + \frac{1}{2}\boldsymbol{\delta}^\top \mathbf{H}(\boldsymbol{\theta})\boldsymbol{\delta} + O(\|\boldsymbol{\delta}\|^3)

.. admonition:: Derivation
   :class: note

   Define :math:`\varphi(t) = f(\boldsymbol{\theta} + t\boldsymbol{\delta})`. By the univariate Taylor theorem:

   .. math::

      \varphi(1) = \varphi(0) + \varphi'(0) + \frac{1}{2}\varphi''(0) + R, \qquad R = \frac{\varphi'''(\xi)}{6} \text{ for some } \xi \in (0, 1)

   Computing: :math:`\varphi'(t) = \nabla f(\boldsymbol{\theta} + t\boldsymbol{\delta})^\top \boldsymbol{\delta}` and :math:`\varphi''(t) = \boldsymbol{\delta}^\top \mathbf{H}(\boldsymbol{\theta} + t\boldsymbol{\delta})\boldsymbol{\delta}`. Setting :math:`t = 0` gives the result; since :math:`\varphi'''` contracts the third derivatives of :math:`f` with :math:`\boldsymbol{\delta}` three times, :math:`R = O(\|\boldsymbol{\delta}\|^3)`.

**Statistical interpretation.** At the MLE :math:`\hat{\boldsymbol{\theta}}`, :math:`\nabla \ell(\hat{\boldsymbol{\theta}}) = \mathbf{0}`, so the expansion simplifies to:

.. math::

   \ell(\boldsymbol{\theta}) \approx \ell(\hat{\boldsymbol{\theta}}) - \frac{1}{2}(\boldsymbol{\theta} - \hat{\boldsymbol{\theta}})^\top \mathbf{J}(\hat{\boldsymbol{\theta}})(\boldsymbol{\theta} - \hat{\boldsymbol{\theta}})

where :math:`\mathbf{J} = -\mathbf{H}_\ell`. Exponentiating: :math:`L(\boldsymbol{\theta}) \propto \exp\{-\frac{1}{2}(\boldsymbol{\theta} - \hat{\boldsymbol{\theta}})^\top \mathbf{J}(\boldsymbol{\theta} - \hat{\boldsymbol{\theta}})\}`, which is a multivariate normal density with mean :math:`\hat{\boldsymbol{\theta}}` and covariance :math:`\mathbf{J}^{-1}` — exactly as in the univariate case (see the Taylor Series section above).


The Wald Statistic
~~~~~~~~~~~~~~~~~~~~

The multivariate Wald test statistic for :math:`H_0: \boldsymbol{\theta} = \boldsymbol{\theta}_0` is:

.. math::

   W = (\hat{\boldsymbol{\theta}} - \boldsymbol{\theta}_0)^\top \mathbf{J}(\hat{\boldsymbol{\theta}})(\hat{\boldsymbol{\theta}} - \boldsymbol{\theta}_0)

Under :math:`H_0` and asymptotic normality, :math:`W \sim \chi^2_p`. This is a direct consequence of the multivariate Taylor expansion: :math:`W` approximates :math:`2[\ell(\hat{\boldsymbol{\theta}}) - \ell(\boldsymbol{\theta}_0)]`. The complete asymptotic theory is in :ref:`Appendix E <appendix-statistical-inference>`.

.. code-block:: python

   import numpy as np

   rng = np.random.default_rng(42)

   n = 50
   mu_true, sigma2_true = 5.0, 4.0
   data = rng.normal(mu_true, np.sqrt(sigma2_true), n)

   mu_hat = np.mean(data)
   sigma2_hat = np.var(data)

   def normal_ll(mu, s2):
       return (-n/2 * np.log(2*np.pi*s2)
               - np.sum((data - mu)**2) / (2*s2))

   ll_max = normal_ll(mu_hat, sigma2_hat)

   # Observed information at MLE
   J11 = n / sigma2_hat
   J22 = n / (2 * sigma2_hat**2)
   J = np.array([[J11, 0], [0, J22]])

   print(f"Multivariate Taylor: Normal(μ, σ²) (n={n})")
   print(f"MLE: μ̂={mu_hat:.4f}, σ̂²={sigma2_hat:.4f}")
   print()
   print(f"{'(μ₀, σ²₀)':>20}  {'ℓ exact':>10}  "
         f"{'ℓ quad':>10}  {'Diff':>8}")
   print("-" * 54)
   for mu0, s20 in [(mu_hat, sigma2_hat),
                     (mu_hat+0.5, sigma2_hat),
                     (mu_hat, sigma2_hat+1),
                     (mu_hat+0.5, sigma2_hat+1),
                     (mu_hat+1.0, sigma2_hat+2)]:
       ll_ex = normal_ll(mu0, s20)
       d = np.array([mu0 - mu_hat, s20 - sigma2_hat])
       ll_qd = ll_max - 0.5 * d @ J @ d
       print(f"  ({mu0:.2f}, {s20:.2f})"
             f"  {ll_ex:>10.4f}  {ll_qd:>10.4f}  "
             f"{abs(ll_ex - ll_qd):>8.4f}")

Multiple Integrals and Change of Variables
--------------------------------------------

Multiple Integrals
~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   The **double integral** of :math:`f` over a region :math:`D \subseteq \mathbb{R}^2` is :math:`\iint_D f(x,y)\,dA`. **Fubini's theorem** (stated without proof): if :math:`f` is integrable over the rectangle :math:`[a,b] \times [c,d]`, then:

   .. math::

      \iint f(x,y)\,dA = \int_a^b \left[\int_c^d f(x,y)\,dy\right]dx = \int_c^d \left[\int_a^b f(x,y)\,dx\right]dy

**Statistical application.** Marginal distributions require integrating out variables: :math:`f_X(x) = \int f_{X,Y}(x,y)\,dy`. Normalizing constants for multivariate densities require evaluating :math:`\int \cdots \int f(\mathbf{x}; \boldsymbol{\theta})\,d\mathbf{x} = 1`. When these integrals lack closed forms, Monte Carlo methods (Chapter 2) provide numerical approximations.


The Jacobian Determinant
~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   For a transformation :math:`\mathbf{g}: \mathbb{R}^p \to \mathbb{R}^p`, the **Jacobian matrix** is:

   .. math::

      \mathbf{J}_g(\mathbf{x}) = \begin{pmatrix} \frac{\partial g_1}{\partial x_1} & \cdots & \frac{\partial g_1}{\partial x_p} \\ \vdots & \ddots & \vdots \\ \frac{\partial g_p}{\partial x_1} & \cdots & \frac{\partial g_p}{\partial x_p} \end{pmatrix}

   The **Jacobian determinant** is :math:`\det(\mathbf{J}_g)`.

.. admonition:: Theorem: Multivariate Change of Variables
   :class: note

   If :math:`\mathbf{Y} = \mathbf{g}(\mathbf{X})` where :math:`\mathbf{g}` is a diffeomorphism (a smooth bijection with smooth inverse), then:

   .. math::

      f_{\mathbf{Y}}(\mathbf{y}) = f_{\mathbf{X}}(\mathbf{g}^{-1}(\mathbf{y})) \cdot \left|\det \mathbf{J}_{g^{-1}}(\mathbf{y})\right|

**Intuition.** The Jacobian determinant measures how the transformation stretches or compresses volume locally. A large :math:`|\det \mathbf{J}|` at a point means the transformation expands volume there, so the density must decrease to conserve total probability. In one dimension, this reduces to the :math:`|dx/dy|` factor from the univariate change of variables.


Worked Example: Polar Coordinates
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The polar coordinate transformation :math:`(r, \theta) \mapsto (x, y) = (r\cos\theta, r\sin\theta)` has Jacobian:

.. math::

   \mathbf{J} = \begin{pmatrix} \cos\theta & -r\sin\theta \\ \sin\theta & r\cos\theta \end{pmatrix}, \qquad \det(\mathbf{J}) = r\cos^2\theta + r\sin^2\theta = r

This is why the area element in polar coordinates is :math:`r\,dr\,d\theta`.

**Connection to Box-Muller.** If :math:`(R^2, \Theta) \sim (\text{Exp}(1/2), \text{Uniform}(0, 2\pi))` independently, then :math:`(R\cos\Theta, R\sin\Theta) \sim N(\mathbf{0}, \mathbf{I}_2)`. The Jacobian determinant handles the density transformation — the complete Box-Muller derivation is in :ref:`Chapter 2.4 <ch2.4-transformation-methods>`.

.. code-block:: python

   import numpy as np

   print("Jacobian: polar → Cartesian")
   print(f"{'r':>6}  {'θ':>8}  {'det(J) analytical':>18}  "
         f"{'det(J) numerical':>18}  {'Diff':>10}")
   print("-" * 66)

   eps = 1e-7
   def transform(r, theta):
       return np.array([r*np.cos(theta), r*np.sin(theta)])

   for r, theta in [(1.0, 0.5), (2.0, 1.0),
                     (0.5, np.pi/4), (3.0, np.pi/3)]:
       det_anal = r
       base = transform(r, theta)
       J = np.zeros((2, 2))
       J[:, 0] = (transform(r+eps, theta)
                  - transform(r-eps, theta)) / (2*eps)
       J[:, 1] = (transform(r, theta+eps)
                  - transform(r, theta-eps)) / (2*eps)
       det_num = np.linalg.det(J)

.. admonition:: Exercise 1: Taylor Approximation of a Log-Likelihood
   :class: exercise

   Consider :math:`X_1, \ldots, X_n \overset{\text{iid}}{\sim} \text{Bernoulli}(p)` with :math:`n = 30`.

   **(a)** Write the log-likelihood :math:`\ell(p) = s\log p + (n-s)\log(1-p)` where :math:`s = \sum x_i`. Compute :math:`\ell'(p)`, :math:`\ell''(p)`, and :math:`\ell'''(p)` analytically.

   **(b)** Generate a data set with ``rng = np.random.default_rng(seed=42)`` and ``data = rng.binomial(1, 0.4, 30)``. Compute the MLE :math:`\hat{p}`. Construct the first-order and second-order Taylor approximations of :math:`\ell(p)` around :math:`\hat{p}`. Over what range of :math:`p` does the second-order approximation stay within 0.1 of the true :math:`\ell(p)`?

   **(c)** Using the second-order Taylor approximation, derive the 95% Wald confidence interval for :math:`p`. Compare to the Wilson interval and the exact Clopper-Pearson interval (via ``scipy.stats``).

   **(d)** The Taylor remainder :math:`R_2(p) = \frac{\ell'''(c)}{6}(p - \hat{p})^3` for some :math:`c` between :math:`p` and :math:`\hat{p}`. Compute :math:`\ell'''(p)` and evaluate :math:`|R_2|` at :math:`p = \hat{p} + 0.1` using the worst-case :math:`c` in that interval. How does this compare to the actual error?

.. dropdown:: Solution
   :class-container: solution

   *Note on part (b):* because the score :math:`\ell'(\hat{p})` is zero at the MLE, the first-order Taylor approximation around :math:`\hat{p}` reduces to the constant :math:`\ell(\hat{p})`. The code therefore constructs only the second-order (quadratic) approximation.

   .. code-block:: python

      import numpy as np
      from scipy import stats

      rng = np.random.default_rng(seed=42)

      # (a) Analytical derivatives
      n = 30
      data = rng.binomial(1, 0.4, n)
      s = int(np.sum(data))
      p_hat = s / n

      print(f"n = {n}, s = {s}, p̂ = {p_hat:.4f}")
      print()
      print("(a) Derivatives of ℓ(p) = s·log(p) + (n-s)·log(1-p):")
      print(f"  ℓ′(p)   = s/p - (n-s)/(1-p)")
      print(f"  ℓ″(p)   = -s/p² - (n-s)/(1-p)²")
      print(f"  ℓ‴(p)   = 2s/p³ - 2(n-s)/(1-p)³")
      print()

      # (b) Taylor approximations
      def loglik(p):
          if p <= 0 or p >= 1:
              return -1e20
          return s * np.log(p) + (n - s) * np.log(1 - p)

      ll_hat = loglik(p_hat)
      score_hat = s / p_hat - (n - s) / (1 - p_hat)
      info_hat = s / p_hat**2 + (n - s) / (1 - p_hat)**2
      J_hat = info_hat

      print(f"(b) At p̂ = {p_hat:.4f}:")
      print(f"  ℓ(p̂) = {ll_hat:.4f}")
      print(f"  Score = {score_hat:.6f}")
      print(f"  J(p̂) = {J_hat:.4f}")
      print()

      p_grid = np.linspace(0.05, 0.85, 500)
      in_range = []
      for p in p_grid:
          ll_exact = loglik(p)
          ll_quad = ll_hat - 0.5 * J_hat * (p - p_hat)**2
          if abs(ll_exact - ll_quad) < 0.1:
              in_range.append(p)

      print(f"  2nd-order within 0.1 of exact for "
            f"p ∈ [{min(in_range):.3f}, {max(in_range):.3f}]")
      print()

      # (c) Confidence intervals
      se = 1 / np.sqrt(J_hat)
      wald_lo = p_hat - 1.96 * se
      wald_hi = p_hat + 1.96 * se

      z = 1.96
      wilson_center = (s + z**2/2) / (n + z**2)
      wilson_hw = (z / (n + z**2)) * np.sqrt(
          s * (n - s) / n + z**2 / 4)
      wilson_lo = wilson_center - wilson_hw
      wilson_hi = wilson_center + wilson_hw

      cp_lo = stats.beta.ppf(0.025, s, n - s + 1)
      cp_hi = stats.beta.ppf(0.975, s + 1, n - s)

      print("(c) 95% confidence intervals:")
      print(f"  Wald:           [{wald_lo:.4f}, {wald_hi:.4f}]")
      print(f"  Wilson:         [{wilson_lo:.4f}, "
            f"{wilson_hi:.4f}]")
      print(f"  Clopper-Pearson: [{cp_lo:.4f}, {cp_hi:.4f}]")
      print()

      # (d) Remainder analysis
      dp = 0.1
      p_test = p_hat + dp

      def third_deriv(p):
          return 2*s/p**3 - 2*(n-s)/(1-p)**3

      # Worst case c in [p_hat, p_test]
      c_grid = np.linspace(p_hat, p_test, 100)
      worst_R2 = max(abs(third_deriv(c) / 6 * dp**3)
                     for c in c_grid)
      actual_error = abs(loglik(p_test)
                         - (ll_hat - 0.5*J_hat*dp**2))

      print(f"(d) Remainder at p = p̂ + {dp}:")
      print(f"  Worst-case |R₂| bound: {worst_R2:.6f}")
      print(f"  Actual error:          {actual_error:.6f}")
      print(f"  Bound is conservative: "
            f"{worst_R2 >= actual_error}")

.. admonition:: Exercise 2: Leibniz Rule and Score Function Properties
   :class: exercise

   Consider the Gamma(:math:`\alpha, \beta`) family with density :math:`f(x; \alpha, \beta) = \frac{\beta^\alpha}{\Gamma(\alpha)} x^{\alpha-1} e^{-\beta x}` for :math:`x > 0`.

   **(a)** Derive the score vector :math:`\mathbf{U}(\alpha, \beta) = \left(\frac{\partial \ell}{\partial \alpha}, \frac{\partial \ell}{\partial \beta}\right)` from the log-likelihood of a single observation. Identify which component requires the **digamma function** :math:`\psi(\alpha) = \frac{d}{d\alpha}\log\Gamma(\alpha)`.

   **(b)** Verify :math:`\mathbb{E}[\mathbf{U}(\alpha_0, \beta_0)] = \mathbf{0}` by simulation: generate 100,000 Gamma samples at :math:`(\alpha, \beta) = (3, 2)`, compute the score at the true parameters, and show the mean of each component is near zero.

   **(c)** Compute the :math:`2 \times 2` Fisher information matrix :math:`\mathbf{I}(\alpha, \beta)` using the second-derivative form :math:`-\mathbb{E}[\mathbf{H}]`. The :math:`(1,1)` entry involves the **trigamma function** :math:`\psi'(\alpha)`. Verify computationally that the score covariance matrix matches :math:`-\mathbb{E}[\mathbf{H}]`.

   **(d)** Explain the difference between :math:`\mathbb{E}_\theta[\mathbf{U}(\theta)] = \mathbf{0}` (expectation over the data at the true parameter) and :math:`\mathbf{U}(\hat{\theta}) = \mathbf{0}` (score equation at the MLE). Why can't you verify :math:`\mathbb{E}[\mathbf{U}] = \mathbf{0}` by simply checking that the sample score equation gives :math:`\bar{X}`?

.. dropdown:: Solution
   :class-container: solution

   .. code-block:: python

      import numpy as np
      from scipy.special import digamma, polygamma

      rng = np.random.default_rng(seed=42)

      alpha0, beta0 = 3.0, 2.0
      n_samples = 100000

      # (a) Score vector for single observation:
      # log f = alpha*log(beta) - log Gamma(alpha)
      #         + (alpha-1)*log(x) - beta*x
      # U_alpha = log(beta) - psi(alpha) + log(x)
      # U_beta  = alpha/beta - x
      print("(a) Score vector for Gamma(α, β):")
      print("  U_α = log(β) - ψ(α) + log(x)")
      print("  U_β = α/β - x")
      print("  The α-component requires the digamma "
            "function ψ(α).")
      print()

      # (b) Verify E[U] = 0
      samples = rng.gamma(alpha0, 1/beta0, n_samples)

      U_alpha = (np.log(beta0) - digamma(alpha0)
                 + np.log(samples))
      U_beta = alpha0 / beta0 - samples

      print(f"(b) E[U(α₀,β₀)] verification "
            f"(n={n_samples:,}):")
      print(f"  Mean U_α = {np.mean(U_alpha):.6f}  "
            f"(expect 0)")
      print(f"  Mean U_β = {np.mean(U_beta):.6f}  "
            f"(expect 0)")
      print()

      # (c) Fisher information matrix
      # -E[H] where H = [[d²ℓ/dα², d²ℓ/dαdβ],
      #                   [d²ℓ/dβdα, d²ℓ/dβ²]]
      # d²ℓ/dα² = -psi'(alpha) (trigamma)
      # d²ℓ/dαdβ = 1/beta
      # d²ℓ/dβ² = -alpha/beta²
      I_analytical = np.array([
          [polygamma(1, alpha0), -1/beta0],
          [-1/beta0, alpha0/beta0**2]])

      # Score covariance
      scores = np.column_stack([U_alpha, U_beta])
      I_simulated = np.cov(scores, rowvar=False)

      print("(c) Fisher information matrix:")
      print("  Analytical -E[H]:")
      print(f"    [{I_analytical[0,0]:.6f}  "
            f"{I_analytical[0,1]:.6f}]")
      print(f"    [{I_analytical[1,0]:.6f}  "
            f"{I_analytical[1,1]:.6f}]")
      print()
      print("  Simulated Cov(U):")
      print(f"    [{I_simulated[0,0]:.6f}  "
            f"{I_simulated[0,1]:.6f}]")
      print(f"    [{I_simulated[1,0]:.6f}  "
            f"{I_simulated[1,1]:.6f}]")
      print()

      ratio = I_simulated / I_analytical
      print("  Element-wise ratio Cov(U) / (-E[H]):")
      print(f"    [{ratio[0,0]:.4f}  {ratio[0,1]:.4f}]")
      print(f"    [{ratio[1,0]:.4f}  {ratio[1,1]:.4f}]")
      print()

      # (d) Conceptual answer
      print("(d) E_θ[U(θ)] = 0 is about the EXPECTATION")
      print("    of the score over repeated samples at the")
      print("    TRUE parameter. U(θ̂) = 0 is a SINGLE-SAMPLE")
      print("    equation that defines the MLE. They are")
      print("    different statements:")
      print("    - E[U(θ₀)] = 0: a property of the MODEL")
      print("    - U(θ̂) = 0: a property of the ESTIMATOR")

.. admonition:: Exercise 3: Multivariate Change of Variables
   :class: exercise

   **(a)** Let :math:`(X, Y)` have joint density :math:`f(x, y) = e^{-(x+y)}` for :math:`x, y > 0` (independent Exp(1) variables). Define :math:`U = X + Y` and :math:`V = X/(X+Y)`. Compute the Jacobian of the inverse transformation :math:`(U, V) \mapsto (X, Y)`, find the joint density of :math:`(U, V)`, and verify that :math:`U \sim \text{Gamma}(2, 1)` and :math:`V \sim \text{Uniform}(0, 1)` independently.

   **(b)** Verify computationally: generate 100,000 pairs :math:`(X, Y)`, transform to :math:`(U, V)`, and check the marginal distributions via the Kolmogorov-Smirnov test and that :math:`U` and :math:`V` are uncorrelated.

   **(c)** Generalize: if :math:`X_1, \ldots, X_n` are iid Exp(1), explain (without computing the full Jacobian) why :math:`T = \sum X_i \sim \text{Gamma}(n, 1)` by induction, using the result from (a) as the base case and Gamma additivity (verifiable via the MGF) for the induction step. How does this relate to the MGF approach?

   **(d)** The transformation in (a) generalizes: if :math:`X \sim \text{Gamma}(a, 1)` and :math:`Y \sim \text{Gamma}(b, 1)` independently, then :math:`X/(X+Y) \sim \text{Beta}(a, b)`. Verify computationally for :math:`a = 3, b = 2`.

.. dropdown:: Solution
   :class-container: solution

   .. code-block:: python

      import numpy as np
      from scipy import stats

      rng = np.random.default_rng(seed=42)

      # (a) Analytical derivation
      print("(a) Jacobian computation:")
      print("  Inverse: X = UV, Y = U(1-V)")
      print("  J = [[∂X/∂U, ∂X/∂V], [∂Y/∂U, ∂Y/∂V]]")
      print("    = [[V, U], [1-V, -U]]")
      print("  det(J) = -UV - U(1-V) = -U")
      print("  |det(J)| = U")
      print()
      print("  f_{U,V}(u,v) = f_{X,Y}(uv, u(1-v)) · U")
      print("               = e^{-u} · u")
      print("               = u·e^{-u} · 1")
      print("               = [Gamma(2,1) density] × "
            "[Uniform(0,1) density]")
      print("  So U ~ Gamma(2,1) and V ~ Uniform(0,1), "
            "independently.")
      print()

      # (b) Simulation verification
      n_sim = 100000
      X = rng.exponential(1, n_sim)
      Y = rng.exponential(1, n_sim)
      U = X + Y
      V = X / (X + Y)

      ks_U = stats.kstest(U, 'gamma', args=(2, 0, 1))
      ks_V = stats.kstest(V, 'uniform')
      corr = np.corrcoef(U, V)[0, 1]

      print(f"(b) Simulation (n={n_sim:,}):")
      print(f"  U ~ Gamma(2,1): KS stat = "
            f"{ks_U.statistic:.4f}, "
            f"p = {ks_U.pvalue:.4f}")
      print(f"  V ~ Uniform(0,1): KS stat = "
            f"{ks_V.statistic:.4f}, "
            f"p = {ks_V.pvalue:.4f}")
      print(f"  Corr(U, V) = {corr:.6f} (expect ~0)")
      print()

      # (c) Induction argument
      print("(c) Induction: if T_{n-1} = X_1+...+X_{n-1} "

      print("    and X_n ~ Exp(1) independently, then")
      print("    T_n = T_{n-1} + X_n.")
