Point Estimation
-----------------

Estimators and Their Properties
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   An **estimator** :math:`\hat{\theta} = T(X_1, \ldots, X_n)` is a function of a random sample :math:`X_1, X_2, \ldots, X_n` used to approximate an unknown parameter :math:`\theta`. As a function of random variables, the estimator is itself a random variable with a **sampling distribution**.

**Intuition.** An estimator is a recipe that takes a dataset and returns a guess for an unknown parameter. Different recipes (sample mean, sample median, trimmed mean) all estimate the same quantity but have different properties — some are systematically off-center, some are more variable, some are more robust to outliers. Statistical theory provides the vocabulary and tools to compare these recipes rigorously before collecting data: we ask how the estimator behaves across all possible datasets (its *sampling distribution*), not just for one particular dataset. This shift from one sample to the ensemble of all possible samples is the foundational move of frequentist inference.

The quality of an estimator is assessed through several properties. We develop each formally.

**Bias.** The bias of an estimator measures systematic deviation from the target:

.. math::

   \text{Bias}(\hat{\theta}) = \mathbb{E}[\hat{\theta}] - \theta

An estimator is **unbiased** if :math:`\text{Bias}(\hat{\theta}) = 0` for all :math:`\theta`. Unbiasedness is desirable but neither necessary nor sufficient for a good estimator — a highly variable unbiased estimator may be less useful than a slightly biased but stable one.

**Variance.** The variance measures the spread of the estimator's sampling distribution:

.. math::

   \text{Var}(\hat{\theta}) = \mathbb{E}\left[(\hat{\theta} - \mathbb{E}[\hat{\theta}])^2\right]

**Mean Squared Error.** The MSE combines bias and variance into a single measure of accuracy:

.. admonition:: Theorem: MSE Bias-Variance Decomposition
   :class: note

   For any estimator :math:`\hat{\theta}` of :math:`\theta`:

   .. math::

      \text{MSE}(\hat{\theta}) = \mathbb{E}\left[(\hat{\theta} - \theta)^2\right] = \text{Bias}(\hat{\theta})^2 + \text{Var}(\hat{\theta})

.. admonition:: Derivation: MSE Decomposition
   :class: dropdown

   Let :math:`\mu = \mathbb{E}[\hat{\theta}]`. Then:

   .. math::

      \text{MSE}(\hat{\theta}) &= \mathbb{E}\left[(\hat{\theta} - \theta)^2\right] \\
      &= \mathbb{E}\left[(\hat{\theta} - \mu + \mu - \theta)^2\right] \\
      &= \mathbb{E}\left[(\hat{\theta} - \mu)^2\right] + 2(\mu - \theta)\mathbb{E}[\hat{\theta} - \mu] + (\mu - \theta)^2 \\
      &= \text{Var}(\hat{\theta}) + 0 + \text{Bias}(\hat{\theta})^2

   The cross term vanishes because :math:`\mathbb{E}[\hat{\theta} - \mu] = 0` by definition of :math:`\mu`.

For an unbiased estimator, MSE equals variance. For a biased estimator, the bias contributes an additional penalty. This decomposition is the foundation of the **bias-variance tradeoff**: a small amount of bias can be worthwhile if it substantially reduces variance.

**Consistency.** An estimator is **consistent** if it converges in probability to the true parameter as the sample size grows: :math:`\hat{\theta}_n \xrightarrow{P} \theta` as :math:`n \to \infty`. A sufficient (but not necessary) condition for consistency is that the estimator is unbiased with variance tending to zero:

.. math::

   \text{Bias}(\hat{\theta}_n) \to 0 \quad \text{and} \quad \text{Var}(\hat{\theta}_n) \to 0 \quad \Longrightarrow \quad \hat{\theta}_n \xrightarrow{P} \theta

This follows from Chebyshev's inequality applied to :math:`\text{MSE}(\hat{\theta}_n) \to 0`.

**Efficiency.** Among all unbiased estimators, some have smaller variance than others. The **relative efficiency** of :math:`\hat{\theta}_1` to :math:`\hat{\theta}_2` is:

.. math::

   \text{eff}(\hat{\theta}_1, \hat{\theta}_2) = \frac{\text{Var}(\hat{\theta}_2)}{\text{Var}(\hat{\theta}_1)}

If :math:`\text{eff} > 1`, then :math:`\hat{\theta}_1` is more efficient. The Cramér-Rao lower bound (developed in the Sufficiency and Information section below) establishes the minimum variance achievable by any unbiased estimator, and estimators achieving this bound are called **efficient**.

**Asymptotic relative efficiency (ARE).** When comparing estimators whose exact variances depend on :math:`n` in complicated ways, we use the limiting ratio:

.. math::

   \text{ARE}(\hat{\theta}_1, \hat{\theta}_2) = \lim_{n\to\infty} \frac{\text{Var}(\hat{\theta}_2)}{\text{Var}(\hat{\theta}_1)}

If :math:`\text{ARE} = c`, then :math:`\hat{\theta}_2` needs approximately :math:`c \cdot n` observations to achieve the same precision as :math:`\hat{\theta}_1` with :math:`n` observations. For example, the sample median has :math:`\text{ARE} = 2/\pi \approx 0.64` relative to the sample mean for normal data — the median wastes about 36% of the information.


Uniformly Minimum Variance Unbiased Estimators
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Among all unbiased estimators of :math:`\theta`, is there a best one? The **UMVUE** (uniformly minimum variance unbiased estimator) achieves the smallest variance for every value of :math:`\theta`. The route to it runs through **sufficiency** — informally, a statistic that captures everything the data say about :math:`\theta` (defined formally in the Sufficiency and Information section below).

.. admonition:: Theorem: Rao-Blackwell
   :class: note

   Let :math:`\hat{\theta}` be any unbiased estimator of :math:`\theta` and :math:`T` be a sufficient statistic for :math:`\theta`. Then :math:`\hat{\theta}^* = \mathbb{E}[\hat{\theta} \mid T]` satisfies:

   1. :math:`\hat{\theta}^*` is unbiased for :math:`\theta`
   2. :math:`\text{Var}(\hat{\theta}^*) \le \text{Var}(\hat{\theta})` for all :math:`\theta`
   3. :math:`\hat{\theta}^*` depends on the data only through :math:`T`

.. admonition:: Proof
   :class: dropdown

   **(1)** By the tower property: :math:`\mathbb{E}[\hat{\theta}^*] = \mathbb{E}[\mathbb{E}[\hat{\theta} \mid T]] = \mathbb{E}[\hat{\theta}] = \theta`.

   **(2)** By the law of total variance:

   .. math::

      \text{Var}(\hat{\theta}) = \text{Var}(\mathbb{E}[\hat{\theta} \mid T]) + \mathbb{E}[\text{Var}(\hat{\theta} \mid T)] = \text{Var}(\hat{\theta}^*) + \mathbb{E}[\text{Var}(\hat{\theta} \mid T)]

   Since :math:`\mathbb{E}[\text{Var}(\hat{\theta} \mid T)] \ge 0`, we have :math:`\text{Var}(\hat{\theta}^*) \le \text{Var}(\hat{\theta})`. Equality holds iff :math:`\hat{\theta}` is already a function of :math:`T`.

The Rao-Blackwell theorem says: conditioning on a sufficient statistic can never increase variance and usually decreases it. But different starting estimators may Rao-Blackwellize to different functions of :math:`T`. To guarantee a unique best estimator, we need **completeness**: a sufficient statistic :math:`T` is complete if :math:`\mathbb{E}_\theta[g(T)] = 0` for all :math:`\theta` implies :math:`g(T) = 0` a.s., so that :math:`T` admits no non-trivial unbiased estimator of zero (the formal definition appears in the Sufficiency and Information section below).

.. admonition:: Theorem: Lehmann-Scheffé
   :class: note

   If :math:`T` is a complete sufficient statistic and :math:`h(T)` is any unbiased estimator of :math:`\theta` based on :math:`T`, then :math:`h(T)` is the unique UMVUE of :math:`\theta`.

.. admonition:: Proof
   :class: dropdown

   The proof follows immediately: if :math:`h_1(T)` and :math:`h_2(T)` are both unbiased for :math:`\theta`, then :math:`\mathbb{E}[h_1(T) - h_2(T)] = 0` for all :math:`\theta`. By completeness, :math:`h_1(T) = h_2(T)` a.s.

**Example:** For :math:`X_1, \ldots, X_n \sim N(\mu, \sigma^2)` with :math:`\sigma^2` known, :math:`T = \sum X_i` is complete sufficient for :math:`\mu`. Since :math:`\bar{X} = T/n` is unbiased for :math:`\mu` and is a function of :math:`T`, the Lehmann-Scheffé theorem guarantees that :math:`\bar{X}` is the UMVUE of :math:`\mu`.

For exponential families (which include Normal, Poisson, Binomial, Gamma, and Beta), the natural sufficient statistic is always complete. This is why the "obvious" estimators — :math:`\bar{X}` for the Poisson rate, :math:`\bar{X}` for the normal mean — are UMVUEs: they are unbiased functions of the complete sufficient statistic.


Common Estimators
~~~~~~~~~~~~~~~~~~

**Sample mean:** :math:`\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i` is unbiased for :math:`\mu` with variance :math:`\sigma^2/n`. By the WLLN (proved in the Asymptotic Theory section below), :math:`\bar{X}` is consistent for :math:`\mu`.

**Sample variance:** :math:`S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2` is unbiased for :math:`\sigma^2`. The :math:`n-1` denominator (Bessel's correction) is not arbitrary:

.. admonition:: Derivation: Why n-1 in the Sample Variance
   :class: dropdown

   We show :math:`\mathbb{E}[S^2] = \sigma^2`. Start with the identity:

   .. math::

      \sum_{i=1}^n (X_i - \bar{X})^2 = \sum_{i=1}^n (X_i - \mu)^2 - n(\bar{X} - \mu)^2

   Taking expectations:

   .. math::

      \mathbb{E}\left[\sum_{i=1}^n (X_i - \bar{X})^2\right] &= \sum_{i=1}^n \mathbb{E}[(X_i - \mu)^2] - n\,\mathbb{E}[(\bar{X} - \mu)^2] \\
      &= n\sigma^2 - n \cdot \frac{\sigma^2}{n} = (n-1)\sigma^2

   Therefore :math:`\mathbb{E}\left[\frac{1}{n-1}\sum(X_i - \bar{X})^2\right] = \sigma^2`. The factor :math:`n-1` compensates for estimating :math:`\mu` from the same data: replacing the unknown :math:`\mu` with :math:`\bar{X}` systematically reduces the sum of squares. This is a simple instance of **degrees of freedom** — we lose one degree of freedom by estimating the mean.

**Biased variance estimator:** The alternative :math:`\hat{\sigma}^2_{\text{MLE}} = \frac{1}{n}\sum_{i=1}^n (X_i - \bar{X})^2` has :math:`\text{Bias}(\hat{\sigma}^2_{\text{MLE}}) = -\sigma^2/n` but lower variance than :math:`S^2`. As the next code block shows, :math:`\hat{\sigma}^2_{\text{MLE}}` can have lower MSE than :math:`S^2` — unbiasedness does not guarantee optimality.

.. code-block:: python

   import numpy as np

   rng = np.random.default_rng(42)

   # Compare σ̂²_MLE (biased) vs S² (unbiased) variance estimators
   mu, sigma = 5.0, 2.0
   sigma2 = sigma**2
   n_reps = 50000

   print(f"{'n':>5}  {'MSE(σ̂²_MLE)':>13}  {'MSE(S²)':>10}  "
         f"{'Bias²(σ̂²_MLE)':>15}  {'Winner':>8}")
   print("-" * 60)

   for n in [5, 10, 25, 50, 100]:
       biased = np.zeros(n_reps)
       unbiased = np.zeros(n_reps)
       for i in range(n_reps):
           sample = rng.normal(mu, sigma, n)
           biased[i] = np.var(sample, ddof=0)    # σ̂²_MLE
           unbiased[i] = np.var(sample, ddof=1)  # S²

       mse_biased = np.mean((biased - sigma2)**2)
       mse_unbiased = np.mean((unbiased - sigma2)**2)
       bias_sq = (np.mean(biased) - sigma2)**2
       winner = ("σ̂²_MLE" if mse_biased < mse_unbiased
                 else "S²")
       print(f"{n:>5}  {mse_biased:>13.4f}  "
             f"{mse_unbiased:>10.4f}  "
             f"{bias_sq:>15.4f}  {winner:>8}")

The biased estimator wins in MSE at every sample size. For normal data, the MSE of the biased estimator is :math:`\frac{2n-1}{n^2}\sigma^4` versus :math:`\frac{2}{n-1}\sigma^4` for the unbiased version. As :math:`n \to \infty` both approach :math:`2\sigma^4/n`, but the biased estimator is always smaller. This illustrates the bias-variance tradeoff: accepting a small bias (:math:`-\sigma^2/n \to 0`) buys a meaningful variance reduction.


Method of Moments
~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   The **method of moments** (MoM) equates population moments :math:`\mu_k' = \mathbb{E}[X^k]` with their sample counterparts :math:`m_k' = \frac{1}{n}\sum_{i=1}^n X_i^k` and solves for unknown parameters.

For a distribution with :math:`p` parameters, equate the first :math:`p` moments and solve the resulting system. MoM estimators are always easy to compute (no optimization required) and are consistent under mild conditions, but they are generally less efficient than MLEs.

**Example: Gamma distribution.** The Gamma(:math:`\alpha, \beta`) distribution (shape :math:`\alpha`, scale :math:`\beta`) has :math:`\mathbb{E}[X] = \alpha\beta` and :math:`\mathbb{E}[X^2] = \alpha\beta^2(1 + \alpha)`. Setting :math:`m_1 = \alpha\beta` and :math:`m_2 = \alpha\beta^2(1+\alpha)`:

.. math::

   \hat{\beta}_{\text{MoM}} = \frac{m_2}{m_1} - m_1 = \frac{m_2 - m_1^2}{m_1}, \qquad \hat{\alpha}_{\text{MoM}} = \frac{m_1}{\hat{\beta}_{\text{MoM}}} = \frac{m_1^2}{m_2 - m_1^2}

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # Method of Moments for Gamma(α=3, β=2)
   alpha_true, beta_true = 3.0, 2.0
   n = 200

   sample = rng.gamma(alpha_true, beta_true, n)

   # Sample moments
   m1 = np.mean(sample)
   m2 = np.mean(sample**2)

   # MoM estimates
   beta_mom = m2 / m1 - m1
   alpha_mom = m1 / beta_mom

   # MLE for comparison
   alpha_mle, _, beta_mle = stats.gamma.fit(sample, floc=0)

   print(f"Gamma({alpha_true}, {beta_true}) sample (n={n}):")
   print(f"  Sample moments: m₁ = {m1:.4f}, m₂ = {m2:.4f}")
   print(f"")
   print(f"  Method of Moments: α̂ = {alpha_mom:.4f}, β̂ = {beta_mom:.4f}")
   print(f"  Maximum Likelihood: α̂ = {alpha_mle:.4f}, β̂ = {beta_mle:.4f}")
   print(f"  True values:        α = {alpha_true:.4f}, β = {beta_true:.4f}")

.. code-block:: text

   Gamma(3.0, 2.0) sample (n=200):
     Sample moments: m₁ = 6.2028, m₂ = 50.5877

     Method of Moments: α̂ = 3.1761, β̂ = 1.9529
     Maximum Likelihood: α̂ = 3.2931, β̂ = 1.8836

Both MoM and MLE are close to the true values for this sample. MoM has the advantage of a closed-form solution, while the MLE requires numerical optimization (there is no closed form for the Gamma MLE). The MLE is asymptotically efficient; the MoM estimator generally is not. We develop the MLE formally in the Likelihood section below and computationally in :ref:`ch3_2-maximum-likelihood-estimation`.


Sampling Distributions
~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   The **sampling distribution** of an estimator :math:`\hat{\theta} = T(X_1, \ldots, X_n)` is its probability distribution induced by the random sample. Because the sample is random, the estimator is a random variable; its distribution describes how :math:`\hat{\theta}` varies across hypothetical repeated samples of the same size from the same population.

Understanding the sampling distribution is the central problem of frequentist inference. It governs the precision of our estimates, determines the width of confidence intervals, and defines the null distributions used in hypothesis tests. We develop the exact results for normal populations and then describe what changes for non-normal data.


Exact Results for Normal Populations
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

When :math:`X_1, \ldots, X_n \sim N(\mu, \sigma^2)`, the sampling distributions of the fundamental statistics are known exactly — no large-sample approximation needed.

**Distribution of the sample mean.**

.. math::

   \bar{X} = \frac{1}{n}\sum_{i=1}^n X_i \sim N\!\left(\mu,\; \frac{\sigma^2}{n}\right)

This follows from the fact that a linear combination of independent normal random variables is normal, with mean :math:`\mu` and variance :math:`\sigma^2/n`. The precision of :math:`\bar{X}` improves like :math:`1/n`.

**Distribution of the sample variance.**

.. math::

   \frac{(n-1)S^2}{\sigma^2} = \frac{1}{\sigma^2}\sum_{i=1}^n (X_i - \bar{X})^2 \sim \chi^2_{n-1}

The :math:`\chi^2_{n-1}` distribution has mean :math:`n-1` and variance :math:`2(n-1)`, so :math:`\mathbb{E}[S^2] = \sigma^2` (confirming unbiasedness) and :math:`\text{Var}(S^2) = 2\sigma^4/(n-1)`.

**Independence of** :math:`\bar{X}` **and** :math:`S^2`. For normal data, :math:`\bar{X}` and :math:`S^2` are **independent** — a non-obvious but fundamental property. This is specific to the normal distribution and does not hold in general. The independence is what makes the :math:`t`-statistic tractable.

**The** :math:`t`-**distribution.** Combining the three results above:

.. math::

   T = \frac{\bar{X} - \mu}{S/\sqrt{n}} = \frac{(\bar{X} - \mu)/(\sigma/\sqrt{n})}{S/\sigma} = \frac{Z}{\sqrt{V/(n-1)}} \sim t_{n-1}

where :math:`Z = (\bar{X}-\mu)/(\sigma/\sqrt{n}) \sim N(0,1)` and :math:`V = (n-1)S^2/\sigma^2 \sim \chi^2_{n-1}` are independent. The :math:`t_{n-1}` distribution has heavier tails than :math:`N(0,1)`: its variance is :math:`(n-1)/(n-3)` (for :math:`n > 3`) rather than 1, and its excess kurtosis is :math:`6/(n-5)` (for :math:`n > 5`). As :math:`n \to \infty`, the :math:`t_{n-1}` distribution converges to :math:`N(0,1)`.


The Standard Error
^^^^^^^^^^^^^^^^^^^^

.. admonition:: Definition
   :class: definition

   The **standard error** of an estimator :math:`\hat{\theta}` is the standard deviation of its sampling distribution:

   .. math::

      \text{SE}(\hat{\theta}) = \sqrt{\text{Var}(\hat{\theta})}

   When the standard error depends on unknown parameters, we substitute estimates to obtain the **estimated standard error** :math:`\widehat{\text{SE}}`.

For the sample mean: :math:`\text{SE}(\bar{X}) = \sigma/\sqrt{n}`, estimated by :math:`\widehat{\text{SE}}(\bar{X}) = S/\sqrt{n}`. The standard error quantifies the precision of the estimator — it is the "typical" distance between :math:`\hat{\theta}` and :math:`\theta` in a single experiment. Confidence intervals are built from it (the margin of error is a multiple of the SE), and it is the denominator of every test statistic.


Approximate Results for Non-Normal Populations
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

When the population is not normal, the exact results above no longer hold. However, the **Central Limit Theorem** (developed fully in the Asymptotic Theory section below) guarantees that for large :math:`n`:

.. math::

   \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \;\dot{\sim}\; N(0,1)

The approximation quality depends on the population's shape: symmetric distributions converge quickly (:math:`n \ge 15` is often sufficient), while highly skewed distributions (e.g., Exponential, Lognormal) may need :math:`n \ge 50` or more. The :math:`t`-statistic :math:`T = (\bar{X} - \mu)/(S/\sqrt{n})` remains approximately :math:`t_{n-1}` by Slutsky's theorem (proved in the Asymptotic Theory section below), since :math:`S \xrightarrow{P} \sigma`.

The :math:`\chi^2` result for :math:`S^2` and the independence of :math:`\bar{X}` and :math:`S^2` are **not** approximately true for non-normal data. The distribution of :math:`S^2` depends on the population kurtosis, and :math:`\bar{X}` and :math:`S^2` can be correlated for skewed populations. These failures are why the :math:`t`-interval has poor coverage for small :math:`n` with skewed data (demonstrated in Exercise 1(a)).


Computational Verification
^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # Sampling distributions of x̄ and S² for Normal(μ=5, σ=2)
   mu, sigma = 5.0, 2.0
   n_reps = 10000

   for n in [15, 100]:
       xbar = np.zeros(n_reps)
       s2 = np.zeros(n_reps)
       for i in range(n_reps):
           sample = rng.normal(mu, sigma, n)
           xbar[i] = np.mean(sample)
           s2[i] = np.var(sample, ddof=1)

       # Chi-squared check: (n-1)S²/σ² ~ χ²_{n-1}
       chi2_vals = (n - 1) * s2 / sigma**2

       print(f"n = {n} ({n_reps:,} replicates):")
       print(f"  x̄: E[x̄] = {np.mean(xbar):.4f} "
             f"(theory {mu:.1f}), "
             f"Var(x̄) = {np.var(xbar):.4f} "
             f"(theory {sigma**2/n:.4f})")
       print(f"  S²: E[S²] = {np.mean(s2):.4f} "
             f"(theory {sigma**2:.1f}), "
             f"SD(S²) = {np.std(s2):.4f}")
       print(f"  (n-1)S²/σ²: mean = "
             f"{np.mean(chi2_vals):.4f} (theory {n-1}), "
             f"var = {np.var(chi2_vals):.4f} "
             f"(theory {2*(n-1):.1f})")
       corr = np.corrcoef(xbar, s2)[0, 1]
       print(f"  Corr(x̄, S²) = {corr:.4f} (theory 0)")
       print()

     (n-1)S²/σ²: mean = 98.9146 (theory 99), var = 197.7431 (theory 198.0)
     Corr(x̄, S²) = 0.0235 (theory 0)

All theoretical predictions are confirmed: :math:`\bar{X}` is unbiased with variance :math:`\sigma^2/n`; :math:`(n-1)S^2/\sigma^2` has the mean and variance of :math:`\chi^2_{n-1}`; and the correlation between :math:`\bar{X}` and :math:`S^2` is near zero (the small deviations of 0.02 are simulation noise).

The next block verifies the :math:`t`-distribution by comparing the pivotal quantities :math:`Z = (\bar{X}-\mu)/(\sigma/\sqrt{n})` (known :math:`\sigma`) and :math:`T = (\bar{X}-\mu)/(S/\sqrt{n})` (estimated :math:`\sigma`):

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # t-distribution emergence
   mu, sigma = 5.0, 2.0
   n = 15
   n_reps = 10000

   z_vals = np.zeros(n_reps)
   t_vals = np.zeros(n_reps)
   se_vals = np.zeros(n_reps)

   for i in range(n_reps):
       sample = rng.normal(mu, sigma, n)
       xbar = np.mean(sample)
       s = np.std(sample, ddof=1)
       z_vals[i] = (xbar - mu) / (sigma / np.sqrt(n))
       t_vals[i] = (xbar - mu) / (s / np.sqrt(n))
       se_vals[i] = s / np.sqrt(n)

   print("Pivotal quantities for Normal(μ=5, σ=2), n=15:")
   print()
   print(f"{'':>20}  {'Z (known σ)':>12}  "
         f"{'T (estimated σ)':>16}")
   print("-" * 55)
   print(f"{'Mean':>20}  {np.mean(z_vals):>12.4f}  "
         f"{np.mean(t_vals):>16.4f}")
   print(f"{'Variance':>20}  {np.var(z_vals):>12.4f}  "
         f"{np.var(t_vals):>16.4f}")
   print(f"{'Theory':>20}  {'1.0000':>12}  "
         f"{(n-1)/(n-3):>16.4f}")
   print(f"{'Kurtosis':>20}  "
         f"{stats.kurtosis(z_vals):>12.4f}  "
         f"{stats.kurtosis(t_vals):>16.4f}")
   print(f"{'Theory':>20}  {'0.0000':>12}  "
         f"{6/(n-1-4):>16.4f}")
   print(f"{'2.5th percentile':>20}  "
         f"{np.percentile(z_vals, 2.5):>12.4f}  "
         f"{np.percentile(t_vals, 2.5):>16.4f}")
   print(f"{'Theory':>20}  "
         f"{stats.norm.ppf(0.025):>12.4f}  "
         f"{stats.t.ppf(0.025, df=n-1):>16.4f}")
   print()
   print(f"Standard error: E[S/√n] = "
         f"{np.mean(se_vals):.4f} "
         f"(theory σ/√n = {sigma/np.sqrt(n):.4f})")

   -------------------------------------------------------
                   Mean       -0.0130           -0.0182
               Variance        1.0028            1.1608
                 Theory        1.0000            1.1667

The :math:`Z` statistic matches :math:`N(0,1)`: variance 1, zero kurtosis, 2.5th percentile at :math:`-1.96`. The :math:`T` statistic has the wider spread of :math:`t_{14}`: variance 1.16 (theory :math:`14/12 = 1.167`), positive excess kurtosis 0.34 (theory :math:`6/10 = 0.6`), and a more extreme 2.5th percentile at :math:`-2.15` (theory :math:`-2.145`). The practical consequence is that :math:`t`-based intervals are wider than :math:`z`-based intervals, correctly accounting for the additional uncertainty from estimating :math:`\sigma`. The gap narrows as :math:`n` grows: at :math:`n = 100`, the :math:`t_{99}` critical value (1.984) is barely distinguishable from :math:`z_{0.025} = 1.960`.

.. admonition:: Statistical Application
   :class: tip

   The sampling distribution concept is central to everything that follows. Confidence intervals quantify the spread of the sampling distribution. Hypothesis tests ask whether an observed statistic is unusual under a hypothesized sampling distribution. The bootstrap (Chapter 4) provides a computational route to the sampling distribution when the exact or asymptotic theory developed here is unavailable — it resamples the data to approximate the distribution directly.


Confidence Intervals
---------------------

.. admonition:: Definition
   :class: definition

   A **confidence interval** at level :math:`1-\alpha` for a parameter :math:`\theta` is a random interval :math:`[L(X_1,\ldots,X_n),\; U(X_1,\ldots,X_n)]` satisfying

   .. math::

      P_\theta\bigl(L \le \theta \le U\bigr) \ge 1-\alpha \qquad \text{for all } \theta

   The probability statement is over the **random endpoints** :math:`L` and :math:`U`, not over :math:`\theta`, which is a fixed (unknown) constant. This is the **coverage guarantee**: if we were to repeat the sampling and interval construction many times, at least :math:`100(1-\alpha)\%` of the intervals would contain :math:`\theta`.

**Intuition.** A confidence interval inverts a probability statement about the estimator into a statement about the parameter. We know the sampling distribution of :math:`\hat{\theta}` — how far it typically falls from :math:`\theta`. A CI takes the observed :math:`\hat{\theta}` and draws a "net" around it wide enough that, based on the known sampling variability, it will usually catch :math:`\theta`. The net's width comes from the standard error; the multiplier comes from the desired confidence level. The interval is random (it depends on the data); the parameter is fixed. Before the experiment, we can say "our procedure captures :math:`\theta` 95% of the time." After the experiment, we have one specific interval — it either contains :math:`\theta` or it doesn't, and we don't know which.


Constructing Intervals from Pivotal Quantities
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The standard approach to constructing confidence intervals uses a **pivotal quantity** — a function of the data and the parameter whose distribution does not depend on any unknown parameters. The key idea: if we can standardize :math:`\hat{\theta}` into a quantity with a known distribution (free of all unknown parameters), we can invert that distributional statement to isolate :math:`\theta`.

.. admonition:: Derivation: The z-Interval
   :class: dropdown

   Suppose :math:`X_1, \ldots, X_n \sim N(\mu, \sigma^2)` with :math:`\sigma^2` known. The quantity

   .. math::

      Z = \frac{\bar{X} - \mu}{\sigma / \sqrt{n}} \sim N(0, 1)

   is pivotal: its distribution does not depend on :math:`\mu`. For a :math:`1-\alpha` interval, we need

   .. math::

      P\!\left(-z_{\alpha/2} \le \frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \le z_{\alpha/2}\right) = 1 - \alpha

   Rearranging the inequality for :math:`\mu`:

   .. math::

      P\!\left(\bar{X} - z_{\alpha/2}\frac{\sigma}{\sqrt{n}} \le \mu \le \bar{X} + z_{\alpha/2}\frac{\sigma}{\sqrt{n}}\right) = 1 - \alpha

   This gives the :math:`z`-interval: :math:`\bar{X} \pm z_{\alpha/2}\,\sigma/\sqrt{n}`.

.. admonition:: Derivation: The t-Interval
   :class: dropdown

   When :math:`\sigma` is unknown, we replace it with :math:`S = \sqrt{S^2}`. But :math:`S` is random, so the pivot changes:

   .. math::

      T = \frac{\bar{X} - \mu}{S / \sqrt{n}}

   The key result is that :math:`T \sim t_{n-1}` (Student's t with :math:`n-1` degrees of freedom). This follows from the fact that for normal data:

   1. :math:`\bar{X} \sim N(\mu, \sigma^2/n)` and :math:`(n-1)S^2/\sigma^2 \sim \chi^2_{n-1}`
   2. :math:`\bar{X}` and :math:`S^2` are independent (established in the Sampling Distributions subsection of Point Estimation above)
   3. :math:`T = \frac{Z}{\sqrt{V/(n-1)}}` where :math:`Z \sim N(0,1)` and :math:`V \sim \chi^2_{n-1}` are independent — this is the definition of the :math:`t_{n-1}` distribution

   The resulting :math:`t`-interval is:

   .. math::

      \bar{X} \pm t_{\alpha/2,\,n-1}\frac{S}{\sqrt{n}}

   where :math:`t_{\alpha/2,\,n-1}` is the upper :math:`\alpha/2` quantile of :math:`t_{n-1}`. For large :math:`n`, :math:`t_{n-1} \approx N(0,1)` and :math:`S \approx \sigma`, so the :math:`t`-interval converges to the :math:`z`-interval.


Margin of Error and Sample Size Determination
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The **margin of error** is the half-width of the confidence interval. For the :math:`z`-interval:

.. math::

   E = z_{\alpha/2}\frac{\sigma}{\sqrt{n}}

To achieve a desired margin of error :math:`E`, we solve for :math:`n`:

.. math::

   n \ge \left(\frac{z_{\alpha/2}\,\sigma}{E}\right)^2

This is a planning formula: before data collection, choose :math:`n` to guarantee a desired precision. It requires an estimate or upper bound for :math:`\sigma`, often from a pilot study or domain knowledge.


Duality of Confidence Intervals and Hypothesis Tests
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Confidence intervals and hypothesis tests are two views of the same inference. A :math:`100(1-\alpha)\%` confidence interval consists of all parameter values :math:`\theta_0` that would **not** be rejected by a level-:math:`\alpha` test of :math:`H_0: \theta = \theta_0`.

**Worked example.** Consider testing :math:`H_0: \mu = \mu_0` versus :math:`H_1: \mu \ne \mu_0` at level :math:`\alpha`. The :math:`t`-test rejects when :math:`|T| > t_{\alpha/2,\,n-1}` where :math:`T = (\bar{X} - \mu_0)/(S/\sqrt{n})`. The set of :math:`\mu_0` values for which the test does *not* reject is:

.. math::

   \left\{\mu_0 : \left|\frac{\bar{X} - \mu_0}{S/\sqrt{n}}\right| \le t_{\alpha/2,\,n-1}\right\} = \left[\bar{X} - t_{\alpha/2,\,n-1}\frac{S}{\sqrt{n}},\;\; \bar{X} + t_{\alpha/2,\,n-1}\frac{S}{\sqrt{n}}\right]

This is exactly the :math:`t`-interval. The duality means: :math:`\theta_0` is inside the CI if and only if a test of :math:`H_0: \theta = \theta_0` would not reject at level :math:`\alpha`.


Common Misinterpretations
~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Caution
   :class: warning

   **What "95% confidence" does NOT mean:**

   - ❌ "There is a 95% probability that :math:`\theta` lies in this interval." After the data are observed, the interval is fixed — :math:`\theta` is either in it or not. The probability statement applies to the *procedure*, not to a specific realized interval.
   - ❌ "95% of the data falls in this interval." The CI is about the parameter, not about individual observations.
   - ❌ "If we repeat the experiment, 95% of new observations will fall in this interval." That describes a **prediction interval**, which is wider than a confidence interval.

   **What it DOES mean:** If we were to repeat the entire experiment many times (each time drawing a new sample and computing a new interval), approximately 95% of those intervals would contain the true :math:`\theta`. The next simulation demonstrates this directly.


Computational Verification: Coverage
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # Simulate 200 t-intervals for Normal(μ=5, σ=2)
   mu, sigma, n = 5.0, 2.0, 25
   n_intervals = 200
   alpha = 0.05

   captures = 0
   for i in range(n_intervals):
       sample = rng.normal(mu, sigma, n)
       xbar = np.mean(sample)
       se = np.std(sample, ddof=1) / np.sqrt(n)
       t_crit = stats.t.ppf(1 - alpha/2, df=n-1)
       lo = xbar - t_crit * se
       hi = xbar + t_crit * se
       if lo <= mu <= hi:
           captures += 1

   print(f"95% t-intervals (n={n}, {n_intervals} intervals):")
   print(f"  Captured μ = {mu}: {captures}/{n_intervals} = {captures/n_intervals:.1%}")
   print(f"  Missed μ: {n_intervals - captures}/{n_intervals}")
   print(f"  t critical value: {t_crit:.4f}")

.. code-block:: text

   95% t-intervals (n=25, 200 intervals):
     Captured μ = 5.0: 187/200 = 93.5%
     Missed μ: 13/200
     t critical value: 2.0639

With 200 intervals, we expect about 190 captures (:math:`200 \times 0.95`); observing 187 is well within sampling variability.

When Coverage Breaks Down: The Wald Proportion Interval
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The **Wald interval** for a binomial proportion, :math:`\hat{p} \pm z_{\alpha/2}\sqrt{\hat{p}(1-\hat{p})/n}`, is the textbook default but is notorious for poor coverage when :math:`n \cdot p` is small. The **Wilson interval** corrects this by inverting the score test rather than the Wald test:

.. math::

   \frac{\hat{p} + z_{\alpha/2}^2/(2n)}{1 + z_{\alpha/2}^2/n} \pm \frac{z_{\alpha/2}}{1 + z_{\alpha/2}^2/n}\sqrt{\frac{\hat{p}(1-\hat{p})}{n} + \frac{z_{\alpha/2}^2}{4n^2}}

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # Coverage investigation: Wald vs Wilson CI for small p
   p_true = 0.05
   n_reps = 50000
   alpha = 0.05

   print("Coverage of 95% CI for Binomial proportion (p = 0.05)")
   print(f"{'n':>5}  {'n·p':>5}  {'Wald':>8}  {'Wilson':>8}")
   print("-" * 35)

   for n in [10, 20, 50, 200]:
       wald_cover = 0
       wilson_cover = 0
       for i in range(n_reps):
           x = rng.binomial(n, p_true)
           p_hat = x / n

           # Wald interval
           se_wald = np.sqrt(p_hat * (1 - p_hat) / n)
           lo_w = p_hat - 1.96 * se_wald
           hi_w = p_hat + 1.96 * se_wald
           if lo_w <= p_true <= hi_w:
               wald_cover += 1

           # Wilson interval
           z = 1.96
           denom = 1 + z**2 / n
           center = (p_hat + z**2 / (2*n)) / denom
           margin = z * np.sqrt(p_hat*(1-p_hat)/n + z**2/(4*n**2)) / denom
           lo_ws = center - margin
           hi_ws = center + margin
           if lo_ws <= p_true <= hi_ws:
               wilson_cover += 1

       print(f"{n:>5}  {n*p_true:>5.1f}  {wald_cover/n_reps:>8.3f}  "
             f"{wilson_cover/n_reps:>8.3f}")

.. code-block:: text

   Coverage of 95% CI for Binomial proportion (p = 0.05)
       n    n·p      Wald    Wilson
   -----------------------------------
      10    0.5     0.403     0.914
      20    1.0     0.640     0.924
      50    2.5     0.922     0.963
     200   10.0     0.925     0.966

The Wald interval's coverage is catastrophic when :math:`n \cdot p` is small: only 40.3% coverage at :math:`n = 10` (nominally 95%). The problem is fundamental — when :math:`\hat{p}` can be exactly 0 (which happens with probability :math:`0.95^{10} \approx 0.60` at :math:`n = 10`), the Wald interval collapses to the point :math:`[0, 0]` and cannot capture the true :math:`p > 0`. The Wilson interval remains above 90% coverage even at :math:`n = 10` because it uses the score test's better small-sample behavior. Even at :math:`n = 200`, the Wald interval only reaches 92.5% — still below the nominal 95%.

.. admonition:: Statistical Application
   :class: tip

   Chapter 4 introduces the **bootstrap confidence interval**, which does not require a pivotal quantity or distributional assumptions. The bootstrap resamples the data to approximate the sampling distribution directly. Understanding the frequentist coverage guarantee developed here is essential for evaluating bootstrap CI methods.


Hypothesis Testing
-------------------

The Neyman-Pearson Framework
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Hypothesis testing provides a formal decision procedure for choosing between competing claims about a parameter based on data.

.. admonition:: Definition
   :class: definition

   A **hypothesis test** involves:

   - A **null hypothesis** :math:`H_0` (the claim to be tested, often a "no effect" or "default" statement)
   - An **alternative hypothesis** :math:`H_1` (the claim we adopt if the evidence against :math:`H_0` is sufficiently strong)
   - A **test statistic** :math:`T(X_1, \ldots, X_n)` that measures the discrepancy between the data and what :math:`H_0` predicts
   - A **rejection region** :math:`R`: we reject :math:`H_0` if :math:`T \in R`

   Hypotheses are **simple** if they specify :math:`\theta` completely (e.g., :math:`H_0: \mu = 5`) and **composite** if they specify a set of values (e.g., :math:`H_1: \mu > 5`).

**Intuition.** Hypothesis testing is a decision procedure, not a belief-updating procedure. We fix a default claim (:math:`H_0`) and ask: "Is the data so incompatible with :math:`H_0` that a rational agent would abandon it?" The framework is asymmetric by design — we control the probability of wrongly rejecting :math:`H_0` (Type I error) because false alarms typically have higher stakes than missed discoveries. The test statistic distills a high-dimensional dataset into a single number measuring departure from :math:`H_0`, and the rejection region determines how extreme that number must be before we act. This is analogous to a courtroom: :math:`H_0` is "not guilty," and we require evidence beyond a reasonable doubt (:math:`\alpha`) before convicting.


Error Types and Power
~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   +------------------------------+-------------------------------+-------------------------------+
   | Truth vs. Decision           | **Do not reject** :math:`H_0` | **Reject** :math:`H_0`        |
   +==============================+===============================+===============================+
   | :math:`H_0` **true**         | Correct decision              | **Type I error** (prob = α)   |
   +------------------------------+-------------------------------+-------------------------------+
   | :math:`H_0` **false**        | **Type II error** (prob = β)  | Correct decision (power = 1−β)|
   +------------------------------+-------------------------------+-------------------------------+

   - The **significance level** :math:`\alpha = P(\text{reject } H_0 \mid H_0 \text{ true})` is the maximum Type I error rate. We control this by design.
   - The **power** of a test against a specific alternative :math:`\theta_1` is :math:`\pi(\theta_1) = P(\text{reject } H_0 \mid \theta = \theta_1) = 1 - \beta(\theta_1)`. We want this to be large.
   - The **power function** :math:`\pi(\theta)` gives the rejection probability as a function of the true parameter. At :math:`H_0`, :math:`\pi(\theta_0) = \alpha`; a good test has :math:`\pi(\theta)` increasing rapidly as :math:`\theta` moves away from :math:`H_0`.

.. figure:: https://pqyjaywwccbnqpwgeiuv.supabase.co/storage/v1/object/public/STAT%20418%20Images/assets/Appendices/appendix_d_fig02_testing_geometry.png
   :alt: Null distribution with rejection regions and null-alternative overlap showing power
   :align: center
   :width: 100%

   **Figure E.2**: The geometry of hypothesis testing. (a) Two-sided rejection regions: the red shaded tails each contain :math:`\alpha/2 = 0.025` of the null distribution, giving critical values :math:`\pm 1.96`. (b) Null (:math:`H_0`) and alternative (:math:`H_1`) distributions overlaid. The orange region is :math:`\beta` (Type II error — failing to reject when :math:`H_1` is true); the green region is power :math:`= 1 - \beta`. Moving the alternative further from the null shrinks :math:`\beta` and increases power.


P-Values
~~~~~~~~~

.. admonition:: Definition
   :class: definition

   The **p-value** is the probability, under :math:`H_0`, of observing a test statistic at least as extreme as the one actually observed:

   .. math::

      p = P_{H_0}(T \ge t_{\text{obs}}) \quad \text{(one-sided)}

   For a two-sided test: :math:`p = P_{H_0}(|T| \ge |t_{\text{obs}}|)`.

**Intuition.** The p-value answers a specific question: "If :math:`H_0` were true, how surprising is what we observed?" It measures surprise on the probability scale — a p-value of 0.03 means that under :math:`H_0`, only 3% of datasets would produce a test statistic as extreme or more extreme than ours. Critically, the p-value is *not* the probability that :math:`H_0` is true (that is a Bayesian posterior probability requiring a prior), and it is *not* the probability that the result occurred "by chance" (the data already occurred). The p-value is a pre-experimental probability evaluated at the observed data: it calibrates how well :math:`H_0` predicts what we saw. The decision rule "reject :math:`H_0` when :math:`p < \alpha`" is equivalent to "reject when :math:`T \in R`" for any fixed :math:`\alpha`.

.. admonition:: Theorem: P-Values are Uniform Under :math:`H_0`
   :class: note

   If the test statistic :math:`T` has a continuous distribution under :math:`H_0`, then the p-value :math:`p = 1 - F_0(T)` is uniformly distributed on :math:`[0, 1]` under :math:`H_0`.

.. admonition:: Derivation
   :class: dropdown

   Let :math:`F_0` be the CDF of :math:`T` under :math:`H_0`. The one-sided p-value is :math:`p = 1 - F_0(T)`. We need :math:`P_{H_0}(p \le u) = u` for :math:`u \in [0,1]`.

   .. math::

      P_{H_0}(p \le u) &= P_{H_0}(1 - F_0(T) \le u) \\
      &= P_{H_0}(F_0(T) \ge 1 - u) \\
      &= P_{H_0}(T \ge F_0^{-1}(1-u)) \\
      &= 1 - F_0(F_0^{-1}(1-u)) = 1 - (1-u) = u

   The key step is the **probability integral transform**: if :math:`T \sim F_0`, then :math:`F_0(T) \sim \text{Uniform}(0,1)`. This is why we can check for a uniform histogram of p-values under :math:`H_0` to validate a test procedure.

.. admonition:: Caution
   :class: warning

   **What a p-value is NOT:**

   - ❌ The probability that :math:`H_0` is true. P-values are computed *assuming* :math:`H_0` is true — they cannot tell you the probability that this assumption is correct. This conflation is the "prosecutor's fallacy": :math:`P(\text{data} \mid H_0)` is not :math:`P(H_0 \mid \text{data})`.
   - ❌ The probability of "getting this result by chance." The entire test is conducted under the assumption of chance (i.e., :math:`H_0`); the p-value measures how extreme the observed result is under that assumption.
   - ❌ The probability that rejecting :math:`H_0` is a mistake. That would be :math:`P(H_0 \mid \text{reject})`, which depends on the prior probability of :math:`H_0` — a Bayesian quantity.

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # Simulate p-values under H₀ and H₁
   mu0 = 0.0
   sigma = 1.0
   n = 25
   n_reps = 10000

   # Under H₀: μ = 0
   pvals_h0 = np.zeros(n_reps)
   for i in range(n_reps):
       sample = rng.normal(mu0, sigma, n)
       t_stat = np.mean(sample) / (np.std(sample, ddof=1) / np.sqrt(n))
       pvals_h0[i] = 2 * stats.t.sf(abs(t_stat), df=n-1)

   # Under H₁: μ = 0.5
   mu1 = 0.5
   pvals_h1 = np.zeros(n_reps)
   for i in range(n_reps):
       sample = rng.normal(mu1, sigma, n)
       t_stat = np.mean(sample) / (np.std(sample, ddof=1) / np.sqrt(n))
       pvals_h1[i] = 2 * stats.t.sf(abs(t_stat), df=n-1)

   print("P-value distributions (two-sided t-test, n=25):")
   print()
   print("Under H₀ (μ = 0):")
   print(f"  Mean p-value: {np.mean(pvals_h0):.4f} (theory: 0.5000)")
   print(f"  Reject at α=0.05: {np.mean(pvals_h0 < 0.05):.4f} "
         f"(theory: 0.0500)")
   print(f"  Reject at α=0.01: {np.mean(pvals_h0 < 0.01):.4f} "
         f"(theory: 0.0100)")
   print(f"  Uniform check — fraction in [0.0, 0.1]: "
         f"{np.mean(pvals_h0 < 0.1):.4f} (theory: 0.1000)")
   print(f"  Uniform check — fraction in [0.4, 0.6]: "
         f"{np.mean((pvals_h0 >= 0.4) & (pvals_h0 < 0.6)):.4f} "
         f"(theory: 0.2000)")
   print()
   print("Under H₁ (μ = 0.5, δ/σ = 0.5):")
   print(f"  Mean p-value: {np.mean(pvals_h1):.4f}")
   print(f"  Power at α=0.05: {np.mean(pvals_h1 < 0.05):.4f}")
   print(f"  Power at α=0.01: {np.mean(pvals_h1 < 0.01):.4f}")

.. code-block:: text

Power Analysis
~~~~~~~~~~~~~~~

Power depends on four quantities: the significance level :math:`\alpha`, the sample size :math:`n`, the effect size :math:`\delta = |\theta_1 - \theta_0|`, and the variability :math:`\sigma`. Specifying any three determines the fourth.

.. admonition:: Derivation: Power of the One-Sample z-Test
   :class: dropdown

   Consider testing :math:`H_0: \mu = \mu_0` versus :math:`H_1: \mu > \mu_0` at level :math:`\alpha`, with :math:`\sigma` known. The test rejects when :math:`Z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}} > z_\alpha`.

   Under the alternative :math:`\mu = \mu_1 > \mu_0`:

   .. math::

      Z = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}} = \frac{\bar{X} - \mu_1}{\sigma/\sqrt{n}} + \frac{\mu_1 - \mu_0}{\sigma/\sqrt{n}}

   The first term is :math:`\sim N(0,1)` under :math:`\mu_1`, and the second is the non-centrality parameter :math:`\delta\sqrt{n}/\sigma` where :math:`\delta = \mu_1 - \mu_0`. Thus under :math:`H_1`:

   .. math::

      \pi(\mu_1) &= P(Z > z_\alpha \mid \mu = \mu_1) \\
      &= P\!\left(\frac{\bar{X} - \mu_1}{\sigma/\sqrt{n}} > z_\alpha - \frac{\delta\sqrt{n}}{\sigma}\right) \\
      &= 1 - \Phi\!\left(z_\alpha - \frac{\delta\sqrt{n}}{\sigma}\right)

   This is the **power function**. It increases with :math:`\delta` (larger effects are easier to detect), with :math:`n` (more data means more power), and decreases with :math:`\sigma` (more noise means less power).

The Neyman-Pearson Lemma
~~~~~~~~~~~~~~~~~~~~~~~~~~

The Neyman-Pearson lemma answers a fundamental question: among all level-:math:`\alpha` tests of a simple null against a simple alternative, which is most powerful?

**Intuition.** If we must decide between two specific distributions :math:`f(\mathbf{x}; \theta_0)` and :math:`f(\mathbf{x}; \theta_1)`, the most informative quantity is how much more likely the data are under one than the other — the likelihood ratio :math:`\Lambda(\mathbf{x}) = f(\mathbf{x};\theta_1)/f(\mathbf{x};\theta_0)`. Points with high :math:`\Lambda` are strong evidence for :math:`\theta_1`; points with low :math:`\Lambda` favor :math:`\theta_0`. The Neyman-Pearson lemma proves that no test can do better than simply thresholding :math:`\Lambda`: any other rejection region of the same size :math:`\alpha` must capture less of the :math:`\theta_1`-distribution. The proof is essentially an accounting argument — by moving probability mass from the NP rejection region to any other region, we always trade high-:math:`\Lambda` points (which contribute more power per unit of :math:`\alpha`) for low-:math:`\Lambda` points (which contribute less). This optimality principle is why likelihood ratios appear at the foundation of virtually all testing theory.

.. admonition:: Theorem: Neyman-Pearson Lemma
   :class: note

   Let :math:`X_1, \ldots, X_n` have joint density :math:`f(\mathbf{x}; \theta)`. For testing :math:`H_0: \theta = \theta_0` versus :math:`H_1: \theta = \theta_1`, the **most powerful** level-:math:`\alpha` test rejects :math:`H_0` when the **likelihood ratio** exceeds a threshold:

   .. math::

      \Lambda(\mathbf{x}) = \frac{f(\mathbf{x}; \theta_1)}{f(\mathbf{x}; \theta_0)} > k

   where :math:`k` is chosen so that :math:`P_{\theta_0}(\Lambda > k) = \alpha`.

.. admonition:: Proof
   :class: dropdown

   Let :math:`\phi^*` be the Neyman-Pearson test (reject when :math:`\Lambda > k`) and :math:`\phi` be any other level-:math:`\alpha` test. We need to show :math:`\mathbb{E}_{\theta_1}[\phi^*] \ge \mathbb{E}_{\theta_1}[\phi]`.

   Consider:

   .. math::

      \mathbb{E}_{\theta_1}[\phi^* - \phi] = \int (\phi^*(\mathbf{x}) - \phi(\mathbf{x})) f(\mathbf{x}; \theta_1)\, d\mathbf{x}

   In the rejection region of :math:`\phi^*`, we have :math:`f(\mathbf{x}; \theta_1) > k \cdot f(\mathbf{x}; \theta_0)` and :math:`\phi^* = 1`, so :math:`\phi^* - \phi \ge 0`. In the acceptance region, :math:`f(\mathbf{x}; \theta_1) \le k \cdot f(\mathbf{x}; \theta_0)` and :math:`\phi^* = 0`, so :math:`\phi^* - \phi \le 0`. Therefore:

   .. math::

      (\phi^*(\mathbf{x}) - \phi(\mathbf{x}))(f(\mathbf{x}; \theta_1) - k\, f(\mathbf{x}; \theta_0)) \ge 0 \quad \text{for all } \mathbf{x}

   Integrating:

   .. math::

      \int (\phi^* - \phi)(f(\mathbf{x}; \theta_1) - k\, f(\mathbf{x}; \theta_0))\, d\mathbf{x} \ge 0

   Expanding:

   .. math::

      \mathbb{E}_{\theta_1}[\phi^* - \phi] \ge k\, \mathbb{E}_{\theta_0}[\phi^* - \phi] = k(\alpha - \mathbb{E}_{\theta_0}[\phi]) \ge 0

   since :math:`\mathbb{E}_{\theta_0}[\phi] \le \alpha` (both tests are level-:math:`\alpha`). Therefore :math:`\mathbb{E}_{\theta_1}[\phi^*] \ge \mathbb{E}_{\theta_1}[\phi]`, and :math:`\phi^*` is the most powerful test.

The lemma tells us that likelihood ratios are the natural currency of hypothesis testing. For simple vs simple hypotheses, the LR test is provably optimal.


Uniformly Most Powerful Tests
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

For composite alternatives (:math:`H_1: \theta > \theta_0`), a test is **uniformly most powerful (UMP)** at level :math:`\alpha` if it is the most powerful test against every :math:`\theta_1 > \theta_0` simultaneously.

.. admonition:: Definition
   :class: definition

   A family of densities :math:`f(x;\theta)` has **monotone likelihood ratio (MLR)** in a statistic :math:`T(x)` if for :math:`\theta_1 > \theta_0`, the ratio :math:`f(\mathbf{x};\theta_1)/f(\mathbf{x};\theta_0)` is a non-decreasing function of :math:`T(\mathbf{x})`. All one-parameter exponential families have MLR in the natural sufficient statistic.

.. admonition:: Theorem: Karlin-Rubin
   :class: note

   If the family has MLR in :math:`T`, then the test that rejects :math:`H_0: \theta \le \theta_0` when :math:`T > c` (where :math:`c` satisfies :math:`P_{\theta_0}(T > c) = \alpha`) is UMP at level :math:`\alpha` for :math:`H_1: \theta > \theta_0`.

.. admonition:: Proof Sketch
   :class: dropdown

   By the Neyman-Pearson lemma, the most powerful test of :math:`H_0: \theta = \theta_0` versus any simple :math:`H_1: \theta = \theta_1 > \theta_0` rejects when :math:`\Lambda = f(\mathbf{x};\theta_1)/f(\mathbf{x};\theta_0) > k`. Since the family has MLR in :math:`T`, :math:`\Lambda > k` is equivalent to :math:`T > c` for some :math:`c`. Crucially, the threshold :math:`c` is determined by the size constraint :math:`P_{\theta_0}(T > c) = \alpha`, which does not depend on :math:`\theta_1`. Therefore the same rejection region :math:`\{T > c\}` is most powerful against every :math:`\theta_1 > \theta_0` — it is UMP.

**Example:** For Poisson(:math:`\lambda`) data, testing :math:`H_0: \lambda \le \lambda_0` versus :math:`H_1: \lambda > \lambda_0`, the UMP test rejects when :math:`\sum X_i > c`. No test can do better for one-sided alternatives.

**Non-existence of two-sided UMP tests.** For two-sided alternatives (:math:`H_1: \theta \ne \theta_0`), a UMP test generally does not exist. A test that is powerful against :math:`\theta_1 > \theta_0` (rejecting for large :math:`T`) sacrifices power against :math:`\theta_1 < \theta_0`. The two-sided :math:`t`-test is a practical compromise, splitting :math:`\alpha` between both tails, but it is not UMP. The **likelihood ratio test** provides a principled approach to two-sided and multiparameter problems.


Common Hypothesis Tests
~~~~~~~~~~~~~~~~~~~~~~~~~

**One-sample t-test.** For :math:`H_0: \mu = \mu_0` with unknown :math:`\sigma`:

.. math::

   T = \frac{\bar{X} - \mu_0}{S/\sqrt{n}} \sim t_{n-1} \quad \text{under } H_0

Reject :math:`H_0` if :math:`|T| > t_{\alpha/2,\, n-1}` (two-sided) or :math:`T > t_{\alpha,\, n-1}` (one-sided).

**Two-sample t-test.** For :math:`H_0: \mu_1 = \mu_2` with independent samples of sizes :math:`n_1, n_2`:

.. math::

   T = \frac{\bar{X}_1 - \bar{X}_2}{S_p\sqrt{1/n_1 + 1/n_2}}, \qquad S_p^2 = \frac{(n_1-1)S_1^2 + (n_2-1)S_2^2}{n_1 + n_2 - 2}

where :math:`S_p^2` is the **pooled variance**. Under :math:`H_0` with equal variances: :math:`T \sim t_{n_1+n_2-2}`.

**Paired t-test.** For matched pairs :math:`(X_i, Y_i)`, define :math:`D_i = X_i - Y_i` and test :math:`H_0: \mu_D = 0`:

.. math::

   T = \frac{\bar{D}}{S_D/\sqrt{n}} \sim t_{n-1} \quad \text{under } H_0

**Chi-squared goodness-of-fit test.** For testing whether observed counts :math:`O_1, \ldots, O_k` match expected counts :math:`E_1, \ldots, E_k`:

.. math::

   \chi^2 = \sum_{j=1}^k \frac{(O_j - E_j)^2}{E_j} \;\xrightarrow{d}\; \chi^2_{k-1-p}

where :math:`p` is the number of parameters estimated from the data. The approximation requires :math:`E_j \ge 5` for all cells (a rough guideline).

**F-test for equal variances.** For :math:`H_0: \sigma_1^2 = \sigma_2^2` with independent normal samples:

.. math::

   F = \frac{S_1^2}{S_2^2} \sim F_{n_1-1,\, n_2-1} \quad \text{under } H_0

The F-distribution also arises in ANOVA and regression (testing whether groups of coefficients are jointly zero).


Multiple Testing
~~~~~~~~~~~~~~~~~

When conducting :math:`m` hypothesis tests simultaneously, the probability of at least one false rejection grows rapidly even if each individual test controls :math:`\alpha`.

.. admonition:: Definition
   :class: definition

   - **Family-wise error rate (FWER):** :math:`P(\text{at least one false rejection})`. With :math:`m` independent tests at level :math:`\alpha`: :math:`\text{FWER} = 1 - (1-\alpha)^m`. For :math:`m = 20` at :math:`\alpha = 0.05`: :math:`\text{FWER} = 0.64`.
   - **False discovery rate (FDR):** :math:`\mathbb{E}\!\left[\frac{\text{false rejections}}{\text{total rejections}}\right]`, with :math:`0/0 = 0` by convention. The FDR controls the expected proportion of false discoveries, making it less conservative than FWER control.

**Bonferroni correction.** Reject the :math:`i`-th null when :math:`p_i < \alpha/m`. This controls :math:`\text{FWER} \le \alpha` (by the union bound) but is conservative — it substantially reduces power.

**Benjamini-Hochberg (BH) procedure.** Sort p-values: :math:`p_{(1)} \le \cdots \le p_{(m)}`. Find the largest :math:`k` such that :math:`p_{(k)} \le \frac{k}{m}\alpha`. Reject all :math:`H_{(1)}, \ldots, H_{(k)}`. This controls :math:`\text{FDR} \le \alpha` (under independence or positive regression dependency) while retaining more power than Bonferroni.

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # Multiple testing demo
   n_tests = 200
   n_true_null = 180
   n_true_alt = 20
   delta = 0.5
   n_per_test = 30
   alpha = 0.05

   p_values = np.zeros(n_tests)
   is_null = np.zeros(n_tests, dtype=bool)
   is_null[:n_true_null] = True

   for i in range(n_tests):
       if is_null[i]:
           sample = rng.normal(0, 1, n_per_test)
       else:
           sample = rng.normal(delta, 1, n_per_test)
       t_stat = (np.mean(sample)
                 / (np.std(sample, ddof=1) / np.sqrt(n_per_test)))
       p_values[i] = 2 * stats.t.sf(abs(t_stat), df=n_per_test-1)

   # Bonferroni
   bonf_reject = p_values < alpha / n_tests

   # Benjamini-Hochberg
   sorted_idx = np.argsort(p_values)
   sorted_p = p_values[sorted_idx]
   m = n_tests
   bh_threshold = np.arange(1, m+1) * alpha / m
   bh_reject_sorted = np.zeros(m, dtype=bool)
   k_max = 0
   for k in range(m):
       if sorted_p[k] <= bh_threshold[k]:
           k_max = k + 1
   bh_reject_sorted[:k_max] = True
   bh_reject = np.zeros(m, dtype=bool)
   bh_reject[sorted_idx] = bh_reject_sorted

   # Unadjusted
   raw_reject = p_values < alpha

   def metrics(reject, is_null):
       fp = np.sum(reject & is_null)
       tp = np.sum(reject & ~is_null)
       total = np.sum(reject)
       fdr = fp / total if total > 0 else 0
       power = tp / np.sum(~is_null)
       fwer = 1 if fp > 0 else 0
       return total, fp, tp, fdr, power, fwer

   print(f"Multiple testing: {n_tests} tests "
         f"({n_true_null} true nulls, "
         f"{n_true_alt} alternatives with δ={delta})")
   print(f"Each test: two-sided t-test with n={n_per_test}")
   print()
   print(f"{'Method':>15}  {'Rejected':>8}  {'FP':>4}  "
         f"{'TP':>4}  {'FDR':>7}  {'Power':>7}  {'FWER':>5}")
   print("-" * 60)

   for name, reject in [("Unadjusted", raw_reject),
                         ("Bonferroni", bonf_reject),
                         ("BH (FDR)", bh_reject)]:
       total, fp, tp, fdr, power, fwer = metrics(reject, is_null)
       print(f"{name:>15}  {total:>8}  {fp:>4}  {tp:>4}  "
             f"{fdr:>7.3f}  {power:>7.3f}  {fwer:>5}")

.. code-block:: text

   Multiple testing: 200 tests (180 true nulls, 20 alternatives with δ=0.5)
   Each test: two-sided t-test with n=30

            Method  Rejected    FP    TP      FDR    Power   FWER
   ------------------------------------------------------------
        Unadjusted        25    11    14    0.440    0.700      1
        Bonferroni         5     0     5    0.000    0.250      0
          BH (FDR)         8     0     8    0.000    0.400      0

The tradeoff is stark. Unadjusted testing rejects 25 hypotheses with 70% power, but 44% of its discoveries are false (11 out of 25). Bonferroni eliminates all false positives but only finds 5 of the 20 true effects (25% power). BH strikes a middle ground: zero false discoveries in this realization while recovering 8 of the 20 effects. In repeated realizations, BH would allow some false discoveries but controls their expected *proportion* at :math:`\le \alpha = 0.05`.

.. admonition:: Statistical Application
   :class: tip

   The Neyman-Pearson lemma motivates the **likelihood ratio test** developed in :ref:`ch3_2-maximum-likelihood-estimation`. The Wald and score tests are asymptotic approximations to the LRT, all sharing the same :math:`\chi^2` limiting distribution. Multiple testing corrections are critical in genomics, A/B testing, and any setting where many hypotheses are tested simultaneously.


Sufficiency and Information
----------------------------

Sufficient Statistics
~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   A statistic :math:`T(\mathbf{X})` is **sufficient** for :math:`\theta` if the conditional distribution of the data :math:`\mathbf{X}` given :math:`T(\mathbf{X}) = t` does not depend on :math:`\theta`.

Intuitively, a sufficient statistic captures everything the data can tell us about :math:`\theta`. Once we know :math:`T`, the remaining randomness in :math:`\mathbf{X}` is pure noise — no further information about :math:`\theta` is available. This is a powerful idea: we can reduce an entire dataset to a (usually low-dimensional) summary without losing any information about the parameter.


The Fisher-Neyman Factorization Theorem
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Checking the definition of sufficiency directly (computing conditional distributions) is usually difficult. The factorization theorem provides an elegant shortcut.

.. admonition:: Theorem: Fisher-Neyman Factorization
   :class: note

   A statistic :math:`T(\mathbf{X})` is sufficient for :math:`\theta` if and only if the joint density (or PMF) can be written as

   .. math::

      f(\mathbf{x}; \theta) = g(T(\mathbf{x}), \theta) \cdot h(\mathbf{x})

   where :math:`g` depends on :math:`\mathbf{x}` only through :math:`T(\mathbf{x})`, and :math:`h` does not depend on :math:`\theta`.

.. admonition:: Proof (Discrete Case)
   :class: dropdown

   **Sufficiency ⟹ Factorization.** If :math:`T` is sufficient, then :math:`P(\mathbf{X} = \mathbf{x} \mid T = t)` does not depend on :math:`\theta`. Write:

   .. math::

      f(\mathbf{x}; \theta) = P(\mathbf{X} = \mathbf{x}, T = t) = P(\mathbf{X} = \mathbf{x} \mid T = t) \cdot P(T = t; \theta)

   where :math:`t = T(\mathbf{x})`. Set :math:`g(t, \theta) = P(T = t; \theta)` and :math:`h(\mathbf{x}) = P(\mathbf{X} = \mathbf{x} \mid T = T(\mathbf{x}))`.

   **Factorization ⟹ Sufficiency.** If :math:`f(\mathbf{x}; \theta) = g(T(\mathbf{x}), \theta) \cdot h(\mathbf{x})`, then:

   .. math::

      P(\mathbf{X} = \mathbf{x} \mid T = t) = \frac{P(\mathbf{X} = \mathbf{x})}{\sum_{\{\mathbf{y}: T(\mathbf{y})=t\}} P(\mathbf{Y} = \mathbf{y})} = \frac{g(t,\theta)\, h(\mathbf{x})}{\sum_{\{\mathbf{y}: T(\mathbf{y})=t\}} g(t,\theta)\, h(\mathbf{y})} = \frac{h(\mathbf{x})}{\sum_{\{\mathbf{y}: T(\mathbf{y})=t\}} h(\mathbf{y})}

   The :math:`g(t,\theta)` cancels, so the conditional distribution does not depend on :math:`\theta`.


Examples of Sufficient Statistics
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

**Normal** :math:`(\mu, \sigma^2)`: The joint density is

.. math::

   f(\mathbf{x}; \mu, \sigma^2) = (2\pi\sigma^2)^{-n/2} \exp\!\left(-\frac{1}{2\sigma^2}\sum(x_i - \mu)^2\right) = (2\pi\sigma^2)^{-n/2} \exp\!\left(-\frac{n\mu^2 + \sum x_i^2 - 2\mu n\bar{x}}{2\sigma^2}\right)

The exponent depends on :math:`\mathbf{x}` only through :math:`(\sum x_i, \sum x_i^2)`, so :math:`T = (\bar{X}, S^2)` — equivalently :math:`(\sum X_i, \sum X_i^2)` — is jointly sufficient for :math:`(\mu, \sigma^2)`.

**Poisson** :math:`(\lambda)`: :math:`f(\mathbf{x}; \lambda) = \prod \frac{\lambda^{x_i} e^{-\lambda}}{x_i!} = \frac{\lambda^{\sum x_i} e^{-n\lambda}}{\prod x_i!}`. The :math:`\theta`-dependent part involves :math:`\mathbf{x}` only through :math:`\sum x_i`, so :math:`T = \sum X_i` is sufficient for :math:`\lambda`.

**Uniform** :math:`(0, \theta)`: :math:`f(\mathbf{x}; \theta) = \theta^{-n} \cdot \prod \mathbf{1}(0 \le x_i \le \theta) = \theta^{-n} \cdot \mathbf{1}(x_{(n)} \le \theta) \cdot \prod \mathbf{1}(x_i \ge 0)`. The :math:`\theta`-dependent part involves :math:`\mathbf{x}` only through :math:`x_{(n)} = \max(x_i)`, so :math:`T = X_{(n)}` is sufficient for :math:`\theta`.


Minimal Sufficiency
~~~~~~~~~~~~~~~~~~~~

A sufficient statistic is **minimal sufficient** if it achieves the greatest data reduction — it is a function of every other sufficient statistic. To find a minimal sufficient statistic, use the **likelihood ratio method**: :math:`T(\mathbf{x}) = T(\mathbf{y})` if and only if the ratio :math:`f(\mathbf{x};\theta)/f(\mathbf{y};\theta)` does not depend on :math:`\theta`.

For example, for Normal :math:`(\mu, \sigma^2)`, computing :math:`f(\mathbf{x};\mu,\sigma^2)/f(\mathbf{y};\mu,\sigma^2)` shows the ratio is free of :math:`(\mu, \sigma^2)` exactly when :math:`\bar{x} = \bar{y}` and :math:`\sum x_i^2 = \sum y_i^2`, confirming that :math:`(\bar{X}, \sum X_i^2)` is minimal sufficient.


Completeness
~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   A family of distributions for a statistic :math:`T` is **complete** if :math:`\mathbb{E}_\theta[g(T)] = 0` for all :math:`\theta` implies :math:`P_\theta(g(T) = 0) = 1` for all :math:`\theta`.

Completeness means the sufficient statistic carries no "wasted" randomness — there is no non-trivial function of :math:`T` that is identically zero in expectation across all parameter values. For exponential families with open natural parameter spaces, the natural sufficient statistic is always complete. This includes Normal, Poisson, Binomial, Exponential, Gamma, and Beta families.

Completeness is the key ingredient that, combined with sufficiency, yields the UMVUE through the Lehmann-Scheffé theorem (stated in the Point Estimation section above): if :math:`T` is complete sufficient and :math:`h(T)` is unbiased for :math:`g(\theta)`, then :math:`h(T)` is the unique UMVUE.


Ancillary Statistics and Basu's Theorem
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   A statistic :math:`A(\mathbf{X})` is **ancillary** for :math:`\theta` if its distribution does not depend on :math:`\theta`. Ancillary statistics carry no information about :math:`\theta` on their own, yet they can affect the precision of other estimators.

**Example:** For :math:`X_1, \ldots, X_n \sim N(\mu, 1)`, the sample range :math:`R = X_{(n)} - X_{(1)}` is ancillary for :math:`\mu`: shifting all observations by a constant changes :math:`\bar{X}` but not :math:`R`. While :math:`R` tells us nothing about :math:`\mu` directly, it indicates how spread out the sample is, which affects how precisely :math:`\bar{X}` estimates :math:`\mu`.

.. admonition:: Theorem: Basu's Theorem
   :class: note

   If :math:`T` is a complete sufficient statistic and :math:`A` is ancillary, then :math:`T` and :math:`A` are independent. (Proof omitted.)

Basu's theorem is elegant: it says that a complete sufficient statistic and an ancillary statistic live in "orthogonal" parts of the sample space. This has practical consequences — for example, for :math:`X_1, \ldots, X_n \sim N(\mu, \sigma^2)` with :math:`\sigma^2` known, :math:`\bar{X}` is complete sufficient for :math:`\mu` while :math:`S^2` is ancillary (its distribution :math:`\sigma^2 \chi^2_{n-1}/(n-1)` does not involve :math:`\mu`), so Basu's theorem delivers the independence of :math:`\bar{X}` and :math:`S^2` — the key fact behind the :math:`t`-distribution — without any calculation.


Fisher Information
~~~~~~~~~~~~~~~~~~~

Fisher information quantifies how much information a single observation carries about :math:`\theta`.

**Intuition.** Consider the log-likelihood :math:`\ell(\theta)` as a landscape over the parameter space. At the true :math:`\theta`, the log-likelihood is (on average) at its peak. Fisher information measures the *curvature* of this peak: a sharp, narrow peak means the data are highly informative (the likelihood strongly distinguishes nearby parameter values), while a broad, flat peak means the data carry little information (many parameter values are nearly equally plausible). Formally, Fisher information is the expected curvature :math:`-\mathbb{E}[\ell''(\theta)]`, or equivalently, the variance of the score. High curvature means the score changes rapidly — the derivative of the log-likelihood is volatile across samples — which means the data are highly sensitive to :math:`\theta`. This geometric picture directly connects to estimation precision: sharper peaks yield more precise estimators, a relationship made exact by the Cramér-Rao bound below.

.. admonition:: Definition
   :class: definition

   The **score function** is the gradient of the log-likelihood with respect to :math:`\theta`:

   .. math::

      U(\theta) = \frac{\partial}{\partial\theta}\log f(X; \theta)

   The **Fisher information** for a single observation is:

   .. math::

      I_1(\theta) = \text{Var}_\theta\!\left(U(\theta)\right) = \mathbb{E}_\theta\!\left[U(\theta)^2\right]

   The second equality holds because :math:`\mathbb{E}[U(\theta)] = 0` (proved below).

.. admonition:: Notation Convention
   :class: important

   - :math:`I_1(\theta)` = Fisher information from a **single observation**
   - :math:`I_n(\theta) = n \cdot I_1(\theta)` = total Fisher information from :math:`n` iid observations
   - :math:`I(\theta) = -\mathbb{E}\!\left[\frac{\partial^2 \ell}{\partial \theta^2}\right]` = **expected** (Fisher) information
   - :math:`J(\hat{\theta}) = -\frac{\partial^2 \ell}{\partial \theta^2}\big|_{\hat{\theta}}` = **observed** information (data-dependent, evaluated at the MLE)

   Under correct model specification, :math:`\mathbb{E}[J(\theta_0)] = I(\theta_0)`. Under misspecification, these may differ — see :ref:`ch3_2-maximum-likelihood-estimation` for the sandwich variance estimator.

.. admonition:: Theorem: :math:`\mathbb{E}[U(\theta)] = 0`
   :class: note

   Under regularity conditions (interchange of differentiation and integration), the expected score is zero.

.. admonition:: Proof
   :class: dropdown

   Since :math:`\int f(x; \theta)\, dx = 1` for all :math:`\theta`, differentiating both sides with respect to :math:`\theta`:

   .. math::

      0 = \frac{\partial}{\partial\theta}\int f(x;\theta)\, dx = \int \frac{\partial}{\partial\theta} f(x;\theta)\, dx = \int \frac{f'(x;\theta)}{f(x;\theta)} f(x;\theta)\, dx = \mathbb{E}\!\left[\frac{\partial}{\partial\theta}\log f(X;\theta)\right] = \mathbb{E}[U(\theta)]


Two Equivalent Forms of Fisher Information
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem
   :class: note

   Under regularity conditions:

   .. math::

      I_1(\theta) = \text{Var}_\theta(U(\theta)) = -\mathbb{E}_\theta\!\left[\frac{\partial^2}{\partial\theta^2}\log f(X;\theta)\right]

   That is, Fisher information equals the variance of the score, and also equals the negative expected curvature of the log-likelihood.

.. admonition:: Proof of Equivalence
   :class: dropdown

   Starting from :math:`\mathbb{E}[U(\theta)] = 0 = \int \frac{\partial}{\partial\theta}\log f(x;\theta) \cdot f(x;\theta)\, dx`, differentiate again with respect to :math:`\theta`:

   .. math::

      0 &= \frac{\partial}{\partial\theta}\int \frac{\partial \log f}{\partial\theta}\, f\, dx \\
      &= \int \left[\frac{\partial^2 \log f}{\partial\theta^2}\, f + \frac{\partial \log f}{\partial\theta}\, \frac{\partial f}{\partial\theta}\right] dx \\
      &= \int \frac{\partial^2 \log f}{\partial\theta^2}\, f\, dx + \int \left(\frac{\partial \log f}{\partial\theta}\right)^2 f\, dx

   since :math:`\frac{\partial f}{\partial\theta} = f \cdot \frac{\partial \log f}{\partial\theta}`. Therefore:

   .. math::

      \mathbb{E}\!\left[\left(\frac{\partial \log f}{\partial\theta}\right)^2\right] = -\mathbb{E}\!\left[\frac{\partial^2 \log f}{\partial\theta^2}\right]

   The left side is :math:`\text{Var}(U(\theta))` (since :math:`\mathbb{E}[U] = 0`), and the right side is :math:`-\mathbb{E}[\ell''(\theta)]`. Both equal :math:`I_1(\theta)`.

The second form is often easier to compute: take the second derivative of the log-likelihood and negate its expectation. The first form (score variance) is more natural for simulation-based verification.

**Additive property.** For an iid sample of size :math:`n`: :math:`I_n(\theta) = n \cdot I_1(\theta)`. The total information scales linearly with :math:`n` — this is why standard errors shrink like :math:`1/\sqrt{n}`.

**Fisher information for common distributions:**

.. list-table::
   :header-rows: 1
   :stub-columns: 1
   :widths: 30 25 25

   * - Distribution
     - Parameter
     - :math:`I_1(\theta)`
   * - Bernoulli(:math:`p`)
     - :math:`p`
     - :math:`\frac{1}{p(1-p)}`
   * - Poisson(:math:`\lambda`)
     - :math:`\lambda`
     - :math:`\frac{1}{\lambda}`
   * - Normal(:math:`\mu, \sigma^2` known)
     - :math:`\mu`
     - :math:`\frac{1}{\sigma^2}`
   * - Exponential(:math:`\lambda`)
     - :math:`\lambda`
     - :math:`\frac{1}{\lambda^2}`

.. code-block:: python

   from scipy import stats

   rng = np.random.default_rng(42)

   n_samples = 50000

   print("Fisher information verification via score variance")
   print(f"({n_samples:,} single-observation samples)")
   print()
   print(f"{'Distribution':>20}  {'I₁(θ) theory':>13}  "
         f"{'Var(score) sim':>15}  {'Ratio':>7}")
   print("-" * 70)

   # Poisson(λ=3): score = x/λ - 1, I₁ = 1/λ
   lam = 3.0

   sim = np.var(score)
   print(f"{'Poisson(λ=3)':>20}  {theory:>13.6f}  "
         f"{sim:>15.6f}  {sim/theory:>7.4f}")

   # Normal(μ=5, σ²=4): score = (x-μ)/σ², I₁ = 1/σ²
   mu, sigma2 = 5.0, 4.0
   x = rng.normal(mu, np.sqrt(sigma2), n_samples)
   score = (x - mu) / sigma2
   theory = 1.0 / sigma2
   sim = np.var(score)
   print(f"{'Normal(μ=5, σ²=4)':>20}  {theory:>13.6f}  "
         f"{sim:>15.6f}  {sim/theory:>7.4f}")

   # Exp(λ=2): score = 1/λ - x, I₁ = 1/λ²
   lam_exp = 2.0
   x = rng.exponential(1.0/lam_exp, n_samples)
   score = 1.0/lam_exp - x
   theory = 1.0 / lam_exp**2
   sim = np.var(score)
   print(f"{'Exp(λ=2)':>20}  {theory:>13.6f}  "
         f"{sim:>15.6f}  {sim/theory:>7.4f}")

   # Bernoulli(p=0.3): score = x/p - (1-x)/(1-p), I₁ = 1/(p(1-p))
   p = 0.3
   x = rng.binomial(1, p, n_samples)
   score = x/p - (1-x)/(1-p)
   theory = 1.0 / (p * (1-p))
   sim = np.var(score)
   print(f"{'Bernoulli(p=0.3)':>20}  {theory:>13.6f}  "
         f"{sim:>15.6f}  {sim/theory:>7.4f}")

The Cramér-Rao Lower Bound
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Cramér-Rao Lower Bound (CRLB)
   :class: note

   Let :math:`T = T(X_1, \ldots, X_n)` be any unbiased estimator of :math:`\tau(\theta)`, a differentiable function of the parameter, based on an iid sample of size :math:`n`. Under regularity conditions — R4–R6 (differentiability, interchange of differentiation and integration, finite Fisher information) of the :ref:`regularity conditions <appendix-e-regularity-conditions>` stated in the Asymptotic Theory section:

   .. math::

      \text{Var}_\theta(T) \ge \frac{[\tau'(\theta)]^2}{n \, I_1(\theta)}

   For estimating :math:`\theta` itself (:math:`\tau(\theta) = \theta`, so :math:`\tau'(\theta) = 1`):

   .. math::

      \text{Var}(\hat{\theta}) \ge \frac{1}{n \, I_1(\theta)}

   No unbiased estimator can have variance below this bound. An estimator achieving equality is called **efficient**.

**Intuition.** The CRLB says there is a fundamental speed limit on estimation precision: no matter how clever our unbiased estimator, the data themselves impose a floor on how precise we can be. The bound is :math:`1/(nI_1(\theta))` — inversely proportional to both the sample size and the per-observation information. This makes sense: more data and more informative observations both shrink the bound. The proof uses the Cauchy-Schwarz inequality to show that the correlation between any unbiased estimator and the score function is constrained, and this constraint propagates directly into a variance lower bound. When an estimator achieves equality (is efficient), it extracts every last bit of information from the data — it is perfectly correlated with the score. For exponential families, the natural sufficient statistic achieves this; for other families, no unbiased estimator may reach the bound, but the MLE approaches it as :math:`n \to \infty`.

.. admonition:: Proof via Cauchy-Schwarz
   :class: dropdown

   Let :math:`U_n(\theta) = \sum_{i=1}^n \frac{\partial}{\partial\theta}\log f(X_i;\theta)` be the total score. We know :math:`\mathbb{E}[U_n] = 0` and :math:`\text{Var}(U_n) = n\,I_1(\theta)`. Let :math:`T` be an unbiased estimator of :math:`\tau(\theta)`.

   **Step 1: Differentiate the unbiasedness condition.** Since :math:`\mathbb{E}_\theta[T] = \tau(\theta)`:

   .. math::

      \tau(\theta) = \int T(\mathbf{x})\, f(\mathbf{x};\theta)\, d\mathbf{x}

   Differentiating both sides with respect to :math:`\theta` and using :math:`\frac{\partial f}{\partial\theta} = f \cdot \frac{\partial \log f}{\partial\theta}`:

   .. math::

      \tau'(\theta) = \int T(\mathbf{x})\, f(\mathbf{x};\theta)\, \frac{\partial \log f(\mathbf{x};\theta)}{\partial\theta}\, d\mathbf{x} = \mathbb{E}_\theta[T \cdot U_n]

   **Step 2: Compute the covariance.** Since :math:`\mathbb{E}[U_n] = 0`:

   .. math::

      \text{Cov}_\theta(T, U_n) = \mathbb{E}_\theta[T \cdot U_n] - \mathbb{E}_\theta[T] \cdot \mathbb{E}_\theta[U_n] = \tau'(\theta)

   **Step 3: Apply Cauchy-Schwarz.** For any random variables :math:`A, B`: :math:`[\text{Cov}(A,B)]^2 \le \text{Var}(A) \cdot \text{Var}(B)`. Applied to :math:`T` and :math:`U_n`:

   .. math::

      [\tau'(\theta)]^2 = [\text{Cov}(T, U_n)]^2 \le \text{Var}(T) \cdot \text{Var}(U_n) = \text{Var}(T) \cdot n\,I_1(\theta)

   Rearranging: :math:`\text{Var}(T) \ge \frac{[\tau'(\theta)]^2}{n\,I_1(\theta)}`. For :math:`\tau(\theta) = \theta`, this gives :math:`\text{Var}(\hat{\theta}) \ge \frac{1}{n\,I_1(\theta)}`. Equality holds iff :math:`T` is an affine function of :math:`U_n`, which occurs precisely for exponential family distributions with their natural sufficient statistics.

**When is the CRLB achieved?** For exponential family distributions, the MLE achieves the CRLB exactly. For example, :math:`\bar{X}` for Normal :math:`(\mu)` has :math:`\text{Var}(\bar{X}) = \sigma^2/n = 1/(n \cdot 1/\sigma^2) = 1/(n\,I_1(\mu))`. For non-exponential families, no unbiased estimator may achieve the bound, but the MLE approaches it asymptotically (see the Asymptotic Theory section below).

.. code-block:: python

   import numpy as np

   rng = np.random.default_rng(42)

   # Verify CRLB: Var(x̄) vs 1/(n·I₁) for Poisson(λ=3)
   lam = 3.0
   I1 = 1.0 / lam
   n_reps = 50000

   print("CRLB verification: Var(x̄) vs 1/(nI₁) for Poisson(λ=3)")
   print(f"I₁(λ) = 1/λ = {I1:.6f}")
   print()
   print(f"{'n':>6}  {'Var(x̄) sim':>12}  "
         f"{'CRLB = 1/(nI₁)':>16}  {'Ratio':>7}")
   print("-" * 50)

   for n in [10, 25, 50, 100, 500]:
       xbar = np.zeros(n_reps)
       for i in range(n_reps):
           xbar[i] = np.mean(rng.poisson(lam, n))
       var_sim = np.var(xbar)
       crlb = 1.0 / (n * I1)
       print(f"{n:>6}  {var_sim:>12.6f}  {crlb:>16.6f}  "
             f"{var_sim/crlb:>7.4f}")

Efficiency of Estimators
~~~~~~~~~~~~~~~~~~~~~~~~~~

Not all estimators are equally efficient. The following comparison illustrates efficiency loss when using a suboptimal estimator.

.. code-block:: python

   import numpy as np

   rng = np.random.default_rng(42)

   # Efficiency comparison: Exp(λ) — MLE vs median-based
   lam_true = 2.0
   n = 50
   n_reps = 50000

   mle_est = np.zeros(n_reps)
   med_est = np.zeros(n_reps)

   for i in range(n_reps):
       sample = rng.exponential(1.0/lam_true, n)
       mle_est[i] = 1.0 / np.mean(sample)
       med_est[i] = np.log(2) / np.median(sample)

   I1 = 1.0 / lam_true**2
   crlb = 1.0 / (n * I1)

   print(f"Efficiency comparison: Exp(λ={lam_true}), n={n}")
   print(f"CRLB = 1/(nI₁) = {crlb:.6f}")
   print()
   print(f"{'Estimator':>20}  {'Mean':>8}  {'Var':>10}  "
         f"{'MSE':>10}  {'Rel. Eff.':>10}")
   print("-" * 65)

   mle_var = np.var(mle_est)
   mle_mse = np.mean((mle_est - lam_true)**2)
   med_var = np.var(med_est)
   med_mse = np.mean((med_est - lam_true)**2)

   print(f"{'MLE (1/x̄)':>20}  {np.mean(mle_est):>8.4f}  "
         f"{mle_var:>10.6f}  {mle_mse:>10.6f}  {1.0:>10.4f}")
   print(f"{'Median (log2/med)':>20}  {np.mean(med_est):>8.4f}  "
         f"{med_var:>10.6f}  {med_mse:>10.6f}  "
         f"{mle_var/med_var:>10.4f}")
   print()
   print(f"Theoretical asymptotic relative efficiency: "
         f"{np.log(2)**2:.4f}")

.. code-block:: text

   Efficiency comparison: Exp(λ=2.0), n=50
   CRLB = 1/(nI₁) = 0.080000

              Estimator      Mean         Var         MSE   Rel. Eff.
   -----------------------------------------------------------------
             MLE (1/x̄)    2.0417    0.086203    0.087938      1.0000

The median-based estimator has more than twice the variance of the MLE. The simulated relative efficiency (0.47) matches the theoretical asymptotic value :math:`(\ln 2)^2 \approx 0.48`. Intuitively, the median discards information from the tails of the distribution, whereas the MLE uses all observations through the sample mean. To achieve the same precision as the MLE with :math:`n = 50`, the median-based estimator would need :math:`n \approx 50/0.48 \approx 104` observations.

.. admonition:: Statistical Application
   :class: tip

   Sufficiency and Fisher information are the theoretical backbone of :ref:`ch3_2-maximum-likelihood-estimation`. The score equation :math:`U(\hat{\theta}) = 0` defines the MLE, the observed information :math:`-\ell''(\hat{\theta})` provides standard errors, and the CRLB establishes the best-case precision. The asymptotic efficiency of MLEs (proved in the Asymptotic Theory section below) means they approach the CRLB as :math:`n \to \infty`.


The Likelihood Function
-------------------------

Likelihood versus Probability
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   Given observed data :math:`\mathbf{x} = (x_1, \ldots, x_n)`, the **likelihood function** is

   .. math::

      L(\theta) = L(\theta; \mathbf{x}) = \prod_{i=1}^n f(x_i; \theta)

   and the **log-likelihood** is

   .. math::

      \ell(\theta) = \log L(\theta) = \sum_{i=1}^n \log f(x_i; \theta)

The likelihood and the density are the same mathematical expression, but they play fundamentally different roles:

- **Density** :math:`f(x; \theta)`: :math:`\theta` is fixed, :math:`x` varies. Answers "how probable is :math:`x`?"
- **Likelihood** :math:`L(\theta; \mathbf{x})`: :math:`\mathbf{x}` is fixed (observed), :math:`\theta` varies. Answers "how well does :math:`\theta` explain the data?"

The likelihood is **not** a probability distribution over :math:`\theta` — it need not integrate to 1, and in general it does not. Only ratios of likelihoods are meaningful: :math:`L(\theta_1)/L(\theta_2)` compares how well two parameter values explain the same data.

**Why log-likelihood?** Working with :math:`\ell(\theta) = \log L(\theta)` has three advantages:

1. **Numerical stability:** Products of many small probabilities underflow; sums of log-probabilities do not.
2. **Analytical convenience:** Sums are easier to differentiate than products.
3. **Concavity:** For exponential families, :math:`\ell(\theta)` is concave, guaranteeing a unique maximum.

Since :math:`\log` is monotone increasing, maximizing :math:`L(\theta)` and :math:`\ell(\theta)` give the same answer.


Maximum Likelihood Estimation
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Definition
   :class: definition

   The **maximum likelihood estimator** (MLE) :math:`\hat{\theta}_{\text{MLE}}` is the parameter value that maximizes the likelihood:

   .. math::

      \hat{\theta}_{\text{MLE}} = \arg\max_\theta \ell(\theta)

   Under regularity conditions, the MLE is found by solving the **score equation** :math:`U(\hat{\theta}) = 0`, where :math:`U(\theta) = \ell'(\theta) = \frac{\partial \ell}{\partial\theta}`.

**Intuition.** The MLE answers the question: "Which parameter value makes the observed data most probable?" This is a fundamentally different question from "What is the most probable parameter value?" (the latter requires a Bayesian prior). The MLE principle is agnostic about prior beliefs — it simply finds the parameter that best explains what happened. The score equation :math:`U(\hat{\theta}) = 0` says the log-likelihood is flat at the MLE: moving :math:`\theta` slightly in either direction does not improve the fit. The MLE has a remarkable collection of asymptotic properties — consistency, normality, and efficiency — that make it the workhorse of parametric inference (see the Asymptotic Theory section below). Its main limitation is that it requires a correctly specified parametric model; under misspecification, it converges to the parameter value closest to the truth in a Kullback-Leibler sense (Exercise 3d).

**MLE for Poisson.** Let :math:`X_1, \ldots, X_n \sim \text{Poisson}(\lambda)`. The log-likelihood is:

.. math::

   \ell(\lambda) = \sum_{i=1}^n \bigl(x_i \log\lambda - \lambda - \log(x_i!)\bigr) = \left(\sum x_i\right)\log\lambda - n\lambda - \sum\log(x_i!)

Differentiating and setting to zero:

.. math::

   \ell'(\lambda) = \frac{\sum x_i}{\lambda} - n = 0 \quad\Longrightarrow\quad \hat{\lambda} = \frac{\sum x_i}{n} = \bar{X}

Confirming this is a maximum: :math:`\ell''(\lambda) = -\sum x_i / \lambda^2 < 0`.

**MLE for Normal.** Let :math:`X_1, \ldots, X_n \sim N(\mu, \sigma^2)`. The log-likelihood is:

.. math::

   \ell(\mu, \sigma^2) = -\frac{n}{2}\log(2\pi) - \frac{n}{2}\log\sigma^2 - \frac{1}{2\sigma^2}\sum(x_i - \mu)^2

Taking partial derivatives and setting to zero:

.. math::

   \frac{\partial\ell}{\partial\mu} = \frac{1}{\sigma^2}\sum(x_i - \mu) = 0 &\quad\Longrightarrow\quad \hat{\mu} = \bar{X} \\
   \frac{\partial\ell}{\partial\sigma^2} = -\frac{n}{2\sigma^2} + \frac{1}{2\sigma^4}\sum(x_i - \mu)^2 = 0 &\quad\Longrightarrow\quad \hat{\sigma}^2 = \frac{1}{n}\sum(x_i - \bar{X})^2

Note that the MLE for :math:`\sigma^2` uses :math:`1/n` (not :math:`1/(n-1)`), so it is the **biased** variance estimator. The MLE maximizes the likelihood but does not guarantee unbiasedness — the bias :math:`-\sigma^2/n` vanishes as :math:`n \to \infty`.

**MLE for Gamma.** For Gamma(:math:`\alpha, \beta`), the score equations have no closed-form solution — :math:`\hat{\alpha}` satisfies a transcendental equation involving the digamma function. This is precisely the setting where numerical optimization (Newton-Raphson, Fisher scoring) is needed, developed computationally in :ref:`ch3_2-maximum-likelihood-estimation`.


The Score Function and Information
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

The **score function** :math:`U(\theta) = \ell'(\theta)` has several key properties:

1. :math:`\mathbb{E}[U(\theta)] = 0` at the true :math:`\theta` (proved in the Sufficiency section above)
2. :math:`\text{Var}(U(\theta)) = I_n(\theta) = n\,I_1(\theta)` (Fisher information)
3. The MLE satisfies :math:`U(\hat{\theta}) = 0`

The **observed information** :math:`J(\theta) = -\ell''(\theta)` and the **expected (Fisher) information** :math:`I(\theta) = \mathbb{E}[J(\theta)]` both measure the curvature of the log-likelihood. Sharp curvature (high information) means the data pinpoint :math:`\theta` precisely; broad curvature (low information) means substantial uncertainty remains.

For exponential families, :math:`J(\hat{\theta}) = I_n(\hat{\theta})` exactly — the observed and expected information coincide at the MLE. For non-exponential families, they can differ; in such cases, the observed information is generally preferred because it reflects the actual data rather than an average over hypothetical datasets.


MLE Properties
~~~~~~~~~~~~~~~

The MLE possesses several remarkable properties under regularity conditions. These conditions ensure the likelihood behaves well enough for the calculus-based arguments to work:

.. admonition:: Regularity Conditions
   :class: note

   The standard regularity conditions for MLE theory — identifiability, common support, an interior true parameter, smoothness of :math:`\log f(x;\theta)`, and interchange of differentiation and integration — are stated precisely as R1–R7 in the :ref:`regularity conditions <appendix-e-regularity-conditions>` box in the Asymptotic Theory section below.

   When these conditions fail — boundary parameters, non-smooth likelihoods, support depending on :math:`\theta` — the MLE may still exist but its properties can change dramatically. For Uniform(:math:`0, \theta`), the MLE :math:`X_{(n)}` converges at rate :math:`1/n` rather than :math:`1/\sqrt{n}` and its limiting distribution is Exponential, not Normal.

Under regularity conditions, the MLE has four remarkable properties:

1. **Invariance:** If :math:`\hat{\theta}` is the MLE of :math:`\theta`, then :math:`g(\hat{\theta})` is the MLE of :math:`g(\theta)` for any function :math:`g`. This follows directly from the definition: :math:`g(\hat{\theta})` maximizes the likelihood over the image of the parameter space. Invariance means we need not re-derive the MLE for transformed parameters — the MLE of :math:`\sigma = \sqrt{\sigma^2}` is simply :math:`\sqrt{\hat{\sigma}^2_{\text{MLE}}}`.
2. **Consistency:** :math:`\hat{\theta}_n \xrightarrow{P} \theta_0` as :math:`n \to \infty`. Intuitively, as data accumulates, the log-likelihood concentrates near the true parameter because the KL divergence :math:`D_{\text{KL}}(\theta_0 \| \theta)` creates a "well" at :math:`\theta_0` that deepens with :math:`n`.
3. **Asymptotic normality:** :math:`\sqrt{n}(\hat{\theta}_n - \theta_0) \xrightarrow{d} N(0, I_1(\theta_0)^{-1})`. The log-likelihood is approximately quadratic near its peak, and the curvature of this quadratic is the Fisher information. This is why the quadratic approximation demonstrated in the code block below works well near the MLE.
4. **Asymptotic efficiency:** The MLE achieves the CRLB asymptotically — no consistent estimator can have smaller asymptotic variance. Combined with the CRLB, this means the MLE extracts the maximum possible information from the data in the large-sample limit.

Properties 2–4 are proved in the Asymptotic Theory section below.


Profile Likelihood
~~~~~~~~~~~~~~~~~~~

When dealing with nuisance parameters, **profile likelihood** isolates inference for the parameter of interest. For :math:`\theta = (\psi, \lambda)` where :math:`\psi` is the parameter of interest and :math:`\lambda` is a nuisance parameter, the profile log-likelihood for :math:`\psi` is:

.. math::

   \ell_P(\psi) = \max_\lambda \ell(\psi, \lambda) = \ell(\psi, \hat{\lambda}_\psi)

where :math:`\hat{\lambda}_\psi` is the MLE of :math:`\lambda` for each fixed :math:`\psi`. The profile likelihood behaves like a genuine log-likelihood for :math:`\psi`: its maximum gives :math:`\hat{\psi}`, and its curvature gives a standard error. Profile likelihood confidence intervals (the set of :math:`\psi` where :math:`2(\ell(\hat{\psi}) - \ell_P(\psi)) \le \chi^2_{1,\alpha}`) often have better coverage than Wald intervals, especially for small samples.

**Example:** For Normal(:math:`\mu, \sigma^2`) data, the profile log-likelihood for :math:`\mu` is obtained by plugging in :math:`\hat{\sigma}^2_\mu = \frac{1}{n}\sum(x_i - \mu)^2` for each :math:`\mu`:

.. math::

   \ell_P(\mu) = -\frac{n}{2}\log\!\left(\frac{1}{n}\sum(x_i - \mu)^2\right) + \text{const}


Computational Illustration: Likelihood Anatomy
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # Poisson likelihood analysis
   n = 50
   lam_true = 3.5
   data = rng.poisson(lam_true, n)

   lam_mle = np.mean(data)

   def loglik(lam, x):
       return np.sum(stats.poisson.logpmf(x, lam))

   ll_mle = loglik(lam_mle, data)

   # Observed info: -ℓ''(λ̂) = Σx_i/λ̂²
   obs_info = np.sum(data) / lam_mle**2
   # Expected info: n/λ̂
   exp_info = n / lam_mle

   se = 1.0 / np.sqrt(obs_info)
   ci_lo = lam_mle - 1.96 * se
   ci_hi = lam_mle + 1.96 * se

   print(f"Poisson likelihood analysis (n={n}, λ_true={lam_true})")
   print(f"Data: sum = {np.sum(data)}, x̄ = {lam_mle:.2f}")
   print()
   print(f"MLE: λ̂ = {lam_mle:.4f}")
   print(f"Log-likelihood at MLE: ℓ(λ̂) = {ll_mle:.4f}")
   print(f"Score at MLE: U(λ̂) = {np.sum(data)/lam_mle - n:.6f}")
   print()
   print(f"Observed information: -ℓ″(λ̂) = {obs_info:.4f}")
   print(f"Expected information:  nI₁(λ̂) = {exp_info:.4f}")
   print(f"(Equal — exponential family property)")
   print(f"Standard error: 1/√(obs. info) = {se:.4f}")
   print(f"95% Wald CI: [{ci_lo:.4f}, {ci_hi:.4f}]")
   print()
   print("Quadratic approximation quality:")
   print(f"{'λ':>6}  {'ℓ(λ) exact':>12}  "
         f"{'ℓ(λ) quad':>12}  {'Difference':>12}")
   print("-" * 50)
   for lam_test in [lam_mle - 1.0, lam_mle - 0.5,
                     lam_mle, lam_mle + 0.5, lam_mle + 1.0]:
       ll_exact = loglik(lam_test, data)
       ll_quad = (ll_mle
                  - 0.5 * obs_info * (lam_test - lam_mle)**2)
       print(f"{lam_test:>6.2f}  {ll_exact:>12.4f}  "
             f"{ll_quad:>12.4f}  {ll_exact - ll_quad:>12.4f}")

Asymptotic Theory
------------------

Asymptotic theory provides the limiting behavior of estimators and test statistics as :math:`n \to \infty`. The fundamental results — the law of large numbers, central limit theorem, and their consequences — underpin nearly every inferential method in this course. This section develops each result rigorously.


Modes of Convergence
~~~~~~~~~~~~~~~~~~~~~~

Three modes of convergence appear throughout statistics, with different strengths.

**Intuition.** The three modes differ in *what* they guarantee about the sequence :math:`X_n`. Almost sure convergence is the strongest: it says the sequence literally settles down to :math:`X` for (almost) every realization — the sample path converges. Convergence in probability is weaker: it says the probability of :math:`X_n` being far from :math:`X` shrinks to zero, but occasional large deviations are permitted as long as they become increasingly rare. Convergence in distribution is weakest: it says nothing about individual realizations, only that the *shape* of the distribution of :math:`X_n` approaches the shape of the distribution of :math:`X` — the histograms look more and more alike. For statistical applications, convergence in distribution is usually sufficient: we care about the distributional approximation (e.g., "the test statistic is approximately :math:`N(0,1)`") rather than the path behavior of any single sequence.

.. admonition:: Definition
   :class: definition

   Let :math:`X_n` be a sequence of random variables and :math:`X` a random variable (or constant).

   **Convergence in probability** (:math:`X_n \xrightarrow{P} X`): For every :math:`\epsilon > 0`,

   .. math::

      P(|X_n - X| > \epsilon) \to 0 \quad \text{as } n \to \infty

   **Convergence in distribution** (:math:`X_n \xrightarrow{d} X`): For every point :math:`x` where the CDF :math:`F_X` is continuous,

   .. math::

      F_{X_n}(x) \to F_X(x) \quad \text{as } n \to \infty

   **Almost sure convergence** (:math:`X_n \xrightarrow{a.s.} X`):

   .. math::

      P\!\left(\lim_{n\to\infty} X_n = X\right) = 1

**Relationships.** Almost sure convergence is the strongest:

.. math::

   X_n \xrightarrow{a.s.} X \;\Longrightarrow\; X_n \xrightarrow{P} X \;\Longrightarrow\; X_n \xrightarrow{d} X

The converses do not hold in general, with one exception: if :math:`X_n \xrightarrow{d} c` for a constant :math:`c`, then :math:`X_n \xrightarrow{P} c`. Convergence in distribution is the weakest mode and is all that the CLT provides — but it is sufficient for most statistical applications.


The Weak Law of Large Numbers
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Weak Law of Large Numbers (WLLN)
   :class: note

   Let :math:`X_1, X_2, \ldots` be iid with :math:`\mathbb{E}[X_i] = \mu` and :math:`\text{Var}(X_i) = \sigma^2 < \infty`. Then

   .. math::

      \bar{X}_n = \frac{1}{n}\sum_{i=1}^n X_i \xrightarrow{P} \mu

**Intuition.** The WLLN formalizes the most basic statistical principle: averages stabilize. Each individual :math:`X_i` is unpredictable, but their average :math:`\bar{X}_n` concentrates around :math:`\mu` because the random fluctuations increasingly cancel. The mechanism is variance reduction: :math:`\text{Var}(\bar{X}_n) = \sigma^2/n \to 0`. Chebyshev's inequality converts this shrinking variance directly into a probability statement. The WLLN is the theoretical justification for using sample means to estimate population means, and more broadly, for the entire enterprise of simulation-based inference: Monte Carlo methods work because empirical averages converge to expectations.

.. admonition:: Proof (via Chebyshev's Inequality)
   :class: dropdown

   Chebyshev's inequality states that for any random variable :math:`Y` with mean :math:`\mu_Y` and variance :math:`\sigma_Y^2`:

   .. math::

      P(|Y - \mu_Y| \ge \epsilon) \le \frac{\sigma_Y^2}{\epsilon^2}

   Applying this to :math:`\bar{X}_n` with :math:`\mathbb{E}[\bar{X}_n] = \mu` and :math:`\text{Var}(\bar{X}_n) = \sigma^2/n`:

   .. math::

      P(|\bar{X}_n - \mu| \ge \epsilon) \le \frac{\sigma^2}{n\epsilon^2} \to 0 \quad \text{as } n \to \infty

   Therefore :math:`\bar{X}_n \xrightarrow{P} \mu`.

   This proof requires finite variance. The WLLN holds more generally (Khintchine's theorem requires only :math:`\mathbb{E}[|X|] < \infty`), but the Chebyshev proof is the most transparent and gives an explicit rate: :math:`P(|\bar{X}_n - \mu| \ge \epsilon) = O(1/n)`.


The Central Limit Theorem
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Central Limit Theorem (CLT)
   :class: note

   Let :math:`X_1, X_2, \ldots` be iid with :math:`\mathbb{E}[X_i] = \mu`, :math:`\text{Var}(X_i) = \sigma^2 \in (0, \infty)`. Then

   .. math::

      Z_n = \frac{\sqrt{n}(\bar{X}_n - \mu)}{\sigma} = \frac{\sum_{i=1}^n X_i - n\mu}{\sigma\sqrt{n}} \xrightarrow{d} N(0,1)

**Intuition.** The CLT is perhaps the most remarkable result in probability: regardless of how the individual :math:`X_i` are distributed (skewed, heavy-tailed, discrete, continuous), their standardized average converges to a Gaussian. Why does this happen? The proof reveals the mechanism: when we take the MGF (or characteristic function) of a sum and Taylor-expand, all distributional details beyond the first two moments are suppressed by powers of :math:`1/\sqrt{n}`. The mean and variance survive; skewness, kurtosis, and all higher structure are washed away. The normal distribution is the *universal attractor* for standardized sums — it is the only distribution whose shape is completely determined by its first two moments. This universality is what makes the normal distribution so central to statistics: it is not that data are normally distributed, but that *averages* approximately are, and most of classical inference is inference about averages or functions of averages.

.. admonition:: Proof (via Moment-Generating Functions)
   :class: dropdown

   Let :math:`Y_i = (X_i - \mu)/\sigma` so that :math:`\mathbb{E}[Y_i] = 0`, :math:`\text{Var}(Y_i) = 1`. Then :math:`Z_n = \frac{1}{\sqrt{n}}\sum_{i=1}^n Y_i`.

   The MGF of :math:`Z_n` is:

   .. math::

      M_{Z_n}(t) = \mathbb{E}\!\left[e^{tZ_n}\right] = \mathbb{E}\!\left[e^{t\sum Y_i/\sqrt{n}}\right] = \prod_{i=1}^n \mathbb{E}\!\left[e^{tY_i/\sqrt{n}}\right] = \left[M_Y\!\left(\frac{t}{\sqrt{n}}\right)\right]^n

   Expanding the MGF of :math:`Y` in a Taylor series around 0:

   .. math::

      M_Y(s) = 1 + s\,\mathbb{E}[Y] + \frac{s^2}{2}\mathbb{E}[Y^2] + O(s^3) = 1 + \frac{s^2}{2} + O(s^3)

   since :math:`\mathbb{E}[Y] = 0` and :math:`\mathbb{E}[Y^2] = 1`. Substituting :math:`s = t/\sqrt{n}`:

   .. math::

      M_Y\!\left(\frac{t}{\sqrt{n}}\right) = 1 + \frac{t^2}{2n} + O(n^{-3/2})

   Therefore:

   .. math::

      M_{Z_n}(t) = \left[1 + \frac{t^2}{2n} + O(n^{-3/2})\right]^n

   Taking logarithms: :math:`\log M_{Z_n}(t) = n\log\!\left(1 + \frac{t^2}{2n} + O(n^{-3/2})\right)`. Using :math:`\log(1+u) = u + O(u^2)` for small :math:`u`:

   .. math::

      \log M_{Z_n}(t) = n\!\left(\frac{t^2}{2n} + O(n^{-3/2})\right) = \frac{t^2}{2} + O(n^{-1/2}) \to \frac{t^2}{2}

   Since :math:`e^{t^2/2}` is the MGF of :math:`N(0,1)`, by the continuity theorem for MGFs, :math:`Z_n \xrightarrow{d} N(0,1)`.

   **Caveat.** This proof assumes the MGF of :math:`Y` exists in a neighborhood of 0, which fails for heavy-tailed distributions (e.g., the lognormal has all moments finite but no MGF). The general proof replaces the MGF with the characteristic function :math:`\phi_Y(t) = \mathbb{E}[e^{itY}]`, which exists for every distribution; the Taylor-expansion argument is otherwise identical, with Lévy's continuity theorem completing the proof.

The CLT is remarkable: regardless of the shape of the underlying distribution (skewed, multimodal, discrete, continuous), the standardized sample mean converges to a normal distribution. The rate of convergence depends on the skewness and kurtosis of :math:`X_i`.

**Berry-Esseen bound.** The CLT convergence rate is :math:`O(1/\sqrt{n})`:

.. math::

   \sup_x \left|P(Z_n \le x) - \Phi(x)\right| \le \frac{C\,\mathbb{E}[|Y|^3]}{\sqrt{n}}

where :math:`C \le 0.4748` (the best known constant). This means the normal approximation improves by a factor of :math:`\sqrt{2}` each time the sample size doubles. In practice, symmetric distributions converge faster — the leading skewness term in the approximation error vanishes — while highly skewed distributions (like Exp(1)) converge more slowly.

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # CLT convergence via moments
   n_reps = 10000

   print("CLT convergence: standardized x̄ should → N(0,1)")
   print("N(0,1) targets: Mean=0, Var=1, Skew=0, Kurt=0")
   print()
   print(f"{'Distribution':>15}  {'n':>5}  {'Mean':>7}  "
         f"{'Var':>7}  {'Skew':>7}  {'Kurt':>7}")
   print("-" * 55)

       ("Exp(1)",
        lambda n: rng.exponential(1.0, n), 1.0, 1.0),
       ("Chi²(3)",
        lambda n: rng.chisquare(3, n), 3.0, np.sqrt(6)),
       ("Bern(0.3)",
        lambda n: rng.binomial(1, 0.3, n),
        0.3, np.sqrt(0.3*0.7)),
   ]:
       for n in [5, 15, 50, 200]:
           z = np.zeros(n_reps)
           for i in range(n_reps):
               sample = sampler(n)
               z[i] = ((np.mean(sample) - mu)
                       / (sigma / np.sqrt(n)))
           print(f"{name:>15}  {n:>5}  {np.mean(z):>7.3f}  "
                 f"{np.var(z):>7.3f}  {stats.skew(z):>7.3f}  "
                 f"{stats.kurtosis(z):>7.3f}")
       print()

Slutsky's Theorem
~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Slutsky's Theorem
   :class: note

   If :math:`X_n \xrightarrow{d} X` and :math:`Y_n \xrightarrow{P} c` (a constant), then:

   - :math:`X_n + Y_n \xrightarrow{d} X + c`
   - :math:`X_n \cdot Y_n \xrightarrow{d} c \cdot X`
   - :math:`X_n / Y_n \xrightarrow{d} X / c` (provided :math:`c \ne 0`)

**Intuition.** Slutsky's theorem says that replacing a random quantity with its probability limit inside an expression that converges in distribution does not change the limiting distribution. In practice, this means we can substitute consistent estimators for unknown constants in distributional results. The key requirement is that :math:`Y_n` converges to a *constant*, not a random variable — the theorem fails if :math:`Y_n` converges in distribution to a non-degenerate limit (in that case, we would need the joint distribution of :math:`(X_n, Y_n)`). This result, combined with the CLT, produces nearly every asymptotic distributional result in classical statistics.

.. admonition:: Proof (Product Case)
   :class: dropdown

   We prove :math:`X_n Y_n \xrightarrow{d} cX`. Write:

   .. math::

      X_n Y_n - cX_n = X_n(Y_n - c)

   We need to show :math:`X_n(Y_n - c) \xrightarrow{P} 0`. Fix :math:`\epsilon > 0` and :math:`M > 0`:

   .. math::

      P(|X_n(Y_n - c)| > \epsilon) &= P(|X_n(Y_n-c)| > \epsilon, |X_n| \le M) + P(|X_n(Y_n-c)| > \epsilon, |X_n| > M) \\
      &\le P(|Y_n - c| > \epsilon/M) + P(|X_n| > M)

   The first term :math:`\to 0` as :math:`n \to \infty` because :math:`Y_n \xrightarrow{P} c`. For the second term, since :math:`X_n \xrightarrow{d} X`, the sequence :math:`\{X_n\}` is **tight**: for any :math:`\delta > 0`, there exists :math:`M` such that :math:`P(|X_n| > M) < \delta` for all :math:`n`. So :math:`P(|X_n(Y_n-c)| > \epsilon)` can be made arbitrarily small. Therefore :math:`X_n Y_n - cX_n \xrightarrow{P} 0`, which combined with :math:`X_n \xrightarrow{d} X` gives :math:`X_n Y_n \xrightarrow{d} cX`.

Slutsky's theorem is why the :math:`t`-statistic works: :math:`T_n = \frac{\sqrt{n}(\bar{X} - \mu)}{S}`, where the numerator :math:`\xrightarrow{d} N(0, \sigma^2)` (by CLT) and :math:`S \xrightarrow{P} \sigma` (by WLLN applied to :math:`S^2`), so :math:`T_n \xrightarrow{d} N(0,1)`.


The Continuous Mapping Theorem
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

.. admonition:: Theorem: Continuous Mapping Theorem (CMT)
   :class: note

   If :math:`g` is a continuous function (or continuous except on a set with probability zero under the limit) and :math:`X_n \xrightarrow{d} X`, then :math:`g(X_n) \xrightarrow{d} g(X)`. The same holds for :math:`\xrightarrow{P}` and :math:`\xrightarrow{a.s.}`.

.. admonition:: Proof (Convergence in Probability)
   :class: dropdown

   Let :math:`\epsilon > 0`. Since :math:`g` is continuous at :math:`X(\omega)` a.s., for any :math:`\epsilon > 0` and :math:`\delta > 0`, there exists an event :math:`A` with :math:`P(A) > 1 - \delta` such that on :math:`A`, :math:`g` is continuous and: :math:`|x - X| < \eta \Rightarrow |g(x) - g(X)| < \epsilon` for some :math:`\eta > 0`.

   Then:

   .. math::

      P(|g(X_n) - g(X)| > \epsilon) \le P(|X_n - X| > \eta) + P(A^c) \le P(|X_n - X| > \eta) + \delta

   Since :math:`X_n \xrightarrow{P} X`, the first term :math:`\to 0`. Since :math:`\delta` is arbitrary, :math:`g(X_n) \xrightarrow{P} g(X)`.

The CMT extends convergence results to transformations. For example, if :math:`\bar{X}_n \xrightarrow{P} \mu` (WLLN), then :math:`e^{\bar{X}_n} \xrightarrow{P} e^\mu` and :math:`1/\bar{X}_n \xrightarrow{P} 1/\mu` (when :math:`\mu \ne 0`).


The Delta Method
~~~~~~~~~~~~~~~~~~

The delta method provides the asymptotic distribution of a transformed estimator. It is one of the most widely used tools in statistical inference.

**Intuition.** Suppose we know that :math:`\hat{\theta}` is asymptotically normal around :math:`\theta`. Now we want the distribution of :math:`g(\hat{\theta})` for some smooth function :math:`g`. The delta method linearizes :math:`g` at :math:`\theta` — since :math:`\hat{\theta}` is close to :math:`\theta` for large :math:`n`, the function is well-approximated by its tangent line: :math:`g(\hat{\theta}) \approx g(\theta) + g'(\theta)(\hat{\theta} - \theta)`. This linear approximation transforms the Gaussian fluctuations of :math:`\hat{\theta}` into Gaussian fluctuations of :math:`g(\hat{\theta})`, scaled by the slope :math:`g'(\theta)`. The variance is multiplied by :math:`[g'(\theta)]^2` — steep transformations amplify uncertainty, flat transformations compress it. When :math:`g'(\theta) = 0` the first-order delta method collapses and a second-order expansion is needed, yielding a chi-squared limit instead of Gaussian.

.. admonition:: Theorem: Delta Method (Univariate)
   :class: note

   If :math:`\sqrt{n}(\hat{\theta}_n - \theta) \xrightarrow{d} N(0, \sigma^2)` and :math:`g` is differentiable at :math:`\theta` with :math:`g'(\theta) \ne 0`, then

   .. math::

      \sqrt{n}\bigl(g(\hat{\theta}_n) - g(\theta)\bigr) \xrightarrow{d} N\!\left(0,\; [g'(\theta)]^2 \sigma^2\right)

   Equivalently: :math:`\text{Var}(g(\hat{\theta})) \approx [g'(\theta)]^2 \cdot \text{Var}(\hat{\theta})`.

.. admonition:: Proof
   :class: dropdown

   By Taylor expansion of :math:`g` around :math:`\theta`:

   .. math::

      g(\hat{\theta}_n) = g(\theta) + g'(\theta)(\hat{\theta}_n - \theta) + \frac{g''(\tilde{\theta}_n)}{2}(\hat{\theta}_n - \theta)^2

   where :math:`\tilde{\theta}_n` is between :math:`\hat{\theta}_n` and :math:`\theta`. Rearranging:

   .. math::

      \sqrt{n}\bigl(g(\hat{\theta}_n) - g(\theta)\bigr) = g'(\theta)\sqrt{n}(\hat{\theta}_n - \theta) + \frac{g''(\tilde{\theta}_n)}{2}\sqrt{n}(\hat{\theta}_n - \theta)^2

   The first term :math:`\xrightarrow{d} g'(\theta) \cdot N(0, \sigma^2) = N(0, [g'(\theta)]^2\sigma^2)` by the CLT hypothesis and linearity of convergence in distribution.

   For the second term: :math:`\sqrt{n}(\hat{\theta}_n - \theta)^2 = \frac{1}{\sqrt{n}}\bigl[\sqrt{n}(\hat{\theta}_n - \theta)\bigr]^2`. Since :math:`\sqrt{n}(\hat{\theta}_n - \theta) \xrightarrow{d} N(0,\sigma^2)` implies :math:`\sqrt{n}(\hat{\theta}_n - \theta) = O_P(1)`, and :math:`1/\sqrt{n} \to 0`, the second term is :math:`O_P(1/\sqrt{n}) \to 0`. By Slutsky's theorem, it vanishes.

**Multivariate delta method.** If :math:`\sqrt{n}(\hat{\boldsymbol{\theta}}_n - \boldsymbol{\theta}) \xrightarrow{d} N(\mathbf{0}, \boldsymbol{\Sigma})` and :math:`g: \mathbb{R}^p \to \mathbb{R}^q` is differentiable, then

.. math::

   \sqrt{n}\bigl(g(\hat{\boldsymbol{\theta}}_n) - g(\boldsymbol{\theta})\bigr) \xrightarrow{d} N\!\left(\mathbf{0},\; \mathbf{J}\,\boldsymbol{\Sigma}\,\mathbf{J}^T\right)

where :math:`\mathbf{J} = \frac{\partial g}{\partial\boldsymbol{\theta}^T}` is the :math:`q \times p` Jacobian evaluated at :math:`\boldsymbol{\theta}`.

**Second-order delta method.** When :math:`g'(\theta) = 0` (the first-order term vanishes), the second-order expansion gives:

.. math::

   n\bigl(g(\hat{\theta}_n) - g(\theta)\bigr) \xrightarrow{d} \frac{g''(\theta)}{2}\sigma^2 \chi^2_1

This arises, for example, when constructing confidence intervals for :math:`\theta^2` near :math:`\theta = 0`.

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # Delta method: g(λ) = √λ for Poisson MLE
   lam_true = 3.0
   n_reps = 50000

   print("Delta method: g(λ) = √λ for Poisson MLE")
   print()

   for n in [25, 100, 500]:
       lam_hat = np.zeros(n_reps)
       g_hat = np.zeros(n_reps)
       for i in range(n_reps):
           lam_hat[i] = np.mean(rng.poisson(lam_true, n))
           g_hat[i] = np.sqrt(lam_hat[i])

       # Delta method: Var(√λ̂) ≈ [g'(λ)]² Var(λ̂)
       #   g'(λ) = 1/(2√λ), Var(λ̂) = λ/n
       #   → [1/(2√λ)]² · λ/n = 1/(4n)
       delta_var = 1.0 / (4*n)
       sim_var = np.var(g_hat)

       print(f"n = {n}:")
       print(f"  Var(√λ̂): simulated = {sim_var:.6f}, "
             f"delta method = {delta_var:.6f}, "
             f"ratio = {sim_var/delta_var:.4f}")
       print()

   print("Delta method formula: Var(√λ̂) ≈ [g′(λ)]² · "
         "Var(λ̂) = 1/(4n)")
   print("(Independent of λ — the variance-stabilizing "
         "property of √ for Poisson)")

.. code-block:: text

   Delta method: g(λ) = √λ for Poisson MLE

   n = 25:
     Var(√λ̂): simulated = 0.009901, delta method = 0.010000, ratio = 0.9901

The delta method prediction matches the simulation to within 1% at all sample sizes. The :math:`\sqrt{\lambda}` transformation is a **variance-stabilizing transformation** for the Poisson: the asymptotic variance :math:`1/(4n)` does not depend on :math:`\lambda`. This is practically useful because it means standard errors for :math:`\sqrt{\hat{\lambda}}` do not require estimating :math:`\lambda` — a fact exploited in ANOVA for count data.


Asymptotic Theory of the MLE
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

We now prove the two fundamental properties of the MLE: consistency and asymptotic normality. Together, they establish that the MLE is an optimal general-purpose estimation method.

.. _appendix-e-regularity-conditions:

.. admonition:: Regularity Conditions for MLE Asymptotics
   :class: important

   The classical asymptotic theory requires the following conditions. Let :math:`\theta_0` denote the true parameter value:

   **R1. Identifiability**: Different parameter values give different distributions: :math:`\theta_1 \neq \theta_2 \Rightarrow f(\cdot|\theta_1) \neq f(\cdot|\theta_2)`.

   **R2. Common support**: The support of :math:`f(x|\theta)` does not depend on :math:`\theta`.

   **R3. Interior true value**: :math:`\theta_0` is in the interior of the parameter space :math:`\Theta`.

   **R4. Differentiability**: :math:`\log f(x|\theta)` is three times continuously differentiable in :math:`\theta` for all :math:`x` in the support.

   **R5. Integrability**: We can interchange differentiation and integration: :math:`\frac{\partial}{\partial \theta} \int f(x|\theta)\, dx = \int \frac{\partial f(x|\theta)}{\partial \theta}\, dx`.

   **R6. Finite Fisher information**: :math:`0 < I_1(\theta_0) < \infty`.

   **R7. Uniform integrability**: :math:`\left|\frac{\partial^3 \log f(x|\theta)}{\partial \theta^3}\right|` is bounded by a function with finite expectation in a neighborhood of :math:`\theta_0`.

   These conditions exclude some pathological cases (e.g., uniform distributions with unknown endpoints, where the support depends on :math:`\theta`) but are satisfied by most common parametric families. R5 is the condition that enables the score-mean-zero and Fisher information equivalence proofs above.

**Intuition.** Consistency says the MLE converges to the truth, and the mechanism is the WLLN applied to the log-likelihood: as :math:`n` grows, the average log-likelihood ratio concentrates at its expectation, which is the negative KL divergence — a quantity uniquely minimized at the true parameter. Asymptotic normality goes further: not only does the MLE converge, it does so at rate :math:`1/\sqrt{n}` with a Gaussian shape, and its asymptotic variance equals the Cramér-Rao bound :math:`1/(nI_1(\theta_0))`. This means the MLE is asymptotically efficient — no consistent estimator has smaller asymptotic variance. The proof works by Taylor-expanding the score equation at :math:`\theta_0`: the CLT gives the numerator a Gaussian limit, and the WLLN forces the denominator to converge to the Fisher information. These two ingredients combine via Slutsky's theorem to yield the result.

.. admonition:: Theorem: Consistency of the MLE
   :class: note

   Under regularity conditions R1–R3, together with a uniform-convergence condition discussed in the proof sketch below, the MLE is **consistent**: :math:`\hat{\theta}_n \xrightarrow{P} \theta_0` as :math:`n \to \infty`.

.. admonition:: Proof Sketch (via WLLN)
   :class: dropdown

   The log-likelihood is :math:`\ell_n(\theta) = \sum_{i=1}^n \log f(X_i; \theta)`. Consider the normalized log-likelihood ratio:

   .. math::

      \frac{1}{n}\ell_n(\theta) - \frac{1}{n}\ell_n(\theta_0) = \frac{1}{n}\sum_{i=1}^n \log\frac{f(X_i;\theta)}{f(X_i;\theta_0)}

   By the WLLN, this converges in probability to:

   .. math::

      \mathbb{E}_{\theta_0}\!\left[\log\frac{f(X;\theta)}{f(X;\theta_0)}\right] = -D_{\text{KL}}(\theta_0 \| \theta)

   where :math:`D_{\text{KL}}` is the Kullback-Leibler divergence. By Gibbs' inequality, :math:`D_{\text{KL}}(\theta_0 \| \theta) \ge 0` with equality iff :math:`\theta = \theta_0` (by identifiability). Therefore the normalized log-likelihood is uniquely maximized at :math:`\theta_0` in the limit, and the maximizer :math:`\hat{\theta}_n \xrightarrow{P} \theta_0`.

   **Why this is a sketch.** The WLLN gives convergence *pointwise* in :math:`\theta`; concluding that the *maximizer* converges requires the convergence to be **uniform** over :math:`\theta` — guaranteed, for example, when the parameter space is compact and :math:`\log f(x;\theta)` is continuous in :math:`\theta` with an integrable envelope (the hypotheses of Wald's consistency theorem). Filling this gap is the technical content of a complete proof.

.. admonition:: Theorem: Asymptotic Normality of the MLE
   :class: note

   Under regularity conditions R1–R7:

   .. math::

      \sqrt{n}(\hat{\theta}_n - \theta_0) \xrightarrow{d} N\!\left(0,\; \frac{1}{I_1(\theta_0)}\right)

   Equivalently, the MLE is approximately :math:`N\!\left(\theta_0, \frac{1}{n\,I_1(\theta_0)}\right)` for large :math:`n`.

.. admonition:: Proof (via Score Function Expansion)
   :class: dropdown

   The MLE satisfies the score equation :math:`\ell'_n(\hat{\theta}_n) = 0`. Expand the score around :math:`\theta_0`:

   .. math::

      0 = \ell'_n(\hat{\theta}_n) = \ell'_n(\theta_0) + \ell''_n(\tilde{\theta}_n)(\hat{\theta}_n - \theta_0)

   where :math:`\tilde{\theta}_n` is between :math:`\hat{\theta}_n` and :math:`\theta_0`. Solving for :math:`\hat{\theta}_n - \theta_0`:

   .. math::

      \hat{\theta}_n - \theta_0 = -\frac{\ell'_n(\theta_0)}{\ell''_n(\tilde{\theta}_n)}

   Multiplying by :math:`\sqrt{n}`:

   .. math::

      \sqrt{n}(\hat{\theta}_n - \theta_0) = \frac{\frac{1}{\sqrt{n}}\ell'_n(\theta_0)}{-\frac{1}{n}\ell''_n(\tilde{\theta}_n)}

   **Numerator:** :math:`\frac{1}{\sqrt{n}}\ell'_n(\theta_0) = \frac{1}{\sqrt{n}}\sum_{i=1}^n U_i(\theta_0)` where :math:`U_i = \frac{\partial}{\partial\theta}\log f(X_i;\theta_0)` are iid with mean 0 and variance :math:`I_1(\theta_0)`. By the CLT:

   .. math::

      \frac{1}{\sqrt{n}}\ell'_n(\theta_0) \xrightarrow{d} N(0, I_1(\theta_0))

   **Denominator:** By consistency :math:`\tilde{\theta}_n \xrightarrow{P} \theta_0`, and by the WLLN:

   .. math::

      -\frac{1}{n}\ell''_n(\tilde{\theta}_n) \xrightarrow{P} I_1(\theta_0)

   By Slutsky's theorem:

   .. math::

      \sqrt{n}(\hat{\theta}_n - \theta_0) \xrightarrow{d} \frac{N(0, I_1(\theta_0))}{I_1(\theta_0)} = N\!\left(0, \frac{1}{I_1(\theta_0)}\right)

This result connects all the preceding theory: the CLT provides the numerator's normality, the WLLN provides the denominator's consistency, Slutsky's theorem combines them, and the Fisher information determines the asymptotic variance. The MLE achieves the CRLB asymptotically — it is **asymptotically efficient**.

.. code-block:: python

   import numpy as np
   from scipy import stats

   rng = np.random.default_rng(42)

   # MLE asymptotic normality for Poisson
   lam_true = 3.0
   n_reps = 50000

   print("MLE asymptotic normality: Poisson(λ=3)")
   print("Standardized: Z_n = √(nI₁)·(λ̂ - λ)")
   print("N(0,1) targets: Mean=0, Var=1, Skew=0, Kurt=0")
   print()
   print(f"{'n':>6}  {'Mean':>7}  {'Var':>7}  "
         f"{'Skew':>7}  {'Kurt':>7}")
   print("-" * 42)

   I1 = 1.0 / lam_true
   for n in [10, 50, 200, 1000]:
       z = np.zeros(n_reps)
       for i in range(n_reps):
           lam_hat = np.mean(rng.poisson(lam_true, n))
           z[i] = np.sqrt(n * I1) * (lam_hat - lam_true)
       print(f"{n:>6}  {np.mean(z):>7.4f}  {np.var(z):>7.4f}  "
             f"{stats.skew(z):>7.4f}  "
             f"{stats.kurtosis(z):>7.4f}")

.. code-block:: text

   Standardized: Z_n = √(nI₁)·(λ̂ - λ)

        n     Mean      Var     Skew     Kurt

The standardized MLE converges rapidly to :math:`N(0,1)`. At :math:`n = 10`, the skewness is already only 0.18 (compared to Exp(1)'s skewness of 0.93 at :math:`n = 5` in the CLT table above). By :math:`n = 1000`, all four moments match the :math:`N(0,1)` targets to two decimal places. The Poisson MLE is the sample mean, so this is also a demonstration of the CLT — but the normalization here uses the Fisher information rather than :math:`\sigma`, emphasizing the MLE-specific interpretation.

.. admonition:: Statistical Application
   :class: tip

   The asymptotic results in this section are the theoretical foundation for everything in :ref:`ch3_2-maximum-likelihood-estimation` and :ref:`ch3_3-sampling-variability`. Wald confidence intervals use :math:`\hat{\theta} \pm z_{\alpha/2}/\sqrt{n\,I_1(\hat{\theta})}` directly from the asymptotic normality theorem. The likelihood ratio test's :math:`\chi^2` distribution follows from a quadratic expansion of the log-likelihood. The delta method provides standard errors for transformed parameters. When these asymptotic approximations are unreliable (small :math:`n`, non-regular models), Chapter 4's bootstrap provides a nonparametric alternative.


Connections: From Review to Computation
-----------------------------------------

This appendix establishes the theoretical foundations; the main chapters develop the computational methods that bring this theory to life.

**Point estimation → Chapters 3–4.** The bias-variance decomposition and MSE framework reappear when evaluating bootstrap bias estimates (Chapter 4) and comparing MLE to method-of-moments estimators (Chapter 3). The MoM estimators developed here serve as starting values for iterative MLE algorithms.

**Confidence intervals → Chapters 4–5.** The frequentist coverage guarantee defines the standard against which bootstrap confidence intervals (Chapter 4) are evaluated. The Wald, percentile, and BCa bootstrap methods each approximate the pivotal-quantity approach differently. In Chapter 5, Bayesian credible intervals offer a fundamentally different interpretation — the interval has a posterior probability of containing :math:`\theta`, rather than a coverage guarantee over repeated sampling.

**Hypothesis testing → Chapters 3–4.** The Neyman-Pearson lemma motivates the likelihood ratio test in :ref:`ch3_2-maximum-likelihood-estimation`; the Wald and score tests are derived as asymptotic approximations. The multiple testing framework (Bonferroni, BH) applies whenever Chapter 3's tests are used simultaneously. Bootstrap hypothesis tests (Chapter 4) provide nonparametric alternatives when the asymptotic null distribution is unknown.

**Sufficiency → Chapter 3.** The factorization theorem connects directly to :ref:`ch3_1-exponential-families`: exponential family sufficient statistics are the natural parameters, and the MLE is a function of the sufficient statistic. Fisher information determines the curvature of the log-likelihood surface that Newton-Raphson and Fisher scoring navigate in :ref:`ch3_2-maximum-likelihood-estimation`.

**Likelihood → Chapters 3, 5.** The likelihood function is the computational centerpiece of parametric inference. Chapter 3 develops numerical methods for maximizing it (gradient ascent, Newton-Raphson, EM algorithm). Chapter 5 uses the likelihood as the bridge between prior and posterior: :math:`\text{posterior} \propto \text{likelihood} \times \text{prior}`.

**Fisher information → Chapter 3.** The observed information :math:`-\ell''(\hat{\theta})` provides standard errors for MLEs. Fisher scoring uses the expected information matrix as a step-size matrix. The CRLB bounds the variance of any unbiased estimator, providing a benchmark for comparing MLE precision to bootstrap standard errors.

**Asymptotic theory → Chapters 3–4.** The CLT and delta method underpin the standard errors and Wald intervals in :ref:`ch3_3-sampling-variability`. The MLE's asymptotic normality justifies the :math:`\chi^2` calibration of the LRT. When asymptotic approximations fail — small samples, non-regular models, parameters on boundaries — Chapter 4's resampling methods provide an alternative that does not rely on these theorems.

      import numpy as np
      from scipy import stats

      rng = np.random.default_rng(seed=42)

      mu, sigma = 0.0, 1.0
      n_reps = 10000
      alpha = 0.05

      print("Part (a): 95% t-interval coverage")
      print(f"{'Distribution':>15}  {'n':>5}  {'Coverage':>10}")
      print("-" * 35)

      # Normal(0,1) at n=15
      for n in [15]:
          captures = 0
          for i in range(n_reps):
              sample = rng.normal(mu, sigma, n)
              xbar = np.mean(sample)
              se = np.std(sample, ddof=1) / np.sqrt(n)
              t_crit = stats.t.ppf(1 - alpha/2, df=n-1)
              lo = xbar - t_crit * se
              hi = xbar + t_crit * se
              if lo <= mu <= hi:
                  captures += 1
          print(f"{'Normal(0,1)':>15}  {n:>5}  "
                f"{captures/n_reps:>10.4f}")

      # Exp(1) — mean = 1
      mu_exp = 1.0
      for n in [5, 15, 50]:
          captures = 0
          for i in range(n_reps):
              sample = rng.exponential(1.0, n)

              t_crit = stats.t.ppf(1 - alpha/2, df=n-1)
              lo = xbar - t_crit * se
              hi = xbar + t_crit * se
              if lo <= mu_exp <= hi:

          print(f"{'Exp(1)':>15}  {n:>5}  "

   .. code-block:: python

      import numpy as np
      from scipy import stats

      rng = np.random.default_rng(seed=42)

      n_tests = 200
      n_true_null = 180
      n_true_alt = 20
      delta = 0.5
      n_per_test = 30
      alpha = 0.05

      p_values = np.zeros(n_tests)
      is_null = np.zeros(n_tests, dtype=bool)
      is_null[:n_true_null] = True

      for i in range(n_tests):
          if is_null[i]:
              sample = rng.normal(0, 1, n_per_test)
          else:
              sample = rng.normal(delta, 1, n_per_test)
          t_stat = (np.mean(sample)
                    / (np.std(sample, ddof=1) / np.sqrt(n_per_test)))
          p_values[i] = 2 * stats.t.sf(abs(t_stat),
                                        df=n_per_test-1)

      # Unadjusted
      raw_reject = p_values < alpha

      # Bonferroni
      bonf_reject = p_values < alpha / n_tests

      # Benjamini-Hochberg
      sorted_idx = np.argsort(p_values)
      sorted_p = p_values[sorted_idx]
      m = n_tests
      bh_threshold = np.arange(1, m+1) * alpha / m
      bh_reject_sorted = np.zeros(m, dtype=bool)
      k_max = 0
      for k in range(m):
          if sorted_p[k] <= bh_threshold[k]:
              k_max = k + 1
      bh_reject_sorted[:k_max] = True
      bh_reject = np.zeros(m, dtype=bool)
      bh_reject[sorted_idx] = bh_reject_sorted

      def report(name, reject):
          fp = np.sum(reject & is_null)
          tp = np.sum(reject & ~is_null)
          total = np.sum(reject)
          fdr = fp / total if total > 0 else 0.0
          power = tp / np.sum(~is_null)
          fwer = int(fp > 0)
          print(f"{name:>15}  {total:>8}  {fp:>4}  "
                f"{tp:>4}  {fdr:>7.3f}  "
                f"{power:>7.3f}  {fwer:>5}")

      print(f"Part (d): Multiple testing")
      print(f"{'Method':>15}  {'Rejected':>8}  {'FP':>4}  "
            f"{'TP':>4}  {'FDR':>7}  "
            f"{'Power':>7}  {'FWER':>5}")
      print("-" * 60)
      report("Unadjusted", raw_reject)
      report("Bonferroni", bonf_reject)
      report("BH (FDR)", bh_reject)

   .. code-block:: text

      Part (d): Multiple testing
               Method  Rejected    FP    TP      FDR    Power   FWER
      ------------------------------------------------------------
           Unadjusted        25    11    14    0.440    0.700      1
           Bonferroni         5     0     5    0.000    0.250      0
             BH (FDR)         8     0     8    0.000    0.400      0

   Without correction, 44% of discoveries are false positives — useless in practice. Bonferroni eliminates false positives entirely (FWER = 0) but at severe cost: only 25% power. BH recovers 40% of true effects with zero false discoveries in this realization. In expectation over many realizations, BH controls the FDR at :math:`\le 0.05`, providing a principled tradeoff between discovery and false discovery.

.. dropdown:: Solution
   :class-container: solution

   **(a)**

   The Poisson PMF is :math:`f(x;\lambda) = \frac{\lambda^x e^{-\lambda}}{x!}`. The log-likelihood for one observation:

   .. math::

      \log f(x;\lambda) = x\log\lambda - \lambda - \log(x!)

   Score: :math:`U(\lambda) = x/\lambda - 1`. Since :math:`\mathbb{E}[X] = \lambda`:

   .. math::

      I_1(\lambda) = \text{Var}(U) = \text{Var}(X/\lambda - 1) = \frac{\text{Var}(X)}{\lambda^2} = \frac{\lambda}{\lambda^2} = \frac{1}{\lambda}

   Alternatively via the second derivative: :math:`\ell''(\lambda) = -x/\lambda^2`, so :math:`I_1(\lambda) = -\mathbb{E}[\ell''] = \mathbb{E}[X]/\lambda^2 = 1/\lambda`.

   .. code-block:: python

   **(c)**

   For Normal(:math:`\mu, \sigma^2`), the score vector is:

   .. math::

      U_\mu = \frac{x - \mu}{\sigma^2}, \qquad U_{\sigma^2} = -\frac{1}{2\sigma^2} + \frac{(x-\mu)^2}{2\sigma^4}

   The Fisher information matrix:

   .. math::

      I(\mu, \sigma^2) = \begin{pmatrix} 1/\sigma^2 & 0 \\ 0 & 1/(2\sigma^4) \end{pmatrix}

   The zero off-diagonal elements mean :math:`\mu` and :math:`\sigma^2` are **orthogonal** — information about one does not affect inference about the other.

   .. code-block:: python

      import numpy as np

          [1.0/sigma2_true, 0],

      import numpy as np
      from scipy import stats

      rng = np.random.default_rng(seed=42)

      n = 75
      lam_true = 4.2
      data = rng.poisson(lam_true, n)

      lam_mle = np.mean(data)

      ll_mle = np.sum(stats.poisson.logpmf(data, lam_mle))
      ll_0 = np.sum(stats.poisson.logpmf(data, lam_0))

      lr_stat = 2 * (ll_mle - ll_0)
      lr_pval = 1 - stats.chi2.cdf(lr_stat, df=1)

      score_pval = 1 - stats.chi2.cdf(score_stat, df=1)

      import numpy as np
      from scipy import stats
      from scipy.optimize import brentq

      rng = np.random.default_rng(seed=42)

      n = 50
      mu_true, sigma_true = 3.0, 2.0
      data = rng.normal(mu_true, sigma_true, n)

      mu_mle = np.mean(data)
      sigma2_mle = np.var(data, ddof=0)

      def profile_loglik(mu, x):
          sig2_hat = np.mean((x - mu)**2)
          return (-n/2 * np.log(2*np.pi)
                  - n/2 * np.log(sig2_hat) - n/2)

      ll_max = profile_loglik(mu_mle, data)

      chi2_crit = stats.chi2.ppf(0.95, df=1)

      def pl_diff(mu):
          return (2 * (ll_max - profile_loglik(mu, data))
                  - chi2_crit)

      lo = brentq(pl_diff, mu_mle - 2, mu_mle)
      hi = brentq(pl_diff, mu_mle, mu_mle + 2)

      # t-interval
      s = np.std(data, ddof=1)
      t_crit = stats.t.ppf(0.975, df=n-1)
      ci_t = (mu_mle - t_crit*s/np.sqrt(n),
              mu_mle + t_crit*s/np.sqrt(n))

   .. code-block:: python

      import numpy as np

      rng = np.random.default_rng(seed=42)

      r_true, p_true = 3, 0.4
      n = 200
      n_reps = 10000

      nb_mean = r_true * (1 - p_true) / p_true
      nb_var = r_true * (1 - p_true) / p_true**2

      naive_covers = 0
      sandwich_covers = 0
      mle_vals = np.zeros(n_reps)

      for i in range(n_reps):
          data = rng.negative_binomial(r_true, p_true, n)
          lam_hat = np.mean(data)
          mle_vals[i] = lam_hat

          # Naive SE: sqrt(λ̂/n) — assumes Poisson
          naive_se = np.sqrt(lam_hat / n)

          # Sandwich SE: sqrt(S²/n)
          s2 = np.var(data, ddof=1)
          sandwich_se = np.sqrt(s2 / n)

          z = 1.96
          if (lam_hat - z*naive_se <= nb_mean
              <= lam_hat + z*naive_se):
              naive_covers += 1
          if (lam_hat - z*sandwich_se <= nb_mean
              <= lam_hat + z*sandwich_se):
              sandwich_covers += 1

      print(f"NegBin mean = {nb_mean:.2f}, "
            f"variance = {nb_var:.2f}")

      print(f"Sandwich SE² ≈ Var(X)/n = {nb_var/n:.6f}")
      print()
      print("95% CI coverage:")

   The Poisson MLE :math:`\hat{\lambda} = \bar{X}` converges to the true mean 4.50 (the pseudo-true value that minimizes KL divergence from NegBin to Poisson). The naive SE assumes :math:`\text{Var}(X) = \lambda` (Poisson), but the true variance is 11.25 (overdispersed). The naive SE therefore underestimates the true variability by a factor of :math:`\sqrt{11.25/4.50} = \sqrt{2.5} \approx 1.58`, leading to CIs that are too narrow: only 78.7% coverage instead of 95%. The sandwich SE uses :math:`S^2/n` — the empirical variance divided by :math:`n` — which correctly reflects the actual variability regardless of the assumed model. Its coverage is 94.9%, essentially nominal.

   This exercise demonstrates a fundamental principle: **the MLE remains consistent under misspecification** (it converges to the parameter value that best approximates the true distribution in KL divergence), but **the Fisher information gives the wrong standard error**. The sandwich (robust) standard error corrects this. In Chapter 3, this distinction arises when applying parametric models to data whose true distribution is unknown.
